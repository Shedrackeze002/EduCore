You already simplify $\tfrac{12}{18}$ to $\tfrac{2}{3}$ by dividing out the common factor $6$. Fractions with variables in them work the same way, with one new rule: the denominator is never allowed to be zero.

## Rational expressions and non-permissible values

:::definition Rational expression
A fraction whose numerator and denominator are polynomials, such as $\dfrac{5}{3x - 12}$ or $\dfrac{x^2 - 25}{3x + 15}$. In this course every numerator and denominator is a monomial (one term) or a binomial (two terms).
:::

Division by zero is undefined, so any value of the variable that makes the denominator $0$ must be left out.

:::definition Non-permissible value
A value of the variable that makes a denominator equal to zero. The expression has no value there. We write the restriction with $\ne$, for example $x \ne 4$.
:::

To find the non-permissible values, set the denominator equal to zero and solve. Factor first if the denominator has two terms with a common factor or is a difference of squares.

:::example Three denominators
Find the non-permissible values of $\dfrac{5}{3x - 12}$, $\dfrac{2x}{x^2 - 16}$ and $\dfrac{7}{x^2 + 4}$.
@step $3x - 12 = 0$ gives $3x = 12$, so $x \ne 4$.
@step $x^2 - 16 = (x - 4)(x + 4) = 0$ when $x = 4$ or $x = -4$, so $x \ne -4,\ 4$.
@step $x^2 + 4 = 0$ would need $x^2 = -4$, but a square is never negative. The denominator is never $0$.
@answer $x \ne 4$; $x \ne -4,\ 4$; no non-permissible values.
:::

:::mistake Looking at the numerator
In $\dfrac{x - 6}{x + 2}$, the value $x = 6$ is allowed: the expression just equals $0$ there. Only the **denominator** gives non-permissible values, so the restriction is $x \ne -2$.
:::

## Simplifying monomials

A rational expression is in **simplest form** when the numerator and denominator have no common factor except $1$. For monomials, simplify the coefficients like a fraction, then subtract exponents for each variable.

:::example Monomial over monomial
Simplify $\dfrac{12x^3}{18x^5}$.
@step The denominator is $0$ only when $x = 0$, so $x \ne 0$.
@step Coefficients: $\dfrac{12}{18} = \dfrac{2}{3}$ (divide by $6$).
@step Powers: $\dfrac{x^3}{x^5} = \dfrac{1}{x^2}$, because the larger power is in the denominator.
@answer $\dfrac{2}{3x^2}$, $x \ne 0$
:::

:::tip Two variables
$\dfrac{15a^2b}{10ab^3} = \dfrac{3a}{2b^2}$, with $a \ne 0$ and $b \ne 0$. Deal with each variable on its own.
:::

## Simplifying by factoring

When the numerator or denominator is a binomial, factor it first: look for a **common factor**, then a **difference of squares**, $a^2 - b^2 = (a - b)(a + b)$. State the non-permissible values from the factored original denominator, then divide out common factors.

:::example Factor, restrict, divide out
Simplify $\dfrac{x^2 - 25}{3x + 15}$.
@step Factor: $\dfrac{(x - 5)(x + 5)}{3(x + 5)}$.
@step Non-permissible value: $x + 5 = 0$ gives $x \ne -5$.
@step Divide out the common factor $(x + 5)$.
@answer $\dfrac{x - 5}{3}$, $x \ne -5$
:::

:::example A restriction that disappears
Simplify $\dfrac{4x - 12}{x^2 - 3x}$.
@step Factor: $\dfrac{4(x - 3)}{x(x - 3)}$, so $x \ne 0,\ 3$.
@step Divide out $(x - 3)$.
@answer $\dfrac{4}{x}$, $x \ne 0,\ 3$. The simplified form no longer shows $x \ne 3$, but the original expression is still undefined there, so the restriction stays.
:::

:::mistake Cancelling terms instead of factors
In $\dfrac{x + 6}{x}$ the $x$ on top is a **term**, not a factor, so it cannot be divided out: $\dfrac{x + 6}{x} \ne 6$. Test $x = 2$: $\dfrac{8}{2} = 4$, not $6$. Only factors of the whole numerator and the whole denominator divide out.
:::

## Equivalent forms and opposites

Multiplying the numerator and denominator by the same non-zero factor gives an **equivalent** expression, just as $\tfrac{3}{4} = \tfrac{6}{8}$.

:::example A missing numerator
Find the missing numerator: $\dfrac{3}{x + 2} = \dfrac{?}{x^2 - 4}$.
@step Factor the new denominator: $x^2 - 4 = (x + 2)(x - 2)$. The old denominator was multiplied by $(x - 2)$.
@step Multiply the numerator by the same factor: $3(x - 2) = 3x - 6$.
@answer $3x - 6$. The new expression has $x \ne -2,\ 2$: the two forms are equal only where both are defined.
:::

Binomials such as $5 - x$ and $x - 5$ are **opposites**: $5 - x = -(x - 5)$. Factor out $-1$ (with any common factor) to make them match.

:::example Opposite factors
Simplify $\dfrac{10 - 2x}{x^2 - 25}$.
@step Numerator: $10 - 2x = -2(x - 5)$. Denominator: $(x - 5)(x + 5)$, so $x \ne -5,\ 5$.
@step $\dfrac{-2(x - 5)}{(x - 5)(x + 5)}$: divide out $(x - 5)$.
@answer $-\dfrac{2}{x + 5}$, $x \ne -5,\ 5$
:::

:::check m302-rational-simplify 3
:::

:::summary
- A non-permissible value makes a denominator zero; find them from the original denominator, factored.
- Simplify monomials by reducing the coefficients and subtracting exponents.
- Factor (common factor, then difference of squares) before dividing out; only factors divide out, never terms.
- Opposites such as $5 - x$ and $x - 5$ divide to $-1$.
- Keep every restriction from the original expression, even after its factor is gone.
:::
