When will an investment double? How long until a medication drops below a safe level? In questions like these the unknown is in the **exponent**, so you need new tools: a common base, or logarithms.

## Equations with a common base

If two powers with the same base are equal, their exponents must be equal.

:::definition Equal powers, equal exponents
If $b^m = b^n$ (with $b > 0$ and $b \ne 1$), then $m = n$.
:::

So the plan is: write both sides as powers of the same base, set the exponents equal, and solve.

:::example One side is a power
Solve $2^{x + 3} = 32$.
@step $32 = 2^5$, so $2^{x + 3} = 2^5$.
@step The bases are the same, so $x + 3 = 5$.
@answer $x = 2$
:::

:::example Both bases change
Solve $9^{x - 1} = 27^x$.
@step Both $9$ and $27$ are powers of $3$: $9 = 3^2$ and $27 = 3^3$.
@step $(3^2)^{x - 1} = (3^3)^x$, so $3^{2x - 2} = 3^{3x}$ (power of a power: multiply the exponents).
@step $2x - 2 = 3x$, so $x = -2$.
@step Check: $9^{-3} = \dfrac{1}{729}$ and $27^{-2} = \dfrac{1}{729}$. Both sides match.
@answer $x = -2$
:::

:::mistake Multiplying the whole exponent
$(3^2)^{x - 1} = 3^{2(x - 1)} = 3^{2x - 2}$. Writing $3^{2x - 1}$ multiplies only the $x$. Put the exponent in brackets before you multiply.
:::

## Reciprocals and coefficients

A fraction like $\frac{1}{4}$ is a power with a negative exponent: $\frac{1}{4} = 4^{-1}$. And a coefficient in front of the power must be divided out **first**.

:::example A reciprocal base
Solve $\left(\frac{1}{4}\right)^x = 64$.
@step $\frac{1}{4} = 4^{-1}$ and $64 = 4^3$, so $4^{-x} = 4^3$.
@step $-x = 3$
@answer $x = -3$
:::

:::example A coefficient
Solve $5(2)^x = 80$.
@step Divide both sides by $5$: $2^x = 16$.
@step $16 = 2^4$, so $x = 4$.
@answer $x = 4$
:::

:::mistake Multiplying the coefficient into the base
$5(2)^x$ is not $10^x$. The exponent applies only to the $2$, so divide by $5$ before you do anything else.
:::

## Solving with logarithms

Often there is no common base: $3^x = 50$ cannot be written with $3$ on both sides. Take the **common logarithm** ($\log$, base 10) of both sides and use the fact that $\log(b^x) = x\log b$: the exponent comes down as a factor.

:::example Take the log of both sides
Solve $3^x = 50$ to the nearest hundredth.
@step $\log 3^x = \log 50$
@step $x\log 3 = \log 50$
@step $x = \dfrac{\log 50}{\log 3} = \dfrac{1.69897\ldots}{0.47712\ldots} = 3.5609\ldots$
@step Check: $3^{3.56} \approx 49.95$, very close to $50$.
@answer $x \approx 3.56$
:::

A graph shows the same answer: the solution of $2^x = 20$ is where $y = 2^x$ meets the line $y = 20$, at $x = \dfrac{\log 20}{\log 2} \approx 4.32$.

:::example A decay equation
Solve $400(0.85)^x = 100$ to the nearest hundredth.
@step Divide by $400$: $0.85^x = 0.25$.
@step $x\log 0.85 = \log 0.25$
@step $x = \dfrac{\log 0.25}{\log 0.85} = \dfrac{-0.60206\ldots}{-0.07058\ldots} = 8.5300\ldots$
@answer $x \approx 8.53$
:::

:::mistake Dividing inside the logarithm
$\dfrac{\log 50}{\log 3}$ is **not** $\log \dfrac{50}{3}$. Find each logarithm, then divide the two numbers.
:::

## An expression in the exponent

When the exponent is an expression, bring it down **in brackets**, then solve the linear equation.

:::example Brackets matter
Solve $2^{3x + 1} = 81$ to the nearest hundredth.
@step $\log 2^{3x + 1} = \log 81$, so $(3x + 1)\log 2 = \log 81$.
@step $3x + 1 = \dfrac{\log 81}{\log 2} = 6.33985\ldots$
@step $3x = 5.33985\ldots$, so $x = 1.77995\ldots$
@answer $x \approx 1.78$
:::

:::tip Check with technology
Graph $y = 2^{3x + 1}$ and $y = 81$ and find the point of intersection. Its $x$-coordinate should match your answer.
:::

:::check m302-exp-equation 3
:::

:::summary
- If $b^m = b^n$, then $m = n$: write both sides with a common base and set the exponents equal.
- Use $\frac{1}{b^n} = b^{-n}$ for reciprocals, and divide out a coefficient before you rewrite the power.
- With no common base, take $\log$ of both sides: $\log b^x = x\log b$, so $x = \dfrac{\log N}{\log b}$.
- Keep an expression in the exponent in brackets when you bring it down.
- Check by substituting or by graphing both sides.
:::
