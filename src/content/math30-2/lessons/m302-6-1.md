A bacteria culture that doubles every hour, a truck that loses 15% of its value every year and a social media account that gains 10% more followers every week all follow the same pattern: in each time step, the quantity is **multiplied** by the same number. That pattern is exponential.

## Growth or decay?

:::definition Exponential function
A function of the form $y = a(b)^x$, where $a \ne 0$, $b > 0$ and $b \ne 1$. The value $a$ is the **initial value** (the value when $x = 0$) and $b$ is the **base**: the number the $y$-value is multiplied by each time $x$ increases by $1$.
:::

The base tells you how the function behaves.

- If $b > 1$, the $y$-values increase: **exponential growth**.
- If $0 < b < 1$, the $y$-values decrease: **exponential decay**.

## Features of the graph

For $y = a(b)^x$ with $a > 0$, every graph has the same features.

| Feature | $y = a(b)^x$, $a > 0$ |
|---|---|
| Domain | $\{x \mid x \in \mathbb{R}\}$ |
| Range | $\{y \mid y > 0,\ y \in \mathbb{R}\}$ |
| $y$-intercept | $a$ |
| $x$-intercept | none |
| Horizontal asymptote | $y = 0$ (the $x$-axis) |
| Increasing or decreasing | increasing if $b > 1$, decreasing if $0 < b < 1$ |

The curve gets closer and closer to the $x$-axis but never touches it, because a positive number times a power of a positive number is always positive.

:::example State the features
State the domain, range, $y$-intercept and asymptote of $y = 4\left(\frac{1}{2}\right)^x$, and say whether it is increasing or decreasing.
@step Any real number can be an exponent, so the domain is $\{x \mid x \in \mathbb{R}\}$.
@step Every $y$-value is positive, and the curve approaches $y = 0$ without reaching it, so the range is $\{y \mid y > 0,\ y \in \mathbb{R}\}$ and the asymptote is $y = 0$.
@step At $x = 0$, $y = 4$. The base $\frac{1}{2}$ is between $0$ and $1$, so the function is decreasing.
@answer Domain all real numbers; range $y > 0$; $y$-intercept $4$; asymptote $y = 0$; decreasing.
:::

:::mistake Including zero in the range
The range is $y > 0$, not $y \ge 0$. The graph never reaches the asymptote, so $y = 0$ is never an output.
:::

## Finding a and b from a table or a graph

In an exponential function, each time $x$ increases by $1$, $y$ is multiplied by $b$. So the **ratio** of consecutive $y$-values is constant, and that ratio is $b$. The $y$-value at $x = 0$ is $a$.

:::figure

:::

:::example From a table
Find the equation of the exponential function in the table, then find $y$ when $x = 6$.
@step At $x = 0$, $y = 3$, so $a = 3$.
@step $\dfrac{6}{3} = \dfrac{12}{6} = \dfrac{24}{12} = 2$, so $b = 2$.
@step $y = 3(2)^x$, and when $x = 6$: $y = 3(2)^6 = 3(64) = 192$.
@answer $y = 3(2)^x$; $y = 192$ when $x = 6$.
:::

:::tip Ratio or difference?
If the $y$-values have a constant **difference**, the function is linear. If they have a constant **ratio**, it is exponential. Check two or three pairs before you decide.
:::

## Exponential models in context

Many real situations are written as $y = a(1 + r)^x$ for growth or $y = a(1 - r)^x$ for decay, where $r$ is the percent rate written as a decimal. A base of $1.08$ means an 8% increase each step; a base of $0.85$ means the quantity keeps 85% and loses 15% each step.

:::example A truck loses value
The value of a pickup truck $t$ years after it is bought is modelled by $V = 32\,000(0.85)^t$, where $V$ is in dollars. Describe the model and find the value after 3 years.
@step The base $0.85$ is between $0$ and $1$: exponential decay. $0.85 = 1 - 0.15$, so the truck loses 15% of its value each year.
@step The initial value is $a = 32\,000$: the truck cost \$32,000.
@step After 3 years: $V = 32\,000(0.85)^3 = 32\,000(0.614125) = 19\,652$.
@answer Decay of 15% per year from \$32,000; worth \$19,652 after 3 years.
:::

:::check m302-exp-features 3
:::

:::summary
- An exponential function has the form $y = a(b)^x$: $a$ is the initial value ($y$-intercept) and $b$ is the base.
- $b > 1$ means growth; $0 < b < 1$ means decay. The value of $a$ does not decide this.
- For $a > 0$: domain all real numbers, range $y > 0$, asymptote $y = 0$, no $x$-intercept.
- Consecutive $y$-values have a constant ratio, and that ratio is $b$.
- In context, $b = 1 + r$ means growth of $r$ per step and $b = 1 - r$ means decay of $r$ per step.
:::
