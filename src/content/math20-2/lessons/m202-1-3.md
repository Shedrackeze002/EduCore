Inductive reasoning suggests what might be true. To be sure that a conjecture is true in **every** case, you need a different kind of reasoning: a deductive proof.

## Inductive and deductive reasoning

:::definition Deductive reasoning and proof
- **Deductive reasoning** starts from statements that are known to be true (definitions, properties, given facts) and uses logic to reach a conclusion that must also be true.
- A **proof** is a mathematical argument that shows a statement is true in all cases.
:::

| Inductive reasoning | Deductive reasoning |
|---|---|
| specific examples → general conjecture | general facts → specific conclusion |
| the conclusion is probably true | the conclusion must be true |
| "The last five buses on Route 8 were late, so the next one will be late." | "Every Route 8 bus stops at the library. This is a Route 8 bus, so it will stop at the library." |

:::example A deductive argument
All quadrilaterals have interior angles that add to $360^\circ$. A kite is a quadrilateral. What can you conclude?
@step The first statement is true for every quadrilateral.
@step The second statement says a kite belongs to that group.
@answer The interior angles of a kite add to $360^\circ$.
:::

## Proving statements about numbers

Examples cannot prove a statement about **all** numbers, but algebra can. Use a variable to stand for any integer:

- an even integer: $2n$
- an odd integer: $2n + 1$
- three consecutive integers: $n$, $n + 1$, $n + 2$ (or $n - 1$, $n$, $n + 1$)

Two numbers that can be different need two different variables, such as $2m + 1$ and $2n + 1$.

:::example The sum of two odd integers is even
Prove that the sum of any two odd integers is even.
@step Let the odd integers be $2m + 1$ and $2n + 1$, where $m$ and $n$ are integers.
@step Their sum is $(2m + 1) + (2n + 1) = 2m + 2n + 2$.
@step Factor out 2: $2m + 2n + 2 = 2(m + n + 1)$.
@step $m + n + 1$ is an integer, so $2(m + n + 1)$ is 2 times an integer, which is even.
@answer The sum of any two odd integers is even.
:::

:::mistake Using the same variable twice
Writing two odd integers as $2n + 1$ and $2n + 1$ makes them the same number. The "proof" would only work for adding a number to itself.
:::

:::

## Proving a number trick

Number tricks always seem to give the same answer. Algebra shows why.

:::example Why the trick works
Choose a number. Add 6. Multiply by 2. Subtract 4. Divide by 2. Subtract the number you started with. Prove that the result is always 4.
@step Let the number be $n$. Add 6: $n + 6$.
@step Multiply by 2: $2(n + 6) = 2n + 12$. Subtract 4: $2n + 8$.
@step Divide by 2: $n + 4$. Subtract the starting number: $n + 4 - n = 4$.
@answer The result is always $4$, whatever number you choose. (Check with 7: $13$, $26$, $22$, $11$, $4$.)
:::

:::

## Valid and invalid proofs

:::definition Valid and invalid proofs
A **valid** proof uses correct reasoning at every step. An **invalid** proof contains at least one error, so its conclusion cannot be trusted.
:::

Common errors in proofs:

- dividing by an expression that equals zero, or might equal zero
- taking the square root of both sides and forgetting the negative root: $(-3)^2 = 3^2$ does not mean $-3 = 3$
- claiming something is always true because it worked for a few examples
- algebra slips, such as multiplying only one term of a bracket

:::example A "proof" that 2 = 1
Let $a$ and $b$ be equal numbers that are not zero. Find the error.
@step Step 1: $a = b$. Step 2: $a^2 = ab$. Step 3: $a^2 - b^2 = ab - b^2$.
@step Step 4: $(a + b)(a - b) = b(a - b)$. Step 5: divide by $a - b$: $a + b = b$.
@step Step 6: $2b = b$. Step 7: $2 = 1$.
@answer Step 5 is the error. Since $a = b$, the expression $a - b$ equals $0$, and dividing by zero is not allowed.
:::

:::mistake Dividing by a variable
Dividing both sides of $x^2 = 5x$ by $x$ gives $x = 5$, but it loses the solution $x = 0$. Dividing by $x$ is only allowed when you know $x \ne 0$.
:::

:::summary
- Deductive reasoning uses facts known to be true to reach a conclusion that must be true.
- Write even integers as $2n$, odd integers as $2n + 1$, and use different variables for numbers that can be different.
- A deductive proof covers every case; examples alone cannot.
- Algebra explains number tricks: the starting number cancels out.
- Invalid proofs often divide by zero, drop a negative square root, rely on examples, or contain algebra slips.
:::
