Amara is designing a square quilt block with an area of $50\ \text{cm}^2$. Her calculator says each side is about $7.07$ cm, but the exact length is $\sqrt{50}$ cm — or, more usefully, $5\sqrt{2}$ cm. In this lesson you will learn to rewrite radicals like this, and to decide which of two radicals is larger without a calculator.

## Radicals and perfect squares

:::definition Radical
A **radical** such as $\sqrt{50}$ has a radical sign and a **radicand** (the number underneath, here $50$). The square root $\sqrt{a}$ means the non-negative number whose square is $a$.
:::

Perfect squares are the key to simplifying. It is worth knowing these by heart:

:::figure

A useful property: for $a, b \ge 0$,

$$\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}.$$

You can test it: $\sqrt{4 \times 9} = \sqrt{36} = 6$, and $\sqrt{4} \times \sqrt{9} = 2 \times 3 = 6$.

## Entire radicals to mixed radicals

:::definition Entire and mixed radicals
An **entire radical** has nothing outside the radical sign, like $\sqrt{48}$. A **mixed radical** has a number (or variable) in front, like $4\sqrt{3}$. A mixed radical is in **simplest form** when the radicand has no perfect-square factor other than $1$.
:::

To simplify, find the **largest** perfect square that divides the radicand, split the radical, and take that square root.

:::example Using perfect squares
Write $\sqrt{48}$ as a mixed radical in simplest form.
@step Perfect squares that divide $48$: $4$ and $16$. The largest is $16$.
@step $\sqrt{48} = \sqrt{16 \times 3} = \sqrt{16} \times \sqrt{3}$
@answer $\sqrt{48} = 4\sqrt{3}$
:::

:::example Using prime factors
Simplify $\sqrt{72}$.
@step $72 = 2 \times 2 \times 2 \times 3 \times 3$
@step Each pair of equal factors comes out once: one $2$ and one $3$. The unpaired $2$ stays inside.
@answer $\sqrt{72} = 2 \times 3\sqrt{2} = 6\sqrt{2}$
:::

:::mistake Not using the largest perfect square
$\sqrt{48} = \sqrt{4 \times 12} = 2\sqrt{12}$ is true, but $12$ still contains the perfect square $4$. Keep going: $2\sqrt{12} = 2 \times 2\sqrt{3} = 4\sqrt{3}$.
:::

## Mixed radicals to entire radicals

Reverse the process: write the number in front as a square root, then multiply the radicands.

:::example Mixed to entire
Write $5\sqrt{3}$ as an entire radical.
@step $5 = \sqrt{25}$
@step $5\sqrt{3} = \sqrt{25} \times \sqrt{3} = \sqrt{75}$
@answer $5\sqrt{3} = \sqrt{75}$
:::

The same steps work with a simple variable, as long as the variable is not negative. If $x \ge 0$, then $\sqrt{x^2} = x$, so $x^2$ behaves like a perfect square.

:::example A variable radicand
Assume $x \ge 0$. (a) Simplify $\sqrt{18x^2}$. (b) Write $4x\sqrt{3}$ as an entire radical.
@step (a) $\sqrt{18x^2} = \sqrt{9x^2} \times \sqrt{2} = 3x\sqrt{2}$
@step (b) $4x = \sqrt{16x^2}$, so $4x\sqrt{3} = \sqrt{16x^2 \times 3} = \sqrt{48x^2}$
@answer (a) $3x\sqrt{2}$ (b) $\sqrt{48x^2}$
:::

## Ordering radicals

A larger number in front does not always mean a larger radical. To compare, write every number as an **entire radical** and compare the radicands. A whole number $w$ is $\sqrt{w^2}$.

:::example Ordering four numbers
Order $2\sqrt{7}$, $3\sqrt{3}$, $\sqrt{30}$ and $5$ from least to greatest.
@step $2\sqrt{7} = \sqrt{28}$, $3\sqrt{3} = \sqrt{27}$, and $5 = \sqrt{25}$.
@step Compare the radicands: $25 < 27 < 28 < 30$.
@answer $5 < 3\sqrt{3} < 2\sqrt{7} < \sqrt{30}$
:::

## Exact lengths in design and trades

Simplest radical form is how exact measurements are recorded before rounding at the last step.

:::example A diagonal brace
A farm gate is $8$ ft wide and $4$ ft tall. How long is a diagonal brace from corner to corner, exactly?
@step By the Pythagorean theorem, $d = \sqrt{8^2 + 4^2} = \sqrt{64 + 16} = \sqrt{80}$.
@step $\sqrt{80} = \sqrt{16 \times 5} = 4\sqrt{5}$
@answer The brace is $4\sqrt{5}$ ft long (about $8.9$ ft).
:::

:::summary
- $\sqrt{ab} = \sqrt{a} \times \sqrt{b}$ for $a, b \ge 0$.
- Entire → mixed: take out the **largest** perfect-square factor.
- Mixed → entire: write the coefficient as a square root and multiply the radicands.
- If $x \ge 0$, then $\sqrt{x^2} = x$.
- To order radicals, write each as an entire radical and compare the radicands.
:::
