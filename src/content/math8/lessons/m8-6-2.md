A table of values shows a few points, but a graph shows the whole relation at a glance. You can see whether it goes up or down, read values that are not in the table, and even predict what comes next.

## Graphing a linear relation

To graph a relation, make a table of values, then plot each pair $(x,\ y)$ as a point on a coordinate grid. For a linear relation, the points line up, so you can draw a straight line through them.

:::example Graph y = 2x − 1
Graph $y = 2x - 1$.
@step Make a table: $x = -1$ gives $y = 2(-1) - 1 = -3$; $x = 0$ gives $y = -1$; $x = 1$ gives $y = 1$; $x = 2$ gives $y = 3$.
@step Plot the points $(-1,\ -3)$, $(0,\ -1)$, $(1,\ 1)$ and $(2,\ 3)$.
@step They lie in a straight line. Draw the line through them with a ruler.
@answer The graph is the straight line shown below.
:::

:::figure

## Reading values from a graph

Every point on the line belongs to the relation, not just the points you plotted. That means you can read new values from the graph.

:::definition Interpolate
To **interpolate** is to find a value **between** known data points.
:::

:::definition Extrapolate
To **extrapolate** is to find a value **beyond** the known data points, by extending the line. It assumes the pattern keeps going.
:::

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":8,"yMin":0,"yMax":22,"xStep":1,"yStep":2,"xLabel":"Distance (km)","yLabel":"Fare ($)"},"points":[{"x":0,"y":4},{"x":2,"y":8},{"x":4,"y":12}],"polylines":[{"points":[[0,4],[4,12]]}],"segments":[{"from":[4,12],"to":[8,20],"dashed":true}],"caption":"Taxi fares: F = 2d + 4"}
:::

:::example Interpolate and extrapolate
The graph shows taxi fares from a table for $0$, $2$ and $4$ km. Find the fare for a $3$ km ride and for a $7$ km ride.
@step $3$ km is between the data points. Go up from $3$ to the line, then across: \$10. This is interpolating.
@step $7$ km is beyond the data, so follow the dashed extension of the line: \$18. This is extrapolating.
@step Check with the equation: $F = 2(7) + 4 = 14 + 4 = 18$.
@answer A $3$ km ride costs \$10 and a $7$ km ride costs \$18.
:::

:::mistake Not reading the scale
On this graph, each grid line up is \$2, not \$1. Always read the numbers on the axes before you count grid lines.
:::

## Matching an equation to a table

In an equation such as $y = 3x + 5$, each number has a job:
- the number that **multiplies $x$** is how much $y$ changes when $x$ goes up by $1$;
- the number **added** is the value of $y$ when $x = 0$.

:::figure
{"type":"table","horizontal":true,"headers":["$x$","$y$"],"rows":[["0","5"],["1","8"],["2","11"],["3","14"]]}
:::

:::example Which equation fits?
Which equation matches the table: $y = 5x + 3$, $y = x + 7$ or $y = 3x + 5$?
@step $y$ goes up by $3$ each time $x$ goes up by $1$, so the equation has $3x$.
@step When $x = 0$, $y = 5$, so the equation adds $5$.
@step Test $y = 3x + 5$ with another column: $x = 3$ gives $3(3) + 5 = 14$. It matches.
@answer $y = 3x + 5$
:::

:::mistake Testing only one column
$y = x + 7$ gives $8$ when $x = 1$, which matches the table, but it gives $9$ when $x = 2$, not $11$. An equation must work for **every** column.
:::

:::check m8-linear-equation 1
:::

## Matching an equation to a graph

A graph that **rises** from left to right has a positive number multiplying $x$. A graph that **falls** has a negative one. The point where the line crosses the $y$-axis shows the value of $y$ when $x = 0$.

:::figure
{"type":"plane","grid":{"xMin":-6,"xMax":6,"yMin":-6,"yMax":6},"points":[{"x":-1,"y":5},{"x":0,"y":3},{"x":1,"y":1},{"x":2,"y":-1}],"lines":[{"through":[[0,3],[1,1]]}]}
:::

:::example Read the equation from a graph
Find the equation of the line in the graph above.
@step Points on the line: $(-1,\ 5)$, $(0,\ 3)$, $(1,\ 1)$ and $(2,\ -1)$.
@step Each time $x$ goes up by $1$, $y$ goes down by $2$, so the equation has $-2x$.
@step When $x = 0$, $y = 3$.
@step Check $(2,\ -1)$: $3 - 2(2) = 3 - 4 = -1$. It matches.
@answer $y = -2x + 3$, which you can also write as $y = 3 - 2x$.
:::

:::summary
- To graph a linear relation, make a table of values, plot the points and draw a straight line through them.
- Interpolating means reading a value between data points; extrapolating means extending the line beyond them.
- Read the scale on each axis before you read a value.
- In $y = ax + b$, $a$ is the change in $y$ for each $1$ of $x$, and $b$ is the value of $y$ when $x = 0$.
- Check an equation against every point in a table or on a graph.
:::
