Three friends each buy a hockey ticket and pay a \$4 service fee per ticket. Together they spend \$75. Each person pays for the same two things, so the total is $3$ groups of (ticket + fee). Brackets show groups like this, and in this lesson you will solve equations with brackets in two ways.

## What the brackets mean

$3(x + 2)$ means $3$ groups of $x + 2$. The tiles show three groups, each with one $x$-tile and two unit tiles. Altogether there are $3$ $x$-tiles and $6$ unit tiles, so $3(x + 2) = 3x + 6$.

:::definition Distributive property
The **distributive property** says that a number outside brackets multiplies **each** term inside: $a(x + b) = ax + ab$. For example, $3(x + 2) = 3x + 6$ and $-2(x - 5) = -2x + 10$.
:::

## Method 1: divide first

In $3(x + 2) = 21$, the whole bracket is multiplied by $3$. Undo that first by dividing both sides by $3$.

:::example Solve 3(x + 2) = 21 by dividing first
Solve $3(x + 2) = 21$.
@step Divide both sides by $3$: $x + 2 = 21 \div 3 = 7$
@step Subtract $2$ from both sides: $x = 7 - 2 = 5$
@step Check: $3(5 + 2) = 3(7) = 21$. It works.
@answer $x = 5$
:::

## Method 2: distribute first

You can also use the distributive property to remove the brackets. Then you have a two-step equation.

:::example Solve −4(x − 3) = 20 by distributing
Solve $-4(x - 3) = 20$.
@step Distribute: $-4(x) + (-4)(-3) = -4x + 12$, so $-4x + 12 = 20$.
@step Subtract $12$ from both sides: $-4x = 8$
@step Divide both sides by $-4$: $x = 8 \div (-4) = -2$
@step Check: $-4(-2 - 3) = -4(-5) = 20$. It works.
@answer $x = -2$
:::

Dividing first gives the same answer: $x - 3 = 20 \div (-4) = -5$, so $x = -5 + 3 = -2$.

:::mistake Multiplying only the first term
$3(x - 4)$ is **not** $3x - 4$. The $3$ multiplies both terms: $3(x - 4) = 3x - 12$. With a negative number outside, watch the signs too: $-2(x - 5) = -2x + 10$, because a negative times a negative is positive.
:::

:::

## Choosing a method and finding mistakes

Both methods always give the same solution. Dividing first is often quicker when the number on the right divides evenly. Distributing first is useful when it does not.

:::example Find the mistake
Mira solved $2(x - 6) = 10$ like this. Step 1: $2x - 6 = 10$. Step 2: $2x = 16$. Step 3: $x = 8$. Find her mistake and solve the equation correctly.
@step Check her answer: $2(8 - 6) = 2(2) = 4$, not $10$, so something is wrong.
@step In Step 1 she multiplied only $x$ by $2$. It should be $2x - 12 = 10$.
@step Then $2x = 10 + 12 = 22$, so $x = 22 \div 2 = 11$.
@step Check: $2(11 - 6) = 2(5) = 10$. It works.
@answer The mistake is in Step 1. The solution is $x = 11$.
:::

:::example A square garden
Each side of a square garden is $(s + 3)$ m long, and its perimeter is $36$ m. Solve $4(s + 3) = 36$.
@step Divide both sides by $4$: $s + 3 = 9$
@step Subtract $3$ from both sides: $s = 6$
@step Check: $4(6 + 3) = 4(9) = 36$. It works.
@answer $s = 6$ m, so each side of the garden is $9$ m long.
:::

:::summary
- $a(x + b)$ means $a$ groups of $x + b$; by the distributive property it equals $ax + ab$.
- Method 1: divide both sides by $a$, then undo the adding or subtracting.
- Method 2: distribute, then solve the two-step equation.
- Multiply **every** term in the brackets, and watch the signs when the number outside is negative.
:::
