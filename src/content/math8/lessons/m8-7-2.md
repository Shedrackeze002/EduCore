A taxi charges \$4 to start plus \$2 for each kilometre, and your fare was \$22. How far did you ride? Two things happen to the distance: it is multiplied by $2$, then $4$ is added. To find it, you undo both steps.

## Undoing two operations

In $2x + 3 = 11$, two things happen to $x$: it is multiplied by $2$, then $3$ is added. To solve it, undo them in **reverse order**: undo the adding first, then the multiplying.

The balance shows $2x + 3 = 11$. Take $3$ unit tiles off **both** sides: $2x = 8$. Then share the $8$ unit tiles between the $2$ $x$-tiles: each $x$-tile matches $4$.

:::example Solve 2x + 3 = 11
Solve $2x + 3 = 11$.
@step Undo the adding: subtract $3$ from both sides. $2x = 11 - 3 = 8$
@step Undo the multiplying: divide both sides by $2$. $x = 8 \div 2 = 4$
@step Check: $2(4) + 3 = 8 + 3 = 11$. It works.
@answer $x = 4$
:::

:::mistake Dividing first
For $2x + 3 = 11$, do not divide by $2$ first. The $3$ is not multiplied by $2$, so subtract it before you divide. If you divide first, you must divide **every** term: $x + 1.5 = 5.5$, which is harder.
:::

## Two-step equations with integers

The steps are the same with negative numbers. To undo subtracting $7$, add $7$. To undo multiplying by a negative number, divide by that negative number.

:::example Solve −3x + 5 = 20
Solve $-3x + 5 = 20$.
@step Subtract $5$ from both sides: $-3x = 20 - 5 = 15$
@step Divide both sides by $-3$: $x = 15 \div (-3) = -5$
@step Check: $-3(-5) + 5 = 15 + 5 = 20$. It works.
@answer $x = -5$
:::

:::example Solve 4x − 7 = −19
Solve $4x - 7 = -19$.
@step Add $7$ to both sides: $4x = -19 + 7 = -12$
@step Divide both sides by $4$: $x = -12 \div 4 = -3$
@step Check: $4(-3) - 7 = -12 - 7 = -19$. It works.
@answer $x = -3$
:::

:::

## Equations with division

For $\dfrac{x}{a} + b = c$, undo the adding or subtracting first, then multiply both sides by $a$.

:::example Solve x/4 − 3 = 2
Solve $\dfrac{x}{4} - 3 = 2$.
@step Add $3$ to both sides: $\dfrac{x}{4} = 2 + 3 = 5$
@step Multiply both sides by $4$: $x = 5 \times 4 = 20$
@step Check: $\dfrac{20}{4} - 3 = 5 - 3 = 2$. It works.
@answer $x = 20$
:::

## Equations written in a different order

Sometimes the number comes first, as in $7 - 2x = 15$, or the variable is on the right, as in $1 = \dfrac{x}{-2} + 6$. Rewrite the equation in the usual order first. Remember that $7 - 2x$ is the same as $-2x + 7$.

:::example Solve 7 − 2x = 15
Solve $7 - 2x = 15$.
@step Rewrite: $-2x + 7 = 15$
@step Subtract $7$ from both sides: $-2x = 15 - 7 = 8$
@step Divide both sides by $-2$: $x = 8 \div (-2) = -4$
@step Check: $7 - 2(-4) = 7 + 8 = 15$. It works.
@answer $x = -4$
:::

:::tip Keep the sign with its term
In $7 - 2x$, the minus sign belongs to $2x$. That is why the coefficient is $-2$, not $2$.
:::

:::

:::summary
- In a two-step equation, undo the operations in reverse order: adding or subtracting first, then multiplying or dividing.
- Whatever you do to one side of an equation, do to the other side.
- Rewrite equations such as $7 - 2x = 15$ as $-2x + 7 = 15$ before you solve.
- Check by substituting your solution into the original equation.
:::
