A print shop enlarging a photo, a sign maker scaling up a logo and a hobby store selling a 1:24 model truck all work with shapes that are the same shape but a different size. In math, those shapes are called **similar**.

## What makes polygons similar?

Two polygons are similar when one is an exact enlargement or reduction of the other. Nothing gets stretched in only one direction, and no angle changes.

:::definition Similar polygons
Two polygons are **similar** when **both** of these are true:
- every pair of **corresponding angles** is equal, and
- every pair of **corresponding sides** is in the same ratio (the sides are **proportional**).
:::

:::definition Corresponding
**Corresponding** sides or angles are the ones in matching positions: the longest side with the longest side, the shortest with the shortest, and so on.
:::

:::example Two rectangles
Rectangle A is $6\ \text{cm}$ by $4\ \text{cm}$. Rectangle B is $9\ \text{cm}$ by $6\ \text{cm}$. Are they similar?
@step Angles: every angle in a rectangle is $90^\circ$, so the corresponding angles are equal.
@step Long sides: $\dfrac{9}{6} = 1.5$. Short sides: $\dfrac{6}{4} = 1.5$.
@answer The ratios are equal, so the sides are proportional. The rectangles **are** similar.

## One condition is not enough

You must check **both** angles and sides. Here are two traps.

**Equal angles, different shape.** A $4\ \text{m}$ square and an $8\ \text{m}$ by $4\ \text{m}$ rectangle both have four $90^\circ$ angles. But $\dfrac{8}{4} = 2$ while $\dfrac{4}{4} = 1$. The ratios are different, so they are **not** similar.

**Proportional sides, different angles.** A $3\ \text{ft}$ square and a $5\ \text{ft}$ rhombus have all their sides in the ratio $\dfrac{5}{3}$. But the rhombus has angles of $60^\circ$ and $120^\circ$, not $90^\circ$. They are **not** similar.

:::mistake "Same size" is not the rule
Similar shapes do **not** have to be the same size. Same size **and** same shape is called *congruent*. Similar only means same shape.
:::

:::tip Triangles are easier
For triangles, if all three pairs of sides have the same ratio, the angles automatically match. Squares are always similar to each other, and so are regular polygons with the same number of sides.
:::

:::example The photo that will not fit
Can a $4\ \text{in} \times 6\ \text{in}$ photo be enlarged to an $8\ \text{in} \times 10\ \text{in}$ print without cutting anything off?
@step Short sides: $\dfrac{8}{4} = 2$. Long sides: $\dfrac{10}{6} \approx 1.67$.
@step The ratios are different, so the shapes are not similar.
@answer No. Part of the photo must be cropped. An $8\ \text{in} \times 12\ \text{in}$ print is similar, because $\dfrac{8}{4} = \dfrac{12}{6} = 2$.
:::

## The scale factor

:::definition Scale factor
The **scale factor**, $k$, tells how many times as long each side of the new figure is:
$$k = \frac{\text{new length}}{\text{original length}}$$
If $k > 1$, the new figure is an **enlargement**. If $k < 1$, it is a **reduction**. If $k = 1$, it is the same size.
:::

:::example An enlargement
A triangle with sides of $5\ \text{cm}$, $7\ \text{cm}$ and $9\ \text{cm}$ is enlarged to a similar triangle with sides of $12.5\ \text{cm}$, $17.5\ \text{cm}$ and $22.5\ \text{cm}$. Find the scale factor.
@step $k = \dfrac{12.5}{5} = 2.5$
@step Check another pair: $\dfrac{17.5}{7} = 2.5$
@answer $k = 2.5$. It is greater than 1, so the new triangle is an enlargement.
:::

:::example A scale model
A model pickup truck is $18.5\ \text{cm}$ long. The real truck is $4.44\ \text{m}$ long. What scale factor turns the real truck into the model?
@step Use the same units: $4.44\ \text{m} = 444\ \text{cm}$.
@step $k = \dfrac{18.5}{444}$, and $444 \div 18.5 = 24$.
@answer $k = \dfrac{1}{24}$, a reduction. The model is labelled $1:24$.
:::

:::mistake Dividing the wrong way
Always put the **new** figure on top. A sign reduced from $15\ \text{cm}$ to $6\ \text{cm}$ has $k = \dfrac{6}{15} = 0.4$, not $\dfrac{15}{6} = 2.5$. A reduction must have a scale factor less than 1.
:::

:::summary
- Similar polygons have equal corresponding angles **and** proportional corresponding sides.
- Equal angles alone are not enough (rectangle vs square). Proportional sides alone are not enough (square vs rhombus).
- Match sides by position: longest with longest, shortest with shortest.
- Scale factor $k = \dfrac{\text{new}}{\text{original}}$. $k > 1$ is an enlargement; $k < 1$ is a reduction.
- Put both lengths in the same unit before you divide.
:::
