Every measuring tool has limits. A tape measure cannot show a hundredth of a millimetre, and a scale that has been dropped may read a few grams heavy. In the trades, knowing how **precise** and how **accurate** a measurement is decides whether a part fits, a recipe works or a job passes inspection.

## The precision of an instrument

:::definition Precision
The **precision** of an instrument is the smallest unit it can measure: the space between its smallest marks, or the last digit on its display. An instrument with a smaller unit is **more precise**.
:::

Look closely at a metric ruler. There are $10$ small spaces between each pair of numbered centimetre marks, so each space is $1\ \text{mm}$. The ruler measures to the nearest millimetre: its precision is $1\ \text{mm}$ ($0.1\ \text{cm}$).

A carpenter's tape measure is usually marked in sixteenths of an inch, so its precision is $\tfrac{1}{16}\ \text{in}$. A digital caliper shows two decimal places of a millimetre, so its precision is $0.01\ \text{mm}$.

:::

:::example Reading the precision of a tool
What is the precision of the imperial ruler above, and what length does it show for the bar?
@step Count the spaces between the $0$ and $1$ inch marks: there are $16$, so each space is $\tfrac{1}{16}\ \text{in}$.
@step The bar ends $7$ small spaces past the $3$ inch mark, so it is $3\tfrac{7}{16}\ \text{in}$ long.
@answer The precision is $\tfrac{1}{16}\ \text{in}$, and the bar is $3\tfrac{7}{16}\ \text{in}$ long.
:::

## The precision of a measurement

A recorded measurement shows how precise the instrument was. The **precision of a measurement** is the place value of its last digit.

- $26.4\ \text{mm}$ is precise to the nearest $0.1\ \text{mm}$.
- $26.40\ \text{mm}$ is precise to the nearest $0.01\ \text{mm}$.
- $3\tfrac{5}{8}\ \text{in}$ is precise to the nearest $\tfrac{1}{8}\ \text{in}$.

:::example A recorded zero
A mechanic uses a micrometer and records the thickness of a brake rotor as $26.40\ \text{mm}$. What is the precision of this measurement?
@step The last digit is the $0$ in the hundredths place.
@step The mechanic wrote the $0$ because the micrometer showed it, so the hundredths place was measured.
@answer The precision is $0.01\ \text{mm}$.
:::

:::mistake Dropping a zero, or judging by size
Writing $26.40\ \text{mm}$ as $26.4\ \text{mm}$ throws away information: it hides the fact that the hundredths were measured. Also, a bigger number is not more precise. $4268\ \text{mm}$ and $18.25\ \text{mm}$ are compared by their last digits, not by their size.
:::

To compare measurements written in different units, change each smallest unit to the same unit first.

:::example Three workers, three units
Three workers measure the same board as $3.2\ \text{m}$, $318\ \text{cm}$ and $3176\ \text{mm}$. Which measurement is the most precise?
@step $3.2\ \text{m}$ is to the nearest $0.1\ \text{m} = 100\ \text{mm}$.
@step $318\ \text{cm}$ is to the nearest $1\ \text{cm} = 10\ \text{mm}$.
@step $3176\ \text{mm}$ is to the nearest $1\ \text{mm}$.
@answer $3176\ \text{mm}$ has the smallest unit, so it is the most precise.
:::

## Accuracy

:::definition Accuracy
The **accuracy** of a measurement is how close it is to the true (actual) value. The smaller the difference between a reading and the true value, the more accurate the reading.
:::

Shops check their tools against objects whose true size is known, such as a **gauge block** in a machine shop or a certified test mass in a bakery. The difference between a reading and the true value tells you how accurate the tool is.

:::example Checking two calipers
A machinist checks two calipers on a gauge block that is exactly $25.400\ \text{mm}$ long. The digital caliper reads $25.46\ \text{mm}$ and the vernier caliper reads $25.4\ \text{mm}$. Which caliper is more accurate?
@step Digital caliper: $|25.46 - 25.400| = 0.06\ \text{mm}$ off.
@step Vernier caliper: $|25.4 - 25.400| = 0\ \text{mm}$ off.
@answer The vernier caliper is more accurate, even though the digital caliper is more precise. The digital caliper probably needs to be zeroed.
:::

:::mistake Precise is not the same as accurate
More decimal places only means a smaller unit. A digital scale that reads to $0.1\ \text{g}$ but has not been calibrated can be far from the true value. Always compare each reading with the true value to judge accuracy.
:::

:::tip Precise and accurate together
The best tool for a job is both: its unit is small enough for the job, and its readings are close to the true value. Choose an instrument whose precision matches the number of decimal places the job needs, then check it against a known standard.
:::

## Comparing accuracy with percent error

An error of $6\ \text{mm}$ is huge on a $40\ \text{mm}$ bracket but tiny on a $2400\ \text{mm}$ beam. To compare the accuracy of measurements of different sizes, write each error as a percent of the true value.

:::definition Percent error
$$\text{percent error} = \dfrac{|\text{measured value} - \text{true value}|}{\text{true value}} \times 100\%$$
A smaller percent error means a more accurate measurement for the size of the object.
:::

:::example Bracket or beam?
A bracket that is truly $40\ \text{mm}$ long is measured as $40.4\ \text{mm}$. A steel beam that is truly $2400\ \text{mm}$ long is measured as $2406\ \text{mm}$. Which measurement is more accurate for the size of the object?
@step Bracket: error $= 0.4\ \text{mm}$, so percent error $= \dfrac{0.4}{40} \times 100\% = 1\%$.
@step Beam: error $= 6\ \text{mm}$, so percent error $= \dfrac{6}{2400} \times 100\% = 0.25\%$.
@answer The beam measurement is more accurate for its size, even though it is off by more millimetres.
:::

:::summary
- **Precision** is the smallest unit an instrument measures, or the place value of the last digit of a measurement. A smaller unit is more precise.
- A zero at the end of a decimal counts: $26.40\ \text{mm}$ is precise to $0.01\ \text{mm}$.
- Compare precision in different units by changing each smallest unit to the same unit.
- **Accuracy** is how close a measurement is to the true value. Subtract to find the error.
- A precise instrument is not always accurate. Percent error compares accuracy for objects of different sizes.
:::
