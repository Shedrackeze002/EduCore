A pan balance stays level only when both pans hold the same mass. An equation works the same way: the two sides are equal, and they stay equal only if you treat them fairly.

## Preservation of equality

:::definition Preservation of equality
**Preservation of equality** means that an equation stays balanced (true) when you do the **same operation to both sides**: add the same number, subtract the same number, multiply by the same number, or divide by the same number (not 0).
:::

:::example Keep a number sentence balanced
The equation $8 + 4 = 12$ is true. Multiply both sides by 3. Is it still true?
@step Left side: $(8 + 4) \times 3 = 12 \times 3 = 36$
@step Right side: $12 \times 3 = 36$
@answer Yes. Both sides equal $36$, so $(8 + 4) \times 3 = 12 \times 3$ is still balanced.
:::

:::mistake Change the whole side
Writing $8 + 4 \times 3 = 12 \times 3$ only multiplies the $4$. The left side becomes $8 + 12 = 20$, but the right side is $36$. Put brackets around the whole side before you multiply or divide it.
:::

:::

:::example Solve with the balance
Solve $2x + 3 = 11$.
@step Remove 3 marbles from each pan: $2x + 3 - 3 = 11 - 3$, so $2x = 8$. The picture above shows this step.
@step Split each pan into 2 equal groups: $\dfrac{2x}{2} = \dfrac{8}{2}$, so $x = 4$.
@step Check: $2(4) + 3 = 8 + 3 = 11$ ✓
@answer Each bag holds 4 marbles: $x = 4$.
:::

:::example Choose a step that keeps the balance
Which step keeps $4x + 3 = 19$ balanced: $4x + 3 - 3 = 19$ or $4x + 3 - 3 = 19 - 3$?
@step The first one subtracts 3 from the left side only. The sides are no longer equal.
@step The second one subtracts 3 from both sides, so $4x = 16$.
@answer $4x + 3 - 3 = 19 - 3$ keeps the equation balanced.
:::

:::check m7-preserve-equality 2
:::

## Finding a mistake

A wrong answer often comes from one step where the two sides were treated differently. Check each step: was the same thing done to both sides?

:::example Spot the mistake
Jun solved $3x + 6 = 21$ like this. Step 1: $3x + 6 - 6 = 21 - 6$. Step 2: $3x = 15$. Step 3: $\dfrac{3x}{3} = 15$. Step 4: $x = 15$. Where is the mistake?
@step Check the answer: $3(15) + 6 = 51$, not $21$. Something went wrong.
@step Step 1 subtracts 6 from both sides. Step 2 is correct.
@step Step 3 divides the left side by 3 but not the right side.
@answer The mistake is in Step 3. It should be $\dfrac{3x}{3} = \dfrac{15}{3}$, so $x = 5$. Check: $3(5) + 6 = 21$ ✓
:::

:::tip Substitute to check
Put your answer back into the original equation. If both sides are not equal, look for the step where the balance tipped.
:::

:::check m7-preserve-equality 3
:::

:::summary
- An equation is like a level pan balance: both sides have the same value.
- **Preservation of equality**: do the same operation to both sides, and the equation stays true.
- Add, subtract, multiply or divide the **whole** side, not just one part of it.
- Check a solution by substituting it into the original equation.
:::
