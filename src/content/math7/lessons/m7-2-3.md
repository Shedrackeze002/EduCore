Kai and Hana both work out $4.5 + 2.4 \times 3$. Kai gets $20.7$ and Hana gets $11.7$. They cannot both be right. Mathematicians agree on one order for the operations, so everyone gets the same answer. In this lesson you will use that order with decimals and write expressions to solve problems.

## The order of operations

:::definition Order of operations
The **order of operations** is the agreed order for doing the operations in an expression:
1. Do the operations inside **brackets** first.
2. **Multiply and divide** from left to right.
3. **Add and subtract** from left to right.
:::

:::example Multiply before you add
Evaluate $4.5 + 2.4 \times 3$.
@step Estimate: $5 + 2 \times 3 = 11$.
@step Multiply first: $2.4 \times 3 = 7.2$
@step Then add: $4.5 + 7.2 = 11.7$
@answer $4.5 + 2.4 \times 3 = 11.7$, so Hana is right.
:::

:::mistake Working from left to right
Kai added first: $4.5 + 2.4 = 6.9$, then $6.9 \times 3 = 20.7$. Multiplication comes before addition, unless brackets say otherwise.
:::

## Brackets

Brackets change the order. Whatever is inside them is done first.

:::example Brackets first
Evaluate $(6.2 - 1.7) \times 4$.
@step Estimate: $(6 - 2) \times 4 = 16$.
@step Brackets first: $6.2 - 1.7 = 4.5$
@step Then multiply: $4.5 \times 4 = 18$
@answer $(6.2 - 1.7) \times 4 = 18$
:::

:::example Three operations
Evaluate $12.6 - 2.4 \div 0.8 + 1.5$.
@step There are no brackets. Divide first: $2.4 \div 0.8 = 3$
@step Now add and subtract from left to right: $12.6 - 3 = 9.6$
@step $9.6 + 1.5 = 11.1$
@answer $12.6 - 2.4 \div 0.8 + 1.5 = 11.1$
:::

:::tip Rewrite after each step
Copy the expression again after each step, with the part you just did replaced by its value. It is easier to see what comes next, and easier to find a mistake.
:::

:::

## Writing an expression for a problem

For a problem with several steps, you can write one expression. Brackets keep the parts together.

:::example At the concession stand
Malik buys $3$ hot dogs at \$2.75 each and $2$ juices at \$1.50 each. He pays with a \$20 bill. How much change does he get?
@step Expression: $20 - (3 \times 2.75 + 2 \times 1.50)$
@step Estimate: $20 - (3 \times 3 + 2 \times 1.5) = 20 - 12 = 8$.
@step Inside the brackets, multiply first: $3 \times 2.75 = 8.25$ and $2 \times 1.50 = 3.00$
@step Add inside the brackets: $8.25 + 3.00 = 11.25$
@step Subtract: $20 - 11.25 = 8.75$
@answer Malik gets \$8.75 in change.
:::

:::example The mean of three jumps
Grace's long jumps are $3.45$ m, $3.6$ m and $3.21$ m. The mean is $(3.45 + 3.6 + 3.21) \div 3$. Find the mean jump.
@step Estimate: every jump is between $3$ and $4$, so the mean is too.
@step Brackets first: $3.45 + 3.60 + 3.21 = 10.26$
@step Then divide: $10.26 \div 3 = 3.42$
@answer The mean jump is $3.42$ m.
:::

:::mistake Forgetting the brackets
$3.45 + 3.6 + 3.21 \div 3$ is **not** the mean. Without brackets, only $3.21$ is divided by $3$. The brackets make you add all three jumps first.
:::

:::check m7-decimal-order-ops 3
:::

:::summary
- Brackets first, then multiply and divide from left to right, then add and subtract from left to right.
- Estimate first with rounded numbers, using the same order of operations.
- Rewrite the expression after each step.
- For a word problem, write one expression and use brackets to keep parts together.
:::
