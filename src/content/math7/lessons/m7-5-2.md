Tickets for a school concert cost \$5 each, plus a \$10 booking fee for each order. How much do $4$ tickets cost? How many tickets can you get for \$40? A table of values and a graph answer questions like these at a glance.

## Making a table of values

:::definition Table of values
A **table of values** shows matching values of the two variables in a relation. You find each output by substituting an input into the relation.
:::

:::example A table from a relation
Make a table of values for $y = 2x + 4$ for $x = 0$ to $4$.
@step $x = 0$: $y = 2(0) + 4 = 4$
@step $x = 1$: $y = 2(1) + 4 = 6$
@step $x = 2$: $y = 2(2) + 4 = 8$
@step $x = 3$: $y = 2(3) + 4 = 10$, and $x = 4$: $y = 2(4) + 4 = 12$
@answer The $y$ values are $4, 6, 8, 10, 12$.
:::

:::figure

:::

:::example Concert tickets
The cost of an order of $n$ tickets is $C = 5n + 10$ dollars. Find the cost of $1$, $2$, $3$ and $4$ tickets.
@step $n = 1$: $C = 5(1) + 10 = 15$
@step $n = 2$: $C = 5(2) + 10 = 20$
@step $n = 3$: $C = 5(3) + 10 = 25$
@step $n = 4$: $C = 5(4) + 10 = 30$
@answer The costs are \$15, \$20, \$25 and \$30.
:::

:::

## Working backwards in a table

Sometimes the output is known and the input is missing. Work backwards: undo the steps in the reverse order.

:::example How many tickets?
An order costs \$45. Use $C = 5n + 10$ to find how many tickets are in the order.
@step Undo the adding: $45 - 10 = 35$.
@step Undo the multiplying: $35 \div 5 = 7$.
@step Check: $5(7) + 10 = 35 + 10 = 45$. It works.
@answer The order has $7$ tickets.
:::

:::mistake Undoing in the wrong order
Do not divide first: $45 \div 5 = 9$ and $9 - 10$ does not make sense here. The relation multiplies first, so you subtract first when you work backwards.
:::

:::check m7-table-of-values 3
:::

## Graphing a table of values

:::definition Ordered pair
Each column of a table of values gives an **ordered pair** $(x, y)$. To plot it, go across to $x$ on the horizontal axis, then up to $y$.
:::

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":6,"yMin":0,"yMax":16,"xStep":1,"yStep":2,"xLabel":"x","yLabel":"y"},"points":[{"x":0,"y":4,"label":"(0, 4)"},{"x":1,"y":6,"label":"(1, 6)"},{"x":2,"y":8,"label":"(2, 8)"},{"x":3,"y":10,"label":"(3, 10)"},{"x":4,"y":12,"label":"(4, 12)"},{"x":5,"y":14,"label":"(5, 14)"}]}

The graph shows $y = 2x + 4$. The points lie in a straight line, which is why the relation is called linear. Each time you move $1$ to the right, the graph goes up $2$. The first point, $(0, 4)$, is on the vertical axis.

## Reading a graph to solve problems

The graph shows the cost of concert tickets, $C = 5n + 10$.

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":7,"yMin":0,"yMax":45,"xStep":1,"yStep":5,"xLabel":"Number of tickets","yLabel":"Cost ($)"},"points":[{"x":1,"y":15},{"x":2,"y":20},{"x":3,"y":25},{"x":4,"y":30},{"x":5,"y":35},{"x":6,"y":40}]}
:::

:::example Reading the graph both ways
(a) What do $4$ tickets cost? (b) How many tickets cost \$40?
@step (a) Find $4$ on the horizontal axis. Go up to the point, then across to the vertical axis: $30$.
@step (b) Find $40$ on the vertical axis. Go across to the point, then down to the horizontal axis: $6$.
@answer (a) $4$ tickets cost \$30. (b) $6$ tickets cost \$40.
:::

:::example The fee and the price
Use the graph to find the price of each ticket and the booking fee.
@step From one point to the next, the cost goes up \$5. Each ticket costs \$5.
@step The first point is $(1, 15)$. Go back one step: $15 - 5 = 10$. The booking fee is \$10.
@answer Each ticket costs \$5 and the fee is \$10, which matches $C = 5n + 10$.
:::

:::mistake Reading the wrong axis
To find the cost of $4$ tickets, start at $4$ on the **horizontal** axis (tickets), not at $4$ on the vertical axis (dollars).
:::

:::summary
- A table of values lists matching inputs and outputs. Substitute each input into the relation.
- To find a missing input, work backwards: undo the steps in the reverse order.
- Plot each column of the table as an ordered pair. The points of a linear relation lie in a straight line.
- Read a graph up from the horizontal axis to find an output, or across from the vertical axis to find an input.
- The rise from one point to the next is the change for each step. The value at $0$ is the start.
:::
