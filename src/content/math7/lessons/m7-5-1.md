Kateri builds squares in a row with toothpicks. How many toothpicks does she need for $50$ squares? Counting them one by one would take a long time. An expression for the pattern gives the answer in one step.

## Patterns and terms

:::definition Term and term number
Each number in a pattern is called a **term**. The **term number** tells where the term is in the pattern: term $1$ is first, term $2$ is second, and so on.
:::

## Writing an expression for the nth term

:::definition Variable
A **variable** is a letter, such as $n$, that stands for a number that can change. Here $n$ stands for the figure number.
:::

To write an expression for the $n$th term:
1. Find how much the terms go up each time. That number multiplies $n$.
2. Compare with term $1$ and add or subtract to fix the start.
3. Check with another term.

:::example Toothpick squares
Write an expression for the number of toothpicks in Figure $n$.
@step The terms go up by $3$ each time, so the expression starts with $3n$.
@step When $n = 1$, $3n = 3$, but Figure 1 has $4$ toothpicks. Add $1$.
@step Check with $n = 4$: $3(4) + 1 = 13$. It matches the table.
@answer Figure $n$ uses $3n + 1$ toothpicks.
:::

:::mistake Writing n + 3
The change ($3$) goes **in front of** $n$. The expression $n + 3$ gives $4, 5, 6, \ldots$, which goes up by only $1$ each time.
:::

:::check m7-pattern-rule 1
:::

:::example A pattern that starts low
The terms of a pattern are $3, 8, 13, 18, \ldots$ Write an expression for the $n$th term.
@step The terms go up by $5$, so the expression starts with $5n$.
@step When $n = 1$, $5n = 5$, but the first term is $3$. Subtract $2$.
@step Check with $n = 3$: $5(3) - 2 = 13$. It matches.
@answer The $n$th term is $5n - 2$.
:::

:::check m7-pattern-rule 2
:::

## Linear relations

:::definition Linear relation
A **linear relation** connects two quantities so that one goes up (or down) by the same amount each time the other goes up by $1$. The toothpick pattern is a linear relation: $t = 3n + 1$, where $t$ is the number of toothpicks.
:::

:::example Chairs around tables
Square tables are pushed together in a row, with one chair at each open side. Write an expression for the number of chairs around $n$ tables.
@step Count from the picture: $1$ table has $4$ chairs, $2$ tables have $6$ and $3$ tables have $8$.
@step The number goes up by $2$ each time: one chair on each long side. The expression starts with $2n$.
@step When $n = 1$, $2n = 2$, but there are $4$ chairs. Add $2$, one for each end of the row.
@answer The number of chairs is $2n + 2$.
:::

:::check m7-pattern-rule 3
:::

## Using a relation

Once you have the relation, you can find any term without drawing it.

:::example Figure 50
How many toothpicks are in Figure 50?
@step Replace $n$ with $50$ in $3n + 1$: $3(50) + 1 = 150 + 1 = 151$.
@answer Figure 50 uses $151$ toothpicks.
:::

:::check m7-pattern-term 1
:::

You can also work backwards to find which term has a certain value. Undo the steps in the reverse order.

:::example Which figure?
Which figure uses $64$ toothpicks?
@step You need $3n + 1 = 64$. Undo the adding: $64 - 1 = 63$.
@step Undo the multiplying: $63 \div 3 = 21$.
@step Check: $3(21) + 1 = 63 + 1 = 64$. It works.
@answer Figure 21 uses $64$ toothpicks.
:::

:::tip Undo in reverse order
The expression $3n + 1$ multiplies first and adds last. To work backwards, subtract first and divide last.
:::

:::check m7-pattern-term 2
:::

:::check m7-pattern-term 3
:::

:::summary
- A pattern is made of terms. The term number $n$ tells the position of a term.
- To write an expression: the change each time multiplies $n$, then add or subtract to match term $1$. Check with another term.
- A linear relation goes up or down by the same amount each time.
- Substitute a term number to find a term. Work backwards (undo in reverse order) to find a term number.
:::
