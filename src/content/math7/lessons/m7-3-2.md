A bread recipe uses $2\dfrac{1}{4}$ cups of white flour and $1\dfrac{2}{3}$ cups of whole wheat flour. A hiking trail is $6\dfrac{1}{2}$ km long, and you have walked $2\dfrac{3}{4}$ km. Amounts like these are mixed numbers, and you can add and subtract them.

## Mixed numbers and improper fractions

:::definition Mixed number
A **mixed number** has a whole number part and a fraction part, like $2\dfrac{1}{4}$. It means $2 + \dfrac{1}{4}$.
:::

:::definition Improper fraction
An **improper fraction** has a numerator that is greater than or equal to its denominator, like $\dfrac{9}{4}$. It is worth $1$ or more.
:::

The number line is cut into quarters. The point is $9$ quarters from $0$, so $2\dfrac{1}{4} = \dfrac{9}{4}$.

:::example Changing between the two forms
Write $2\dfrac{1}{4}$ as an improper fraction, and write $\dfrac{11}{4}$ as a mixed number.
@step Each whole is $\dfrac{4}{4}$, so $2$ wholes are $\dfrac{8}{4}$. Then $\dfrac{8}{4} + \dfrac{1}{4} = \dfrac{9}{4}$.
@step $11 \div 4 = 2$ remainder $3$, so $\dfrac{11}{4}$ is $2$ wholes and $3$ quarters.
@answer $2\dfrac{1}{4} = \dfrac{9}{4}$ and $\dfrac{11}{4} = 2\dfrac{3}{4}$
:::

## Adding mixed numbers

Add the whole numbers. Add the fractions, using a common denominator. If the fractions add to $1$ or more, carry $1$ whole.

:::example Flour for bread
A recipe uses $2\dfrac{1}{4}$ cups of white flour and $1\dfrac{2}{3}$ cups of whole wheat flour. How much flour is that?
@step Common denominator $12$: $2\dfrac{1}{4} = 2\dfrac{3}{12}$ and $1\dfrac{2}{3} = 1\dfrac{8}{12}$.
@step Whole numbers: $2 + 1 = 3$. Fractions: $\dfrac{3}{12} + \dfrac{8}{12} = \dfrac{11}{12}$.
@answer The recipe uses $3\dfrac{11}{12}$ cups of flour.
:::

:::example Carrying a whole
Find $3\dfrac{3}{4} + 2\dfrac{1}{2}$.
@step Common denominator $4$: $2\dfrac{1}{2} = 2\dfrac{2}{4}$.
@step Whole numbers: $3 + 2 = 5$. Fractions: $\dfrac{3}{4} + \dfrac{2}{4} = \dfrac{5}{4} = 1\dfrac{1}{4}$.
@step Carry the $1$: $5 + 1\dfrac{1}{4} = 6\dfrac{1}{4}$.
@answer $3\dfrac{3}{4} + 2\dfrac{1}{2} = 6\dfrac{1}{4}$
:::

:::mistake Stopping at 5 5/4
$5\dfrac{5}{4}$ is not finished. In a mixed number, the fraction part must be less than $1$. Carry the extra whole to get $6\dfrac{1}{4}$.
:::

## Subtracting mixed numbers

Subtract the whole numbers and subtract the fractions. Sometimes the first fraction is smaller than the one you take away. Then you **regroup**: take $1$ whole from the whole number and add it to the fraction.

:::example No regrouping
Find $5\dfrac{5}{6} - 2\dfrac{1}{3}$.
@step Common denominator $6$: $2\dfrac{1}{3} = 2\dfrac{2}{6}$.
@step Whole numbers: $5 - 2 = 3$. Fractions: $\dfrac{5}{6} - \dfrac{2}{6} = \dfrac{3}{6} = \dfrac{1}{2}$.
@answer $5\dfrac{5}{6} - 2\dfrac{1}{3} = 3\dfrac{1}{2}$
:::

:::example Regrouping
Find $5\dfrac{1}{4} - 2\dfrac{3}{4}$.
@step You cannot take $\dfrac{3}{4}$ from $\dfrac{1}{4}$. Regroup $1$ whole as $\dfrac{4}{4}$: $5\dfrac{1}{4} = 4 + \dfrac{4}{4} + \dfrac{1}{4} = 4\dfrac{5}{4}$.
@step Whole numbers: $4 - 2 = 2$. Fractions: $\dfrac{5}{4} - \dfrac{3}{4} = \dfrac{2}{4} = \dfrac{1}{2}$.
@answer $5\dfrac{1}{4} - 2\dfrac{3}{4} = 2\dfrac{1}{2}$
:::

:::mistake Subtracting the fractions backwards
Do **not** take the smaller fraction away from the bigger one. Working out $\dfrac{3}{4} - \dfrac{1}{4}$ instead gives a wrong answer:

$$5\dfrac{1}{4} - 2\dfrac{3}{4} \ne 3\dfrac{1}{2}$$

Regroup first. The correct answer is $2\dfrac{1}{2}$.
:::

:::

## Harder regrouping

To subtract from a whole number, write it as a mixed number first: $6 = 5\dfrac{8}{8}$.

:::example Subtracting from a whole number
Find $6 - 3\dfrac{7}{8}$.
@step Regroup: $6 = 5\dfrac{8}{8}$.
@step Whole numbers: $5 - 3 = 2$. Fractions: $\dfrac{8}{8} - \dfrac{7}{8} = \dfrac{1}{8}$.
@answer $6 - 3\dfrac{7}{8} = 2\dfrac{1}{8}$
:::

:::example Unlike denominators and regrouping
Find $4\dfrac{1}{6} - 1\dfrac{3}{4}$.
@step Common denominator $12$: $4\dfrac{1}{6} = 4\dfrac{2}{12}$ and $1\dfrac{3}{4} = 1\dfrac{9}{12}$.
@step $\dfrac{2}{12}$ is less than $\dfrac{9}{12}$, so regroup: $4\dfrac{2}{12} = 3\dfrac{14}{12}$.
@step Whole numbers: $3 - 1 = 2$. Fractions: $\dfrac{14}{12} - \dfrac{9}{12} = \dfrac{5}{12}$.
@answer $4\dfrac{1}{6} - 1\dfrac{3}{4} = 2\dfrac{5}{12}$
:::

:::tip Another way: improper fractions
You can also change both mixed numbers to improper fractions: $5\dfrac{1}{4} - 2\dfrac{3}{4} = \dfrac{21}{4} - \dfrac{11}{4} = \dfrac{10}{4} = 2\dfrac{1}{2}$. Use whichever way you find easier.
:::

:::check m7-mixed-add-sub 3
:::

:::summary
- A mixed number has a whole part and a fraction part. An improper fraction is worth $1$ or more.
- To add or subtract mixed numbers, work with the whole numbers and the fractions separately, using a common denominator.
- When adding, carry $1$ whole if the fractions add to $1$ or more.
- When subtracting, regroup $1$ whole if the first fraction is too small.
- Write the answer as a mixed number in lowest terms.
:::
