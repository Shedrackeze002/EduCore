A bowling alley charges \$4 for shoes and \$6 for each game. How much do 3 games cost? What about 10 games? One short **expression** can answer every one of these questions at once.

## Variables and expressions

In algebra, a letter can stand for a number we do not know yet, or for a number that can change.

:::definition Variable
A **variable** is a letter, such as $n$ or $x$, that stands for a number.
:::

:::definition Expression
An **expression** is a group of numbers, variables and operations, such as $6g + 4$ or $\dfrac{n}{2}$. An expression does **not** have an equals sign.
:::

When a number is written right next to a variable, it means multiply. So $6g$ means $6 \times g$, and $3n$ means $3 \times n$.

The bowling cost is $6g + 4$, where $g$ is the number of games: \$6 for each game, plus \$4 for shoes.

## Expressions and equations

An **equation** makes a statement: it says that two things are equal.

:::definition Equation
An **equation** says that two expressions have the same value, such as $6g + 4 = 22$. It always has an equals sign.
:::

| Expressions (no equals sign) | Equations (equals sign) |
|---|---|
| $6g + 4$ | $6g + 4 = 22$ |
| $3n$ | $3n = 15$ |
| $8 + 5$ | $8 + 5 = 13$ |

:::mistake A variable does not make an equation
$5x + 2$ has a variable, but it is still an expression, because it has no equals sign. And $8 + 5 = 13$ has no variable, but it is an equation. Only the equals sign decides.
:::

## The parts of an expression

:::definition Coefficient and constant term
In $6g + 4$, the number $6$ multiplies the variable, so it is the **coefficient**. The number $4$ has no variable, so it is the **constant term**. It stays the same no matter what $g$ is.
:::

:::example Name the parts
A phone plan costs \$25 a month plus \$10 for each GB of data. The bill is $10d + 25$. Name the variable, the coefficient and the constant term, and say what each one means.
@step The variable is $d$: the number of GB of data used.
@step The coefficient is $10$: the cost of each GB.
@step The constant term is $25$: the monthly cost before any data is used.
@answer Variable $d$, coefficient $10$, constant term $25$.
:::

:::tip Amount for each one
In a story, the coefficient is usually an amount **for each** one (each game, each GB, each week). The constant term is an amount that is added **once**.
:::

## Evaluating expressions

To **evaluate** an expression, replace each variable with its value, then calculate. Use the order of operations: brackets first, then multiply and divide, then add and subtract.

:::example One variable
Evaluate $3n + 5$ when $n = 4$.
@step Replace $n$ with $4$: $3 \times 4 + 5$
@step Multiply first: $12 + 5$
@step Then add: $17$
@answer The value is $17$.
:::

:::example Brackets
Evaluate $2(x + 3)$ when $x = 6$.
@step Replace $x$ with $6$: $2(6 + 3)$
@step Brackets first: $2 \times 9$
@step Multiply: $18$
@answer The value is $18$.
:::

:::mistake 3n is not thirty-something
When $n = 4$, $3n$ is $3 \times 4 = 12$, not $34$. Write the multiplication sign when you substitute: $3 \times 4$.
:::

:::example Two variables in a formula
In basketball, $P = 2t + 3h + f$ gives a player’s points: $t$ two-point baskets, $h$ three-point baskets and $f$ free throws. Kwame made 6 two-point baskets, 2 three-point baskets and 3 free throws. How many points did he score?
@step Substitute: $P = 2(6) + 3(2) + 3$
@step Multiply first: $P = 12 + 6 + 3$
@step Add: $P = 21$
@answer Kwame scored $21$ points.
:::

:::check m7-evaluate-expression 3
:::

:::summary
- A **variable** is a letter that stands for a number. $6g$ means $6 \times g$.
- An **expression** has no equals sign. An **equation** has an equals sign.
- In $6g + 4$, the **coefficient** is $6$ and the **constant term** is $4$.
- To evaluate an expression, substitute the values, then follow the order of operations.
:::
