In a video game, a character slides across the screen. On a game board, a piece moves three squares right and two up. Each of these is a translation: a slide that moves every point the same distance in the same direction.

## Transformations and images

:::definition Transformation and image
A **transformation** moves a shape to a new position. The shape after the move is the **image**. The image of point $A$ is named $A'$, said "A prime".
:::

:::definition Translation
A **translation** is a slide. Every point of the shape moves the same distance in the same direction. The image has the same size, shape and direction as the original.
:::

On a Cartesian plane, describe a translation with two moves: how far right or left, and how far up or down.

- Right adds to $x$. Left subtracts from $x$.
- Up adds to $y$. Down subtracts from $y$.

:::example Sliding a game piece
A game piece is at $P(-2, 3)$. It moves $5$ units right and $4$ units down. Where is its image $P'$?
@step Right $5$: $x = -2 + 5 = 3$
@step Down $4$: $y = 3 - 4 = -1$
@answer $P'(3, -1)$
:::

:::mistake Which number changes?
A move left or right changes only $x$. A move up or down changes only $y$. Do not add the left-right move to $y$.
:::

## Translating a shape

To translate a shape, translate **each vertex** the same way. Then join the image vertices in the same order.

:::example Translating a triangle
Triangle $ABC$ has $A(-4, 1)$, $B(-1, 1)$ and $C(-3, 4)$. Translate it $5$ units right and $3$ units down.
@step $A'$: $(-4 + 5,\ 1 - 3) = (1, -2)$
@step $B'$: $(-1 + 5,\ 1 - 3) = (4, -2)$
@step $C'$: $(-3 + 5,\ 4 - 3) = (2, 1)$
@answer $A'(1, -2)$, $B'(4, -2)$ and $C'(2, 1)$. The image is the same size and shape and faces the same way.
:::

## Describing a translation

To describe a translation, follow **one** vertex to its image. Subtract: new $x$ − old $x$ gives the move across, and new $y$ − old $y$ gives the move up or down.

:::figure

:::

:::example What was the slide?
Triangle $DEF$ was translated to $D'E'F'$. Describe the translation.
@step $D(1, 2)$ moved to $D'(-5, -1)$.
@step Across: $-5 - 1 = -6$, so $6$ units left.
@step Up or down: $-1 - 2 = -3$, so $3$ units down.
@answer The translation is $6$ units left and $3$ units down.
:::

With the signs, $6$ units left and $3$ units down is written as a horizontal move of $-6$ and a vertical move of $-3$.

:::tip Two slides in a row
Two translations make one translation. Add the horizontal moves and add the vertical moves. For example, $4$ left and $2$ up, then $1$ right and $5$ down: $-4 + 1 = -3$ and $2 + (-5) = -3$, so $3$ units left and $3$ units down.
:::

:::mistake Going the wrong way
Describe the move **from** the original **to** the image. Going from the image back to the original gives the opposite directions.
:::

:::summary
- A translation slides every point the same distance in the same direction.
- The image of $A$ is $A'$. The image has the same size, shape and direction.
- Right/left changes $x$. Up/down changes $y$.
- Translate a shape one vertex at a time.
- To describe a translation, follow one vertex: new − old gives each move.
:::
