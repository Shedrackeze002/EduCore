A recipe calls for $\frac{3}{8}$ of a cup of milk, and a calculator shows $3 \div 8 = 0.375$. Try $1 \div 3$ and the calculator fills the screen with $3$s. In this lesson you will see why some fractions make decimals that stop and others make decimals that go on forever, and how to change between the two forms.

## Fractions are divisions

The fraction bar means "divided by". So $\frac{3}{8}$ means $3 \div 8$.

:::definition Terminating decimal
A **terminating decimal** stops after a certain number of digits, like $0.375$ or $2.75$.
:::

There are two ways to change a fraction to a decimal.

1. If the denominator is a factor of $10$, $100$ or $1000$, make an equivalent fraction with that denominator.
2. Otherwise, divide the numerator by the denominator.

:::example An equivalent fraction
Write $\frac{3}{8}$ as a decimal.
@step $8 \times 125 = 1000$, so multiply the numerator and the denominator by $125$: $\frac{3}{8} = \frac{375}{1000}$.
@step $\frac{375}{1000}$ is $375$ thousandths.
@answer $\frac{3}{8} = 0.375$
:::

:::example A mixed number
Write $2\frac{3}{4}$ as a decimal.
@step $\frac{3}{4} = \frac{75}{100} = 0.75$
@step Add the whole number: $2 + 0.75 = 2.75$
@answer $2\frac{3}{4} = 2.75$
:::

## Repeating decimals

Divide $5 \div 11$. The remainders come back again and again, so the digits do too: $0.454545\ldots$

:::definition Repeating decimal
A **repeating decimal** has a digit or a block of digits that repeats forever, like $0.454545\ldots$
:::

:::definition Bar notation
**Bar notation** puts a bar over the digits that repeat: $0.454545\ldots = 0.\overline{45}$. Only the repeating digits go under the bar.
:::

:::example A repeat that starts later
Write $\frac{1}{6}$ as a decimal.
@step Divide: $1 \div 6 = 0.16666\ldots$
@step The $1$ comes once. Then the $6$ repeats forever.
@answer $\frac{1}{6} = 0.1\overline{6}$
:::

:::mistake Too much under the bar
$0.\overline{16}$ means $0.161616\ldots$, which is a different number. For $\frac{1}{6}$, only the $6$ repeats, so write $0.1\overline{6}$.
:::

You cannot type a bar into an answer box, so some questions ask you to round instead. $\frac{5}{11} = 0.4545\ldots$ The ten-thousandths digit is $5$, so round up: $\frac{5}{11} \approx 0.455$ to the nearest thousandth.

These patterns are worth knowing.

## Which fractions terminate?

You can tell before you divide. Write the fraction in lowest terms, then look at the prime factors of the denominator.

- Only $2$s and $5$s: the decimal **terminates**.
- Any other prime factor (like $3$, $7$ or $11$): the decimal **repeats**.

This works because $10 = 2 \times 5$. A denominator made of $2$s and $5$s can always be grown into $10$, $100$ or $1000$.

:::example Terminate or repeat?
Which of $\frac{7}{20}$, $\frac{5}{12}$ and $\frac{9}{12}$ are terminating decimals?
@step $\frac{7}{20}$: $20 = 2 \times 2 \times 5$. Only $2$s and $5$s, so it terminates: $0.35$.
@step $\frac{5}{12}$: $12 = 2 \times 2 \times 3$. There is a $3$, so it repeats: $0.41\overline{6}$.
@step $\frac{9}{12}$: first simplify to $\frac{3}{4}$. $4 = 2 \times 2$, so it terminates: $0.75$.
@answer $\frac{7}{20}$ and $\frac{9}{12}$ terminate. $\frac{5}{12}$ repeats.
:::

:::tip Simplify first
$\frac{9}{12}$ has a $3$ in its denominator, but it still terminates. Always write the fraction in lowest terms before you look at the denominator.
:::

## Decimals to fractions

For a **terminating decimal**, the place value of the last digit gives the denominator. Then simplify.

:::example Hundredths and thousandths
Write $0.45$ and $0.125$ as fractions in lowest terms.
@step $0.45$ is $45$ hundredths: $\frac{45}{100}$. Divide both by $5$: $\frac{9}{20}$.
@step $0.125$ is $125$ thousandths: $\frac{125}{1000}$. Divide both by $125$: $\frac{1}{8}$.
@answer $0.45 = \frac{9}{20}$ and $0.125 = \frac{1}{8}$
:::

:::check m7-decimal-to-fraction 1
:::

For a **repeating decimal**, use the patterns from the ninths and the ninety-ninths. $\frac{1}{9} = 0.\overline{1}$, so $\frac{4}{9} = 0.\overline{4}$. And $\frac{1}{99} = 0.\overline{01}$, so $\frac{36}{99} = 0.\overline{36}$.

$$0.\overline{a} = \dfrac{a}{9} \qquad 0.\overline{ab} = \dfrac{ab}{99}$$

:::example Repeating decimals as fractions
Write $0.\overline{6}$ and $0.\overline{36}$ as fractions in lowest terms.
@step $0.\overline{6} = \frac{6}{9}$. Divide both by $3$: $\frac{2}{3}$.
@step $0.\overline{36} = \frac{36}{99}$. Divide both by $9$: $\frac{4}{11}$.
@step Check: $4 \div 11 = 0.3636\ldots$
@answer $0.\overline{6} = \frac{2}{3}$ and $0.\overline{36} = \frac{4}{11}$
:::

:::mistake Using 100 for a repeating decimal
$0.\overline{36}$ is **not** $\frac{36}{100}$. That fraction is $0.36$, which stops. A two-digit repeat goes over $99$.
:::

:::summary
- A fraction is a division: $\frac{3}{8} = 3 \div 8 = 0.375$.
- A terminating decimal stops. A repeating decimal goes on forever; a bar marks the repeating digits, as in $0.1\overline{6}$.
- In lowest terms, a fraction terminates when its denominator has no prime factors other than $2$ and $5$.
- Terminating decimal to fraction: use place value, then simplify.
- Repeating decimal to fraction: $0.\overline{a} = \frac{a}{9}$ and $0.\overline{ab} = \frac{ab}{99}$, then simplify.
:::
