Patterns are everywhere at work. A banquet hall needs to know how many tables to set up for 30 guests. A taxi meter goes up by the same amount every kilometre. If you can spot the pattern, you can predict what comes next without counting every time.

## What is a pattern?

:::definition Pattern and term
A **pattern** is a list of numbers or shapes that follows a rule. Each number in the pattern is called a **term**.
:::

Square tables are pushed together in a row for a community supper. One chair goes on each open side.

A **table of values** lists the terms of a pattern in order, so you can see how they change.
:::

:::example How many people at 5 tables?
Use the table above.
@step Find the change from one term to the next: $6 - 4 = 2$, $8 - 6 = 2$, $10 - 8 = 2$.
@step Each new table adds $2$ people, one on each long side.
@step 5 tables: $10 + 2 = 12$
@answer A row of $5$ tables seats $12$ people.
:::

## Adding patterns and doubling patterns

Most patterns at work **add the same amount** each time. Some patterns **double**: each term is two times the one before.

:::example Saving for a bike
Ava saves part of her pay from a coffee shop. Her total is \$35 after week 1, \$60 after week 2, \$85 after week 3 and \$110 after week 4. How much will she have after week 6?
@step Change: $60 - 35 = 25$, $85 - 60 = 25$, $110 - 85 = 25$. She adds \$25 each week.
@step Week 5: $110 + 25 = 135$
@step Week 6: $135 + 25 = 160$
@answer Ava will have \$160 after week 6.
:::

:::example Views on a video
A bakery posts a video. It has $20$ views after day 1, $40$ after day 2, $80$ after day 3 and $160$ after day 4. How many views after day 6?
@step The jumps are $20$, $40$, $80$. They are not the same, so this is not an adding pattern.
@step Each term is double the one before: $20 \times 2 = 40$, $40 \times 2 = 80$.
@step Day 5: $160 \times 2 = 320$. Day 6: $320 \times 2 = 640$.
@answer The video will have $640$ views after day 6.
:::

:::mistake Always adding
Check the jumps before you extend a pattern. If the jumps get bigger each time, the pattern might be doubling. Adding $80$ to $160$ would give $240$, which is wrong.
:::

:::

## Working toward a goal

Sometimes you know the goal and need to find **when** you will reach it.

:::example When will Ava have \$260?
Ava has \$110 after week 4 and adds \$25 each week. In which week will her savings reach \$260?
@step How much more does she need? $260 - 110 = 150$
@step How many more weeks? $150 \div 25 = 6$
@step $4 + 6 = 10$
@step Check: $110 + 6 \times 25 = 110 + 150 = 260$
@answer Ava will reach \$260 in week 10.
:::

:::check m104-pattern-extend 3
:::

## Writing a rule

:::definition Rule
A **rule** tells you how to find any term in a pattern. You can write it in words, or with letters.
:::

In words, the pattern $5, 8, 11, 14, \ldots$ has the rule "start at $5$ and add $3$ each time."

:::check m104-pattern-rule 1
:::

A rule with letters lets you jump straight to any term. Here $n$ is the term number and $y$ is the term.

:::figure
{"type":"table","horizontal":true,"headers":["$n$","$y$"],"rows":[["1","5"],["2","8"],["3","11"],["4","14"],["5","17"]]}
:::

:::example Find the rule
Write a rule for $y$ using $n$.
@step Each time $n$ goes up by $1$, $y$ goes up by $3$. So the rule starts with $3n$, which means $3 \times n$.
@step When $n = 1$: $3 \times 1 = 3$. The table shows $5$, so add $2$.
@step The rule is $y = 3n + 2$.
@step Check with $n = 4$: $3 \times 4 + 2 = 14$. It matches.
@answer $y = 3n + 2$
:::

:::mistake Adding the change instead of multiplying
The change ($3$) goes **in front of** $n$. The rule $y = n + 3$ gives $4, 5, 6, \ldots$, which does not match the table.
:::

:::tip Use the rule for big jumps
For the tables and chairs, the rule is $p = 2t + 2$. For $20$ tables: $p = 2 \times 20 + 2 = 42$ people. No need to count every table!
:::

:::check m104-pattern-rule 2
:::

:::check m104-pattern-rule 3
:::

:::summary
- A pattern follows a rule. Each number in it is a term.
- Find the change from one term to the next. If it is the same, keep adding it.
- If each term is double the one before, keep multiplying by $2$.
- To reach a goal, find how much more you need, then divide by the change.
- A rule like $y = 3n + 2$ comes from the change ($3$) and a start-up amount ($2$). Always check it with the table.
:::
