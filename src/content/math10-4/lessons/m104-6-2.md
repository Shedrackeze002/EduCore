Carpenters, plumbers, warehouse workers and hairstylists all measure things. A cut that is a few millimetres off can waste a whole board. In this lesson you will read metric and imperial rulers carefully.

## Reading a metric ruler

A metric ruler shows centimetres. Each centimetre is split into $10$ small spaces.

:::definition Millimetre
A **millimetre** (mm) is one of the $10$ small spaces in a centimetre. $10\ \text{mm} = 1\ \text{cm}$. A dime is about $1\ \text{mm}$ thick.
:::

:::figure
{"type":"ruler","system":"metric","length":10,"start":0,"end":4.7}
:::

:::example Reading to the millimetre
How long is the bar on the ruler above?
@step The bar starts at $0$.
@step The right end is past the $4$ cm mark. Count the small marks after $4$: there are $7$.
@step So the bar is $4$ cm and $7$ mm, which is $4.7\ \text{cm}$.
@answer The bar is $4.7\ \text{cm}$, or $47\ \text{mm}$, long.
:::

The middle mark in each centimetre is a little longer. It shows $5\ \text{mm}$, so you do not have to count from the start every time.

:::mistake Starting at the end of the ruler
Most rulers have a little space before the $0$ mark. Always line up the object with **$0$**, not with the end of the ruler.
:::

## Reading an imperial ruler

Many tools in Canada still use **inches**. Lumber, pipe and tape measures often show inches.

:::definition Inch
An **inch** (in) is an imperial unit of length. $1\ \text{in}$ is about $2.5\ \text{cm}$. A **tape measure** is a long ruler that rolls up. Most show both inches and centimetres.
:::

An inch is split into equal parts. The longer the mark, the bigger the fraction:

:::figure
{"type":"table","headers":["Mark","Meaning"],"rows":[["Longest","whole inch"],["Next longest","half inch (1/2)"],["Medium","quarter inch (1/4)"],["Short","eighth of an inch (1/8)"],["Shortest","sixteenth of an inch (1/16)"]]}
:::

:::figure
{"type":"ruler","system":"imperial","length":4,"start":0,"end":2.625,"division":8}
:::

:::example Reading to the eighth of an inch
On this ruler each inch has $8$ spaces. How long is the bar?
@step The bar starts at $0$ and ends past the $2$-inch mark.
@step Count the spaces after $2$: there are $5$. Each space is $\tfrac{1}{8}$ in.
@answer The bar is $2\tfrac{5}{8}$ in long. You can type it as 2 5/8.
:::

:::example Reading to the sixteenth of an inch
A bolt ends $4$ spaces past the $1$-inch mark on a ruler with $16$ spaces in each inch. How long is it?
@step The bolt is $1\tfrac{4}{16}$ in long.
@step Simplify: $\tfrac{4}{16} = \tfrac{1}{4}$, because $4 \div 4 = 1$ and $16 \div 4 = 4$.
@answer The bolt is $1\tfrac{1}{4}$ in long.
:::

:::mistake Using the wrong fraction
Check how many spaces are in one inch before you write the fraction. On a ruler with $16$ spaces in each inch, $5$ spaces past $2$ is $2\tfrac{5}{16}$ in, not $2\tfrac{5}{8}$ in.
:::

## When the object does not start at zero

Sometimes the end of a tape is bent, or the object sits in the middle of the ruler. Then read **both** ends and subtract.

$$\text{length} = \text{end} - \text{start}$$

:::figure
{"type":"ruler","system":"metric","length":12,"start":2,"end":6.3}
:::

:::example Subtracting the start
The bar above starts at $2\ \text{cm}$ and ends at $6.3\ \text{cm}$. How long is it?
@step Read the start: $2\ \text{cm}$. Read the end: $6.3\ \text{cm}$.
@step $6.3 - 2 = 4.3$
@answer The bar is $4.3\ \text{cm}$, or $43\ \text{mm}$, long.
:::

:::mistake Reading only the end
The bar above ends at $6.3\ \text{cm}$, but it is **not** $6.3\ \text{cm}$ long. It starts at $2$, so you must subtract.
:::

:::tip Starting at 1 inch
Carpenters sometimes start a measurement at the $1$-inch mark, because the hook on the end of a tape can wobble. Just remember to take away that $1$ inch at the end.
:::

## Measuring to cut

To cut something to size, compare the length you have with the length you need. Use the same unit for both.

:::example How much to cut off
A piece of trim measures $3\tfrac{7}{8}$ in. It needs to be $3\tfrac{1}{2}$ in. How much should be cut off?
@step Write both lengths in eighths: $3\tfrac{7}{8} = \tfrac{31}{8}$ and $3\tfrac{1}{2} = 3\tfrac{4}{8} = \tfrac{28}{8}$.
@step $\tfrac{31}{8} - \tfrac{28}{8} = \tfrac{3}{8}$
@answer Cut off $\tfrac{3}{8}$ in.
:::

:::mistake Subtracting different fractions
$\tfrac{7}{8} - \tfrac{1}{2}$ is **not** $\tfrac{6}{6}$. Change $\tfrac{1}{2}$ to $\tfrac{4}{8}$ first, so both fractions count eighths.
:::

:::check m104-read-ruler 3
:::

:::summary
- On a metric ruler, each small space is $1\ \text{mm}$, and $10\ \text{mm} = 1\ \text{cm}$.
- On an imperial ruler, count the spaces after the last whole inch. Each space is $\tfrac{1}{8}$ or $\tfrac{1}{16}$ in. Simplify the fraction if you can.
- Line the object up with $0$. If it does not start at $0$, use length $=$ end $-$ start.
- To cut to size, write both lengths in the same unit and subtract.
:::
