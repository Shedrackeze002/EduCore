Calculus is the study of change, and its raw material is functions. Before we can measure how fast a function changes, we need two tools: building new functions out of old ones (composition), and the **difference quotient**, the expression that will become the derivative in Unit 3.

## Composite functions

Two functions can be applied one after the other. If $g$ acts first and $f$ acts on the result, the combined function is the composition $f \circ g$.

:::definition Composite function
$(f \circ g)(x) = f(g(x))$. The inner function $g$ is applied first; its output becomes the input of the outer function $f$.
:::

:::example Evaluating a composition
Let $f(x) = 2x - 3$ and $g(x) = x^2 + 1$. Find $(f \circ g)(2)$ and $(g \circ f)(2)$.
@step Inside first: $g(2) = 2^2 + 1 = 5$, so $(f \circ g)(2) = f(5) = 2(5) - 3 = 7$.
@step In the other order: $f(2) = 2(2) - 3 = 1$, so $(g \circ f)(2) = g(1) = 1^2 + 1 = 2$.
@answer $(f \circ g)(2) = 7$ and $(g \circ f)(2) = 2$. The order matters.
:::

To find a formula for a composition, substitute the **whole** inner expression for every $x$ in the outer function.

:::example A composite formula
With the same $f$ and $g$, find $(f \circ g)(x)$ and $(g \circ f)(x)$.
@step $(f \circ g)(x) = f(x^2 + 1) = 2(x^2 + 1) - 3 = 2x^2 - 1$
@step $(g \circ f)(x) = g(2x - 3) = (2x - 3)^2 + 1 = 4x^2 - 12x + 9 + 1$
@answer $(f \circ g)(x) = 2x^2 - 1$ and $(g \circ f)(x) = 4x^2 - 12x + 10$
:::

:::mistake Composition is not multiplication
$(f \circ g)(x)$ means $f(g(x))$, not $f(x) \cdot g(x)$. Here $f(x)g(x) = (2x - 3)(x^2 + 1)$, a completely different function.
:::

## Inside and outside

Calculus often runs composition backwards: given a function, you identify the inner and outer parts. Ask yourself, "What would I calculate first?"

:::example Decomposing a function
Write $H(x) = \sqrt{3x + 1}$ as $f(g(x))$.
@step To evaluate $H(x)$ you first calculate $3x + 1$, then take the square root.
@step So the inner function is $g(x) = 3x + 1$ and the outer function is $f(x) = \sqrt{x}$.
@step Check: $f(g(x)) = \sqrt{3x + 1}$ ✓
@answer $f(x) = \sqrt{x}$ and $g(x) = 3x + 1$
:::

:::tip Looking ahead
In Unit 4, the **chain rule** differentiates a composite function by treating the inner and outer functions separately. Spotting them quickly now pays off later.
:::

## The domain of a composite function

A composite function is defined only when both steps work: $x$ must be in the domain of $g$, **and** the output $g(x)$ must be in the domain of $f$.

:::example A root of a linear function
Let $f(x) = \sqrt{x}$ and $g(x) = 5 - x$. Find the domain of $f \circ g$.
@step $(f \circ g)(x) = \sqrt{5 - x}$
@step The radicand must not be negative: $5 - x \ge 0$, so $x \le 5$.
@answer The domain is $x \le 5$, or $(-\infty, 5]$.
:::

:::example Two restrictions
Let $f(x) = \dfrac{1}{x - 3}$ and $g(x) = \sqrt{x}$. Find the domain of $f \circ g$.
@step $(f \circ g)(x) = \dfrac{1}{\sqrt{x} - 3}$
@step $g(x) = \sqrt{x}$ needs $x \ge 0$.
@step $f$ cannot take the input $3$: $\sqrt{x} = 3$ when $x = 9$, so $x \ne 9$.
@answer $x \ge 0$ and $x \ne 9$, that is, $[0, 9) \cup (9, \infty)$
:::

:::mistake Simplifying away a restriction
For $f(x) = x^2$ and $g(x) = \sqrt{x}$, $(f \circ g)(x) = (\sqrt{x})^2 = x$. The simplified formula looks defined everywhere, but $g$ only accepts $x \ge 0$. Find the domain **before** you simplify.
:::

## The difference quotient

The slope of the line through two points on the graph of $f$ measures how fast $f$ changes between them. If the points are $(x, f(x))$ and $(x + h, f(x + h))$, the run is $h$ and the rise is $f(x + h) - f(x)$.

:::definition Difference quotient
$$\frac{f(x + h) - f(x)}{h}, \quad h \ne 0$$
It is the slope of the **secant line** through $(x, f(x))$ and $(x + h, f(x + h))$.
:::

:::example Simplifying a difference quotient
Simplify the difference quotient for $f(x) = x^2 - 3x$.
@step $f(x + h) = (x + h)^2 - 3(x + h) = x^2 + 2xh + h^2 - 3x - 3h$
@step Subtract $f(x) = x^2 - 3x$: $f(x + h) - f(x) = 2xh + h^2 - 3h$
@step Every term has a factor of $h$: $\dfrac{h(2x + h - 3)}{h} = 2x + h - 3$
@answer $\dfrac{f(x + h) - f(x)}{h} = 2x + h - 3$
:::

:::example A reciprocal function
Simplify the difference quotient for $f(x) = \dfrac{1}{x}$.
@step $f(x + h) - f(x) = \dfrac{1}{x + h} - \dfrac{1}{x} = \dfrac{x - (x + h)}{x(x + h)} = \dfrac{-h}{x(x + h)}$
@step Divide by $h$: $\dfrac{-h}{x(x + h)} \cdot \dfrac{1}{h}$
@answer $\dfrac{f(x + h) - f(x)}{h} = \dfrac{-1}{x(x + h)}$
:::

:::mistake Expanding f(x + h)
$f(x + h)$ means "replace every $x$ with $(x + h)$". It is **not** $f(x) + h$, and $(x + h)^2 = x^2 + 2xh + h^2$, not $x^2 + h^2$.
:::

:::tip A built-in check
After you subtract $f(x)$, every remaining term should contain $h$. If a term without $h$ survives, look for an algebra slip.
:::

:::summary
- $(f \circ g)(x) = f(g(x))$: apply $g$ first. The order matters.
- To decompose a function, ask what you would calculate first: that is the inner function.
- The domain of $f \circ g$ needs $x$ in the domain of $g$ and $g(x)$ in the domain of $f$. Find it before simplifying.
- The difference quotient $\dfrac{f(x + h) - f(x)}{h}$ is the slope of a secant line. Expand, subtract, factor out $h$, and cancel.
:::
