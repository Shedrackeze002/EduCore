Is the derivative of a product the product of the derivatives? Try $x \cdot x = x^2$: its derivative is $2x$, but $\dfrac{d}{dx}(x) \cdot \dfrac{d}{dx}(x) = 1 \cdot 1 = 1$. Products and quotients need rules of their own.

## The product rule

:::definition Product rule
If $f$ and $g$ are differentiable, then
$$\frac{d}{dx}\left[f(x)g(x)\right] = f'(x)g(x) + f(x)g'(x).$$
With $u = f(x)$ and $v = g(x)$: $(uv)' = u'v + uv'$.
:::

**Proof.** Start from the definition and add and subtract the same term, $f(x + h)g(x)$:
$$\frac{f(x + h)g(x + h) - f(x)g(x)}{h} = f(x + h)\cdot\frac{g(x + h) - g(x)}{h} + g(x)\cdot\frac{f(x + h) - f(x)}{h}.$$
As $h \to 0$, the difference quotients approach $g'(x)$ and $f'(x)$, and $f(x + h) \to f(x)$ because a differentiable function is continuous. So the limit is $f(x)g'(x) + g(x)f'(x)$.

:::example A product of polynomials
Differentiate $f(x) = (2x + 3)(x^{2} - 1)$.
@step Let $u = 2x + 3$ and $v = x^{2} - 1$, so $u' = 2$ and $v' = 2x$.
@step $f'(x) = u'v + uv' = 2(x^{2} - 1) + (2x + 3)(2x)$.
@step Expand: $2x^{2} - 2 + 4x^{2} + 6x$.
@answer $f'(x) = 6x^{2} + 6x - 2$
:::

Check: expanding first gives $f(x) = 2x^{3} + 3x^{2} - 2x - 3$, and the power rule gives the same $6x^{2} + 6x - 2$. The product rule matters when expanding is impossible or painful, as with roots, trigonometric and exponential functions.

:::mistake Multiplying the derivatives
$(uv)' \ne u'v'$. For the example above, $u'v' = 2(2x) = 4x$, which is wrong. Each term of the product rule differentiates **one** factor and keeps the other.
:::

## The quotient rule

:::definition Quotient rule
If $f$ and $g$ are differentiable and $g(x) \ne 0$, then
$$\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)g(x) - f(x)g'(x)}{\left[g(x)\right]^2}, \qquad \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}.$$
:::

**Where it comes from.** Let $q = \dfrac{u}{v}$, so $u = qv$. The product rule gives $u' = q'v + qv'$, so $q' = \dfrac{u' - qv'}{v} = \dfrac{u' - \frac{u}{v}v'}{v} = \dfrac{u'v - uv'}{v^2}$.

:::example A quotient of linear functions
Differentiate $f(x) = \dfrac{2x + 1}{x - 3}$.
@step Let $u = 2x + 1$ and $v = x - 3$, so $u' = 2$ and $v' = 1$.
@step $f'(x) = \dfrac{2(x - 3) - (2x + 1)(1)}{(x - 3)^{2}}$.
@step Numerator: $2x - 6 - 2x - 1 = -7$.
@answer $f'(x) = -\dfrac{7}{(x - 3)^{2}}$
:::

:::mistake The order matters
The numerator is a difference, so the order counts: $u'v - uv'$, **not** $uv' - u'v$. Reversing it changes the sign of the answer. A memory aid: "low d-high minus high d-low, over the square of what's below."
:::

## Roots and tables of values

:::example A product with a root
Differentiate $f(x) = \sqrt{x}\,(4x - 1)$.
@step Let $u = \sqrt{x}$ and $v = 4x - 1$, so $u' = \dfrac{1}{2\sqrt{x}}$ and $v' = 4$.
@step $f'(x) = \dfrac{4x - 1}{2\sqrt{x}} + 4\sqrt{x}$.
@step Write $4\sqrt{x} = \dfrac{8x}{2\sqrt{x}}$ and add.
@answer $f'(x) = \dfrac{12x - 1}{2\sqrt{x}}$
:::

You do not need formulas for $f$ and $g$ to use the rules, only their values and slopes at the point.

:::example Using a table
Use the table. Find $h'(2)$ if $h(x) = f(x)g(x)$, and $k'(2)$ if $k(x) = \dfrac{f(x)}{g(x)}$.
@step At $x = 2$: $f(2) = 3$, $f'(2) = -1$, $g(2) = 4$ and $g'(2) = 5$.
@step $h'(2) = f'(2)g(2) + f(2)g'(2) = (-1)(4) + (3)(5) = 11$.
@step $k'(2) = \dfrac{f'(2)g(2) - f(2)g'(2)}{[g(2)]^2} = \dfrac{(-1)(4) - (3)(5)}{16} = -\dfrac{19}{16}$.
@answer $h'(2) = 11$ and $k'(2) = -\dfrac{19}{16}$

## Applications

:::example Horizontal tangents of a quotient
Find the points where $y = \dfrac{x^{2} + 3}{x - 1}$ has a horizontal tangent.
@step $\dfrac{dy}{dx} = \dfrac{2x(x - 1) - (x^{2} + 3)(1)}{(x - 1)^{2}} = \dfrac{x^{2} - 2x - 3}{(x - 1)^{2}}$.
@step A fraction is $0$ when its numerator is $0$: $(x - 3)(x + 1) = 0$, so $x = 3$ or $x = -1$.
@step $y(3) = \dfrac{12}{2} = 6$ and $y(-1) = \dfrac{4}{-2} = -2$.
@answer $(-1,\ -2)$ and $(3,\ 6)$
:::

:::example A medication
The concentration of a medication in the blood is $C(t) = \dfrac{50t}{t^{2} + 4}$ mg/L, $t$ hours after an injection. Find $C'(1)$ and $C'(3)$.
@step $C'(t) = \dfrac{50(t^{2} + 4) - 50t(2t)}{(t^{2} + 4)^{2}} = \dfrac{50(4 - t^{2})}{(t^{2} + 4)^{2}}$.
@step $C'(1) = \dfrac{50(3)}{25} = 6$ and $C'(3) = \dfrac{50(-5)}{169} \approx -1.48$.
@answer The concentration rises at $6$ mg/L per hour after $1$ h, and falls at about $1.48$ mg/L per hour after $3$ h.

:::summary
- Product rule: $(uv)' = u'v + uv'$. It is not $u'v'$.
- Quotient rule: $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$; the order in the numerator matters.
- Write $u$, $v$, $u'$ and $v'$ first, then substitute; simplify by expanding or factoring.
- With a table, read all four values in the right row, then use the rule.
:::
