A physicist who knows a rocket's velocity at every instant wants its position; an economist who knows the marginal cost wants the total cost. Both need to run differentiation backwards. That reverse process, antidifferentiation, is the first step toward integrals.

## Undoing a derivative

If $F'(x) = f(x)$, then $F$ is an **antiderivative** of $f$. Since $\frac{d}{dx}\left(x^{2}\right) = 2x$, the function $x^{2}$ is an antiderivative of $2x$. So are $x^{2} + 5$ and $x^{2} - 3$: adding a constant does not change the derivative.

:::definition Antiderivative and constant of integration
$F$ is an **antiderivative** of $f$ on an interval if $F'(x) = f(x)$ for every $x$ in the interval. If $F$ is one antiderivative, every antiderivative has the form $F(x) + C$, where the constant $C$ is the **constant of integration**. The general antiderivative is written as an **indefinite integral**:
$$\int f(x)\,dx = F(x) + C.$$
:::

Why must every antiderivative look like $F + C$? If $G' = f$ as well, then $(G - F)' = 0$, and a function whose derivative is $0$ everywhere on an interval is constant (this follows from the Mean Value Theorem). On a graph, the antiderivatives are vertical shifts of one another: at each $x$ they all have the same slope.

## The power rule in reverse

Differentiating $x^{n+1}$ gives $(n + 1)x^{n}$. To undo it, raise the power by one and divide by the new power.

:::definition Rules for antiderivatives
$$\int x^{n}\,dx = \frac{x^{n+1}}{n + 1} + C \quad (n \ne -1)$$
$$\int k\,f(x)\,dx = k\int f(x)\,dx, \qquad \int \big(f(x) \pm g(x)\big)\,dx = \int f(x)\,dx \pm \int g(x)\,dx$$
:::

:::example A polynomial
Find $\displaystyle\int (6x^{2} - 4x + 5)\,dx$.
@step Integrate term by term: $\int 6x^{2}\,dx = 6\cdot\dfrac{x^{3}}{3} = 2x^{3}$, $\int -4x\,dx = -4\cdot\dfrac{x^{2}}{2} = -2x^{2}$ and $\int 5\,dx = 5x$.
@step Check: $\dfrac{d}{dx}\left(2x^{3} - 2x^{2} + 5x\right) = 6x^{2} - 4x + 5$.
@answer $2x^{3} - 2x^{2} + 5x + C$
:::

Roots and reciprocals become powers first: $\sqrt{x} = x^{1/2}$ and $\dfrac{1}{x^{3}} = x^{-3}$.

:::example Roots and negative powers
Find $\displaystyle\int \left(3\sqrt{x} - \frac{2}{x^{3}}\right)dx$ for $x > 0$.
@step Rewrite the integrand as $3x^{1/2} - 2x^{-3}$.
@step $\int 3x^{1/2}\,dx = 3\cdot\dfrac{x^{3/2}}{3/2} = 2x^{3/2}$ and $\int -2x^{-3}\,dx = -2\cdot\dfrac{x^{-2}}{-2} = x^{-2}$.
@answer $2x^{3/2} + \dfrac{1}{x^{2}} + C$
:::

:::mistake No product rule for integrals
There is no simple rule for $\int f(x)g(x)\,dx$. For example, $\int x(x + 1)\,dx$ is **not** $\frac{x^{2}}{2}\cdot\left(\frac{x^{2}}{2} + x\right)$. Expand first: $\int (x^{2} + x)\,dx = \frac{x^{3}}{3} + \frac{x^{2}}{2} + C$. Quotients are the same: divide first.
:::

In the practice questions, type the antiderivative with $C = 0$; the answer box adds the $+ C$ for you.

## Other basic antiderivatives

Every derivative rule you know gives an antiderivative rule when you read it backwards.

:::definition Basic antiderivatives
$$\int \cos x\,dx = \sin x + C, \qquad \int \sin x\,dx = -\cos x + C, \qquad \int \sec^{2} x\,dx = \tan x + C$$
$$\int e^{x}\,dx = e^{x} + C, \qquad \int \frac{1}{x}\,dx = \ln|x| + C$$
The rule for $\frac{1}{x}$ fills the gap in the power rule ($n = -1$). For $x > 0$ it is simply $\ln x + C$.
:::

:::example Mixed terms
Find $\displaystyle\int \left(4\cos x - 3e^{x} + \frac{2}{x}\right)dx$ for $x > 0$.
@step $\int 4\cos x\,dx = 4\sin x$, $\int -3e^{x}\,dx = -3e^{x}$ and $\int \frac{2}{x}\,dx = 2\ln x$.
@step Check: $\dfrac{d}{dx}\left(4\sin x - 3e^{x} + 2\ln x\right) = 4\cos x - 3e^{x} + \dfrac{2}{x}$.
@answer $4\sin x - 3e^{x} + 2\ln x + C$
:::

:::example Rewrite first
Find $\displaystyle\int \frac{x^{3} + 2}{x^{2}}\,dx$ for $x > 0$.
@step Divide each term by $x^{2}$: $\dfrac{x^{3} + 2}{x^{2}} = x + 2x^{-2}$.
@step $\int x\,dx = \dfrac{x^{2}}{2}$ and $\int 2x^{-2}\,dx = 2\cdot\dfrac{x^{-1}}{-1} = -\dfrac{2}{x}$.
@answer $\dfrac{x^{2}}{2} - \dfrac{2}{x} + C$
:::

:::mistake The sign of sine
$\dfrac{d}{dx}\cos x = -\sin x$, so $\int \sin x\,dx = -\cos x + C$, not $\cos x + C$. Differentiating your answer catches this every time.
:::

## Initial-value problems

A derivative together with one value of the function pins down $C$. This is an **initial-value problem**, and the given value is the **initial condition**.

:::example Using an initial condition
Find $f(x)$ given $f'(x) = 3x^{2} - 4x$ and $f(1) = 5$.
@step Antidifferentiate: $f(x) = x^{3} - 2x^{2} + C$.
@step Substitute $x = 1$: $f(1) = 1 - 2 + C = -1 + C = 5$, so $C = 6$.
@answer $f(x) = x^{3} - 2x^{2} + 6$
:::

## From acceleration to position

Velocity is the derivative of position, and acceleration is the derivative of velocity. Going backwards takes two antiderivatives, each with its own constant, so two conditions are needed: usually the initial velocity $v(0)$ and the initial position $s(0)$.

:::example A ball thrown upward
A ball is thrown straight up at $14.7$ m/s from a height of $2$ m. Its acceleration is $a(t) = -9.8$ m/s² (gravity), with $t$ in seconds. Find its height $s(t)$ and its height after $1$ s.
@step $v(t) = \int -9.8\,dt = -9.8t + C_{1}$, and $v(0) = 14.7$ gives $C_{1} = 14.7$.
@step $s(t) = \int (-9.8t + 14.7)\,dt = -4.9t^{2} + 14.7t + C_{2}$, and $s(0) = 2$ gives $C_{2} = 2$.
@step $s(1) = -4.9 + 14.7 + 2 = 11.8$
@answer $s(t) = -4.9t^{2} + 14.7t + 2$, and the ball is $11.8$ m high after $1$ s.
:::

:::summary
- $F$ is an antiderivative of $f$ when $F' = f$; all antiderivatives of $f$ are $F(x) + C$.
- Power rule: $\int x^{n}\,dx = \frac{x^{n+1}}{n+1} + C$ for $n \ne -1$, and $\int \frac{1}{x}\,dx = \ln|x| + C$.
- $\int \cos x\,dx = \sin x$, $\int \sin x\,dx = -\cos x$, $\int \sec^{2} x\,dx = \tan x$ and $\int e^{x}\,dx = e^{x}$ (each $+ C$).
- Rewrite products, quotients and roots as sums of powers before integrating, and check by differentiating.
- An initial condition determines $C$; a motion problem needs one condition for each antiderivative.
:::
