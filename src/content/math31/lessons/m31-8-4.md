The chain rule differentiates compositions such as $(x^{2} + 1)^{5}$ and $e^{3x}$. Integration by substitution runs the chain rule backwards, and after the basic rules it is the most useful integration technique you will learn.

## Reversing the chain rule

By the chain rule, $\dfrac{d}{dx}(x^{2} + 1)^{5} = 5(x^{2} + 1)^{4}\cdot 2x = 10x(x^{2} + 1)^{4}$. Read backwards,
$$\int 10x(x^{2} + 1)^{4}\,dx = (x^{2} + 1)^{5} + C.$$
The integrand contains an inside function, $x^{2} + 1$, **and** the derivative of that inside function, $2x$, as a factor. That pattern, $f\big(g(x)\big)\,g'(x)$, is what substitution looks for.

:::definition Substitution rule
If $u = g(x)$, then $du = g'(x)\,dx$, and
$$\int f\big(g(x)\big)\,g'(x)\,dx = \int f(u)\,du.$$
:::

## The method

1. Choose $u$: usually the inside of a power, a root, an exponential or a logarithm.
2. Find $du = u'(x)\,dx$, and solve for the part of the integrand it replaces.
3. Rewrite the whole integral in terms of $u$; no $x$ may remain.
4. Integrate, then substitute $u = g(x)$ back.

:::example Adjusting a constant
Find $\displaystyle\int x^{2}(x^{3} + 2)^{4}\,dx$.
@step Let $u = x^{3} + 2$. Then $du = 3x^{2}\,dx$, so $x^{2}\,dx = \frac{1}{3}\,du$.
@step $\displaystyle\int x^{2}(x^{3} + 2)^{4}\,dx = \frac{1}{3}\int u^{4}\,du = \frac{1}{3}\cdot\frac{u^{5}}{5} + C = \frac{u^{5}}{15} + C$
@step Check: $\dfrac{d}{dx}\left[\dfrac{(x^{3} + 2)^{5}}{15}\right] = \dfrac{5(x^{3} + 2)^{4}\cdot 3x^{2}}{15} = x^{2}(x^{3} + 2)^{4}$.
@answer $\dfrac{1}{15}(x^{3} + 2)^{5} + C$
:::

:::mistake Every piece must change
$\int x^{2}(x^{3} + 2)^{4}\,dx$ is **not** $\int u^{4}\,du$: the factor $x^{2}\,dx$ is only $\frac{1}{3}\,du$. After substituting, check that no $x$ and no $dx$ is left, and that every constant factor came along.
:::

## Exponentials, logarithms and trigonometric functions

:::example Four substitutions
Find (a) $\int e^{3x}\,dx$, (b) $\int xe^{x^{2}}\,dx$, (c) $\displaystyle\int \frac{2x}{x^{2} + 1}\,dx$ and (d) $\int \cos x\,\sin^{2} x\,dx$.
@step (a) $u = 3x$, $du = 3\,dx$: $\frac{1}{3}\int e^{u}\,du = \frac{1}{3}e^{3x} + C$.
@step (b) $u = x^{2}$, $du = 2x\,dx$: $\frac{1}{2}\int e^{u}\,du = \frac{1}{2}e^{x^{2}} + C$.
@step (c) $u = x^{2} + 1$, $du = 2x\,dx$: $\int \frac{1}{u}\,du = \ln(x^{2} + 1) + C$ (no absolute value is needed, since $x^{2} + 1 > 0$).
@step (d) $u = \sin x$, $du = \cos x\,dx$: $\int u^{2}\,du = \frac{1}{3}\sin^{3} x + C$.
@answer (a) $\frac{1}{3}e^{3x} + C$ (b) $\frac{1}{2}e^{x^{2}} + C$ (c) $\ln(x^{2} + 1) + C$ (d) $\frac{1}{3}\sin^{3} x + C$
:::

An initial condition picks out one antiderivative, just as in Lesson 8.1.

:::example With an initial condition
Find the antiderivative $F$ of $f(x) = 6x(x^{2} + 1)^{2}$ with $F(0) = 2$.
@step Let $u = x^{2} + 1$, so $du = 2x\,dx$ and $6x\,dx = 3\,du$.
@step $\int 3u^{2}\,du = u^{3} + C$, so $F(x) = (x^{2} + 1)^{3} + C$.
@step $F(0) = 1 + C = 2$, so $C = 1$.
@answer $F(x) = (x^{2} + 1)^{3} + 1$
:::

## Definite integrals: change the limits

When you rewrite a definite integral in terms of $u$, change the limits to $u$-values as well. Then there is no need to substitute back.

:::example Changing the limits
Evaluate $\displaystyle\int_0^{4} x\sqrt{x^{2} + 9}\,dx$.
@step Let $u = x^{2} + 9$, so $du = 2x\,dx$ and $x\,dx = \frac{1}{2}\,du$.
@step When $x = 0$, $u = 9$; when $x = 4$, $u = 25$.
@step $\displaystyle\frac{1}{2}\int_{9}^{25} u^{1/2}\,du = \frac{1}{2}\cdot\frac{2}{3}\Big[u^{3/2}\Big]_{9}^{25} = \frac{1}{3}(125 - 27)$
@answer $\dfrac{98}{3} \approx 32.67$
:::

:::mistake Mixing x-limits and u
$\frac{1}{3}\Big[u^{3/2}\Big]_0^4$ uses $x$-limits with a function of $u$, and gives the wrong answer $\frac{8}{3}$. Either change the limits to $u$-values or substitute back to $x$ before using the $x$-limits.
:::

:::example Distance from a velocity
A test car's velocity is $v(t) = 6t\sqrt{t^{2} + 16}$ m/s. How far does it travel in the first $3$ s?
@step Distance $= \int_0^3 6t\sqrt{t^{2} + 16}\,dt$ (the velocity is never negative).
@step Let $u = t^{2} + 16$, so $6t\,dt = 3\,du$; the limits become $u = 16$ and $u = 25$.
@step $\displaystyle 3\int_{16}^{25} u^{1/2}\,du = 2\Big[u^{3/2}\Big]_{16}^{25} = 2(125 - 64)$
@answer $122$ m
:::

:::

:::summary
- Substitution reverses the chain rule: look for an inside function $g(x)$ whose derivative $g'(x)$ is also a factor (up to a constant).
- Let $u = g(x)$, write $du = g'(x)\,dx$, rewrite everything in $u$, integrate, then substitute back.
- Constant factors are fine: solve $du = 3x^{2}\,dx$ for $x^{2}\,dx = \frac{1}{3}\,du$.
- For a definite integral, change the limits to $u$-values and skip substituting back.
:::
