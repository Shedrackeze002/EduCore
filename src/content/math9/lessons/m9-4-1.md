Toothpick patterns, gym memberships and growing plants all follow rules. If you can write the rule as an equation, you can find any figure in the pattern, even Figure 100, without drawing it. You can also check your equation before you trust it.

:::definition Linear equation
A **linear equation** describes a linear relation, such as $t = 3n + 1$. Its graph is a straight line, and the variable $n$ is not squared or in a denominator.
:::

Each new square shares a side with the one before, so it adds $3$ toothpicks. The number added each time multiplies $n$. Then fix the constant so the first figure is right.

:::example Write the equation
Write an equation for the number of toothpicks, $t$, in Figure $n$.
@step Each figure has $3$ more toothpicks than the one before, so the equation has $3n$.
@step For Figure 1, $3(1) = 3$, but there are $4$ toothpicks. Add $1$.
@answer $t = 3n + 1$
:::

## Verifying by substitution

:::definition Verify
To **verify** an equation is to check that it gives the right value for every known pair. Substitute values from the table and compare.
:::

:::example Verify the equation
Verify $t = 3n + 1$ with Figure 4.
@step Substitute $n = 4$: $t = 3(4) + 1 = 12 + 1 = 13$.
@step The table shows $13$ toothpicks for Figure 4.
@answer The equation gives the right value, so it is verified for Figure 4. Checking another figure makes you even more sure.
:::

:::mistake Checking only one figure
Someone might guess $t = 4n$, because Figure 1 has $4$ toothpicks. Check Figure 2: $4(2) = 8$, but there are only $7$. The equation must work for **every** figure, so $t = 4n$ is wrong.
:::

## Equations from situations

In a situation, look for two amounts:
- the **starting amount** or fixed fee, which is the constant term;
- the **rate**, the amount that changes for each unit, which multiplies the variable.

:::example A climbing gym
A climbing gym charges a \$25 membership fee plus \$8 for each visit. Write an equation for the total cost $C$, in dollars, for $n$ visits, and verify it for $3$ visits.
@step The fixed fee is $25$ and the rate is $8$ per visit, so $C = 25 + 8n$.
@step From the words, $3$ visits cost $25 + 8 + 8 + 8 = 49$ dollars.
@step From the equation, $C = 25 + 8(3) = 25 + 24 = 49$. It matches.
@answer $C = 25 + 8n$
:::

In Grade 9 the rate does not have to be a whole number. A bean plant that is $4$ cm tall and grows $0.5$ cm each day has height $h = 4 + 0.5d$ after $d$ days. A candle that is $30$ cm tall and burns down $1.5$ cm each hour has height $h = 30 - 1.5t$, because the height goes **down**.

:::

## Using the equation

Once an equation is verified, you can use it to find values far beyond the table.

:::example Which figure has 100 toothpicks?
Use $t = 3n + 1$ to find the figure with $100$ toothpicks.
@step Substitute $t = 100$: $100 = 3n + 1$.
@step Subtract $1$ from both sides: $3n = 99$. Divide by $3$: $n = 33$.
@step Verify: $3(33) + 1 = 99 + 1 = 100$. It matches.
@answer Figure 33 has $100$ toothpicks.
:::

:::example When x goes up by 2
The table shows $x = 0$, $2$, $4$, $6$ and $y = 5$, $6$, $7$, $8$. Write an equation for $y$.
@step When $x$ goes up by $2$, $y$ goes up by $1$. For each $1$, $y$ goes up by $1 \div 2 = 0.5$.
@step When $x = 0$, $y = 5$, so the constant is $5$: $y = 0.5x + 5$.
@step Verify with $x = 6$: $y = 0.5(6) + 5 = 3 + 5 = 8$. It matches.
@answer $y = 0.5x + 5$, which you can also write as $y = \frac{1}{2}x + 5$.
:::

:::check m9-pattern-equation 3
:::

:::summary
- In a linear pattern, the amount added each time multiplies the variable, and the constant term makes the first value right.
- In a situation, the starting amount is the constant and the rate multiplies the variable. Subtract the rate when the amount goes down.
- Verify an equation by substituting known values; it must work for every one.
- Use a verified equation to find values beyond the table, or solve it to find which figure has a given value.
:::
