A graph turns an equation into a picture. In this lesson you will graph linear relations with fraction and decimal rates, decide whether the points should be joined, and use a graph to estimate values between and beyond your data.

## Graphing from an equation

To graph a linear relation, make a table of values and plot the points. When the rate is a fraction, choose values of $x$ that make the arithmetic easy: for $y = \frac{2}{3}x + 1$, use multiples of $3$.

:::example Graph y = (2/3)x + 1
Graph $y = \frac{2}{3}x + 1$.
@step Choose $x = -3$, $0$, $3$ and $6$.
@step $x = -3$: $y = \frac{2}{3}(-3) + 1 = -2 + 1 = -1$. $x = 0$: $y = 1$. $x = 3$: $y = 2 + 1 = 3$. $x = 6$: $y = 4 + 1 = 5$.
@step Plot $(-3,\ -1)$, $(0,\ 1)$, $(3,\ 3)$ and $(6,\ 5)$, and draw the line through them.
@answer The line crosses the $y$-axis at $1$ and rises $2$ units for every $3$ units to the right.
:::

:::figure

:::tip Read a graph quickly
The constant term is where the line crosses the $y$-axis. A positive rate makes the line rise from left to right; a negative rate makes it fall.

## Discrete or continuous?

:::definition Discrete data
**Discrete data** can only take separate values, usually counts such as people, tickets or shirts. Graph discrete data as separate points.
:::

:::definition Continuous data
**Continuous data** can take any value in a range, usually measurements such as time, length or volume. Graph continuous data as a solid line.
:::

A shop charges a \$20 set-up fee plus \$5 for each team T-shirt, so $C = 5n + 20$. You cannot order $2.5$ shirts, so the graph is separate points.

:::figure

A bean plant is $3$ cm tall and grows $0.5$ cm each day, so $h = 0.5d + 3$. Time can be any value, such as $2.5$ days, so the graph is a solid line.

:::figure

:::

:::mistake Joining points that cannot be joined
The points for the T-shirts lie in a straight line, but that does not make the data continuous. Ask whether values **between** the points make sense.

## Interpolating

:::definition Interpolate
To **interpolate** is to estimate a value **between** known data points, by reading the line.
:::

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":12,"yMin":0,"yMax":10,"xStep":1,"yStep":1,"xLabel":"Time (days)","yLabel":"Height (cm)"},"points":[{"x":0,"y":3},{"x":4,"y":5},{"x":8,"y":7}],"polylines":[{"points":[[0,3],[8,7]]}]}
:::

:::example Read between the data
The plant was measured on days $0$, $4$ and $8$. How tall was it on day $6$?
@step Day $6$ is between the measurements on days $4$ and $8$, so this is interpolation.
@step Go up from $6$ on the horizontal axis to the line, then across: $6$ cm.
@step Check with the equation: $h = 0.5(6) + 3 = 3 + 3 = 6$.
@answer The plant was $6$ cm tall on day $6$.
:::

## Extrapolating

:::definition Extrapolate
To **extrapolate** is to estimate a value **beyond** the known data, by extending the line or using the equation. It assumes the pattern keeps going.
:::

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":16,"yMin":0,"yMax":27,"xStep":1,"yStep":3,"xLabel":"Time (h)","yLabel":"Height (cm)"},"points":[{"x":0,"y":24},{"x":4,"y":18},{"x":8,"y":12}],"polylines":[{"points":[[0,24],[8,12]]}],"segments":[{"from":[8,12],"to":[16,0],"dashed":true}]}
:::

:::example When will the candle burn out?
A $24$ cm candle was measured after $0$, $4$ and $8$ hours. When will it burn out?
@step From $(0,\ 24)$ to $(4,\ 18)$ the height drops $6$ cm in $4$ h, which is $6 \div 4 = 1.5$ cm per hour. So $h = 24 - 1.5t$.
@step The candle burns out when $h = 0$: $24 - 1.5t = 0$, so $1.5t = 24$ and $t = 24 \div 1.5 = 16$.
@step The dashed line on the graph also reaches $0$ at $16$ h.
@answer The candle burns out after $16$ hours. This is extrapolation, because $16$ h is beyond the data.
:::

:::tip Be careful with extrapolation
Extrapolation assumes the pattern continues. A plant will not keep growing $0.5$ cm a day forever, so predictions far beyond the data are less reliable.
:::

:::summary
- To graph a linear relation, make a table of values; with a fraction rate, choose $x$-values that are multiples of the denominator.
- Discrete data (counts) are graphed as separate points; continuous data (measurements) as a solid line.
- Interpolating means estimating between data points; extrapolating means estimating beyond them.
- You can interpolate or extrapolate by reading the graph or by substituting into the equation.
:::
