A chessboard has $8 \times 8 = 64$ squares. A puzzle cube can be built from $3 \times 3 \times 3 = 27$ small cubes. When the same number is multiplied again and again, mathematicians use a short way to write it: a power.

## Powers: base and exponent

:::definition Power, base and exponent
A **power** is a short way to write repeated multiplication of the same factor. In $5^{4}$, the **base** is $5$ (the factor being multiplied) and the **exponent** is $4$ (how many times the base is a factor).
$$5^{4} = 5 \times 5 \times 5 \times 5$$
:::

We read $5^{4}$ as "five to the fourth power" or "five to the fourth." Two exponents have special names: $6^{2}$ is "six **squared**" and $6^{3}$ is "six **cubed**." The names come from geometry: a square with side length $4$ is made of $4^{2} = 16$ unit squares, and a cube with edge length $3$ is made of $3^{3} = 27$ unit cubes.

:::example Writing a power
Write $7 \times 7 \times 7 \times 7 \times 7 \times 7$ as a power.
@step The same factor, $7$, is repeated. The base is $7$.
@step Count the factors: there are $6$. The exponent is $6$.
@answer $7 \times 7 \times 7 \times 7 \times 7 \times 7 = 7^{6}$
:::

## Evaluating powers

To **evaluate** a power, write it as repeated multiplication and multiply.

:::example Evaluating $2^{5}$
@step $2^{5} = 2 \times 2 \times 2 \times 2 \times 2$
@step Multiply step by step: $2 \times 2 = 4$, $4 \times 2 = 8$, $8 \times 2 = 16$, $16 \times 2 = 32$.
@answer $2^{5} = 32$
:::

:::mistake The exponent is not a multiplier
$2^{5}$ is **not** $2 \times 5 = 10$. The exponent tells how many times $2$ is a factor, so $2^{5} = 32$.
:::

:::tip Powers of 10
Each factor of $10$ adds a zero: $10^{4} = 10\,000$, which is $1$ followed by $4$ zeros.
:::

## Negative bases and brackets

Brackets decide what the base is. Compare these three powers.

:::figure
{"type":"table","headers":["Power","Base","Meaning","Value"],"rows":[["$(-2)^{4}$","-2","$(-2) \\times (-2) \\times (-2) \\times (-2)$","16"],["$-2^{4}$","2","$-(2 \\times 2 \\times 2 \\times 2)$","-16"],["$(-2)^{3}$","-2","$(-2) \\times (-2) \\times (-2)$","-8"]]}
:::

- In $(-2)^{4}$ the brackets hold $-2$, so the base is $-2$.
- In $-2^{4}$ there are no brackets. The base is $2$. Work out $2^{4} = 16$ first, then take the opposite: $-16$.

:::example Evaluating with a negative base
Evaluate $(-3)^{4}$ and $-3^{4}$.
@step $(-3)^{4} = (-3) \times (-3) \times (-3) \times (-3)$. Four negative factors give a positive product: $(-3)^{4} = 81$.
@step $-3^{4}$ has base $3$: $-3^{4} = -(3 \times 3 \times 3 \times 3) = -81$.
@answer $(-3)^{4} = 81$ and $-3^{4} = -81$
:::

:::mistake Is the minus sign part of the base?
$-5^{2}$ is **not** $25$. Without brackets, the exponent belongs to $5$ only: $-5^{2} = -(5 \times 5) = -25$. Only $(-5)^{2} = 25$.
:::

## Even and odd exponents

Negative factors cancel in pairs: $(-2) \times (-2) = 4$. So the sign of a power with a negative base depends on the exponent.

:::note Signs of powers with a negative base
- **Even exponent:** the negative factors pair up, so the value is positive. $(-2)^{6} = 64$
- **Odd exponent:** one negative factor is left over, so the value is negative. $(-2)^{5} = -32$
:::

:::example Predicting the sign
Is $(-7)^{9}$ positive or negative? Is $-7^{10}$ positive or negative?
@step $(-7)^{9}$ has base $-7$ and an odd exponent, so it is negative.
@step $-7^{10}$ has base $7$. $7^{10}$ is positive, and the minus sign in front makes it negative.
@answer Both values are negative.
:::

:::

:::summary
- A power $a^{n}$ means $n$ factors of the base $a$: $5^{4} = 5 \times 5 \times 5 \times 5$.
- The exponent is not a multiplier: $2^{5} = 32$, not $10$.
- Brackets decide the base: $(-2)^{4} = 16$, but $-2^{4} = -16$.
- A negative base with an even exponent gives a positive value; with an odd exponent, a negative value.
:::
