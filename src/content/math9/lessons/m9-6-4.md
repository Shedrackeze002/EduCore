"You must be at least 120 cm tall to ride." "The elevator can carry at most 900 kg." Rules like these do not give one exact value: they allow a whole range of values. To describe a range, you use an **inequality**.

## What is an inequality?

:::definition Inequality
An **inequality** is a statement that two expressions are not equal, using one of the symbols $<$, $>$, $\le$ or $\ge$. For example, $x > 3$ says "$x$ is greater than $3$".
:::

| Symbol | Meaning | Key words |
|---|---|---|
| $<$ | less than | less than, fewer than, below, under |
| $>$ | greater than | more than, greater than, above, over |
| $\le$ | less than or equal to | at most, no more than, a maximum of, cannot exceed |
| $\ge$ | greater than or equal to | at least, no less than, a minimum of |

:::definition Solution set
The **solution set** of an inequality is the set of all values that make it true. The inequality $x > 3$ has infinitely many solutions: $4$, $3.5$, $100$ and many more.
:::

:::example Is it a solution?
Is $5$ a solution of $x > 3$? Of $x \le 5$? Of $x < 5$?
@step $5 > 3$ is true, so $5$ is a solution of $x > 3$.
@step $5 \le 5$ is true because $5 = 5$, so $5$ is a solution of $x \le 5$.
@step $5 < 5$ is false, so $5$ is not a solution of $x < 5$.
@answer Yes, yes and no.
:::

## Inequalities on a number line

A number line shows the whole solution set at once. Draw a dot at the **boundary** value, then an arrow over all the solutions.

- A **closed** (filled) dot means the boundary is included: $\le$ or $\ge$.
- An **open** dot means the boundary is not included: $<$ or $>$.
- The arrow points right for greater values and left for smaller values.

Which inequality does the number line above show? Use $x$ as the variable.
@step The dot is at $4$, so the boundary is $4$.
@step The dot is closed, so $4$ is included: the symbol is $\le$ or $\ge$.
@step The arrow points left, toward smaller values.
@answer $x \le 4$

## Writing inequalities for situations

To write an inequality for a situation, choose a variable, find the boundary value and pick the symbol from the key words.

:::example A height rule
To ride the Thunder Coaster at a summer fair, a rider must be at least 120 cm tall. Write an inequality and show it on a number line.
@step Let $h$ be a rider's height in centimetres.
@step "At least 120" means 120 or more, so the symbol is $\ge$: $h \ge 120$
@step Draw a closed dot at $120$ (120 cm is allowed) and an arrow to the right.
@answer $h \ge 120$
:::

Sometimes one side of the inequality is an expression.

:::example A taxi budget
A taxi charges \$4 plus \$2 per kilometre. Jamal can spend at most \$30. Write an inequality for the distance $k$, in kilometres, that he can travel.
@step The cost in dollars is $4 + 2k$.
@step "At most \$30" means the cost is less than or equal to 30.
@answer $4 + 2k \le 30$
:::

:::mistake At least and at most
"At least" sounds small, but it means the value can be that number **or more**, so it uses $\ge$. "At most" means that number **or less**, so it uses $\le$. "No more than" also means $\le$.
:::

:::check m9-inequality-represent 3
:::

:::summary
- An inequality uses $<$, $>$, $\le$ or $\ge$. Its solution set is every value that makes it true.
- On a number line: a closed dot for $\le$ and $\ge$, an open dot for $<$ and $>$, and an arrow toward the solutions.
- Key words: "at least" is $\ge$, "at most" and "no more than" are $\le$, "more than" is $>$, "less than" is $<$.
- To write an inequality for a situation, define a variable, write an expression and choose the symbol from the key words.
:::
