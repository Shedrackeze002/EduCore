$3x + 2x$ and $5x$ look different, but they always have the same value: try $x = 4$ and both give $20$. Expressions like these are **equivalent**. In this lesson you will simplify polynomials by writing equivalent ones with fewer terms.

## Like terms

:::definition Like terms
**Like terms** have the same variables raised to the same exponents. Only the coefficients can be different. $4x$ and $-x$ are like terms. $2xy$ and $-5xy$ are like terms. $3x^2$ and $3x$ are **not** like terms.
:::

With algebra tiles, like terms are tiles of the same shape. All $x$-tiles can be grouped together, but an $x$-tile can never be grouped with an $x^2$-tile.

:::example Find the like terms
Which terms are like terms in $3x^2 + 5x - x^2 + 2 - 4x$?
@step The $x^2$-terms are $3x^2$ and $-x^2$.
@step The $x$-terms are $5x$ and $-4x$.
@step The only constant is $2$.
@answer $3x^2$ and $-x^2$ are like terms, and $5x$ and $-4x$ are like terms.
:::

:::mistake Combining terms that are not alike
$3x + 2x^2$ is **not** $5x^3$ and not $5x^2$. The terms are different shapes of tile, so they stay as two terms. Also, $2x + 3x = 5x$, not $5x^2$: when you add like terms, add the coefficients and keep the variable part the same.
:::

## Zero pairs

Shaded tiles are positive and white tiles are negative.

:::definition Zero pair
A **zero pair** is one shaded tile and one white tile of the same kind. Together they are worth $0$, so you can remove them without changing the value.
:::

:::example Simplify with tiles
Simplify $4x + 2 - x - 5$ using the tiles above.
@step There are $4$ shaded $x$-tiles and $1$ white $x$-tile. Remove $1$ zero pair: $3$ shaded $x$-tiles are left, which is $3x$.
@step There are $2$ shaded unit tiles and $5$ white unit tiles. Remove $2$ zero pairs: $3$ white unit tiles are left, which is $-3$.
@answer $4x + 2 - x - 5 = 3x - 3$

## Collecting like terms with symbols

Tiles get slow with big numbers. With symbols, group the like terms and add their coefficients. Keep the sign in front of each term with it.

:::example Simplify a polynomial
Simplify $4x^2 - 3x + 7 - x^2 + 5x - 9$.
@step Group the like terms: $(4x^2 - x^2) + (-3x + 5x) + (7 - 9)$
@step Add the coefficients: $4 - 1 = 3$, $-3 + 5 = 2$ and $7 - 9 = -2$.
@answer $3x^2 + 2x - 2$
:::

:::tip Check by substituting
Equivalent expressions give the same value for every $x$. Try $x = 2$ in the example: $4(4) - 3(2) + 7 - 4 + 5(2) - 9 = 14$ and $3(4) + 2(2) - 2 = 14$. The values match.
:::

:::check m9-like-terms 2
:::

The same idea works with two variables. Remember that $xy$, $x^2$ and $y^2$ are three different kinds of term.

:::example Two variables
Simplify $2xy + 3y^2 - 5xy + y^2 - 4$.
@step Group the like terms: $(2xy - 5xy) + (3y^2 + y^2) - 4$
@step Add the coefficients: $2 - 5 = -3$ and $3 + 1 = 4$.
@answer $-3xy + 4y^2 - 4$
:::

:::mistake Losing a minus sign
In $7 - x^2 + 5x - 9$ the terms are $7$, $-x^2$, $5x$ and $-9$. When you move terms into groups, the minus sign travels with its term. Writing $+x^2$ or $+9$ changes the polynomial.
:::

:::check m9-like-terms 3
:::

:::summary
- Like terms have the same variables with the same exponents. Only like terms can be combined.
- A shaded tile and a white tile of the same kind form a zero pair worth $0$.
- To collect like terms, group them (keeping their signs) and add the coefficients. The variable part stays the same.
- Equivalent expressions have the same value for every value of the variable, so you can check by substituting.
:::
