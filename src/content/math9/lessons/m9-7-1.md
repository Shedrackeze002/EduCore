A phone zooms in on a photo. A print shop shrinks a poster down to a flyer. In both cases the picture keeps its shape but changes its size. That is what a scale diagram does.

## What is a scale diagram?

:::definition Scale diagram
A **scale diagram** is a drawing of an object where every length is multiplied by the same number. The shape stays the same; only the size changes.
:::

:::definition Scale factor
The **scale factor**, $k$, is the number every length is multiplied by:
$$k = \dfrac{\text{image length}}{\text{original length}}$$
The **original** is the object you start with. The **image** is the new drawing.
:::

:::example Finding a scale factor
Find the scale factor that takes logo A to logo B.
@step Pick a pair of matching sides: the bottom of A is $4\ \text{cm}$ and the bottom of B is $10\ \text{cm}$.
@step $k = \dfrac{\text{image}}{\text{original}} = \dfrac{10}{4} = 2.5$
@step Check with another pair: $\dfrac{15}{6} = 2.5$. Same answer, so B really is a scale diagram of A.
@answer The scale factor is $k = 2.5$. Every length on B is $2.5$ times the matching length on A.
:::

## Enlargements and reductions

:::definition Enlargement and reduction
If $k > 1$, the image is bigger: it is an **enlargement**. If $0 < k < 1$, the image is smaller: it is a **reduction**. If $k = 1$, the image is the same size.
:::

:::example A sticker that shrinks
A $12\ \text{cm}$ by $8\ \text{cm}$ sticker (A) is reduced so that its length is $9\ \text{cm}$ (B). Find the scale factor and the new width $x$.
@step $k = \dfrac{9}{12} = \dfrac{3}{4} = 0.75$
@step $k$ is less than 1, so this is a reduction.
@step $x = 0.75 \times 8 = 6$
@answer $k = 0.75$, and the new width is $x = 6\ \text{cm}$.
:::

:::mistake Dividing the wrong way
Always put the **image** on top. For the sticker, $\dfrac{12}{9} \approx 1.33$ would say the sticker got bigger, but it got smaller. A reduction must have a scale factor less than 1.
:::

:::tip Fractions or decimals
A scale factor can be a decimal or a fraction. When the decimal repeats, use the fraction. If a $6\ \text{cm}$ side becomes $4\ \text{cm}$, then $k = \dfrac{4}{6} = \dfrac{2}{3}$, which is exact, while $0.67$ is only close.
:::

## Finding new lengths

To find a length on the image, multiply the matching original length by $k$:
$$\text{image length} = k \times \text{original length}$$

:::example A poster becomes a flyer
A poster is $60\ \text{cm}$ long and $45\ \text{cm}$ wide. Liam reduces it with a scale factor of $0.4$ to make a flyer. Find the size of the flyer.
@step Length: $0.4 \times 60 = 24$
@step Width: $0.4 \times 45 = 18$
@answer The flyer is $24\ \text{cm}$ long and $18\ \text{cm}$ wide.
:::

## Working backward and multi-step problems

Sometimes you know the image and need the original. Undo the multiplication by dividing:
$$\text{original length} = \text{image length} \div k$$

:::example A model canoe
A model canoe is built with a scale factor of $0.05$. The model is $26\ \text{cm}$ long. How long is the real canoe?
@step $\text{original} = 26 \div 0.05 = 520\ \text{cm}$
@step $520\ \text{cm} = 5.2\ \text{m}$
@answer The real canoe is $5.2\ \text{m}$ long.
:::

:::example Enlarging a photo
Sofia has a $10\ \text{cm}$ by $15\ \text{cm}$ photo. She wants a scale copy whose shorter side is $25\ \text{cm}$. How long is the longer side?
@step Use the shorter sides to find $k$: $k = \dfrac{25}{10} = 2.5$
@step Apply $k$ to the longer side: $2.5 \times 15 = 37.5$
@answer The longer side of the copy is $37.5\ \text{cm}$.
:::

:::check m9-scale-factor 3
:::

:::summary
- In a scale diagram, every length is multiplied by the same scale factor $k$.
- $k = \dfrac{\text{image length}}{\text{original length}}$. Put the image on top.
- $k > 1$ is an enlargement. $0 < k < 1$ is a reduction.
- Image length $= k \times$ original length. Original length $=$ image length $\div k$.
- Use a fraction for $k$ when its decimal repeats.
:::
