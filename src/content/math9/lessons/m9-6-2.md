Some equations come with brackets, like $3(2x - 1) = 2(x + 5)$, or with the variable inside a fraction, like $\dfrac{x}{4} + 3 = 7$ or $\dfrac{24}{x} = 6$. Each one needs one extra step before the usual balancing. In this lesson you will learn that step for each kind.

## Equations with brackets

Use the distributive property to remove the brackets first. Then solve as before.

:::example One bracket
Solve $3(x - 4) = 18$.
@step Expand: $3x - 12 = 18$
@step Add $12$ to both sides: $3x = 30$
@step Divide both sides by $3$: $x = 10$
@step Check: $3(10 - 4) = 3(6) = 18$
@answer $x = 10$
:::

:::example Brackets on both sides
Solve $3(2x - 1) = 2(x + 5)$.
@step Expand both sides: $6x - 3 = 2x + 10$
@step Subtract $2x$ from both sides: $4x - 3 = 10$
@step Add $3$ to both sides: $4x = 13$
@step Divide both sides by $4$: $x = \dfrac{13}{4}$, which is $3.25$.
@step Check: left side $3(2(3.25) - 1) = 3(5.5) = 16.5$; right side $2(3.25 + 5) = 2(8.25) = 16.5$.
@answer $x = \dfrac{13}{4}$, or $3.25$
:::

:::mistake Multiplying only the first term
$2(x + 5)$ is $2x + 10$, not $2x + 5$. The number outside the bracket multiplies **every** term inside. With a negative number outside, watch the signs: $-4(x - 3) = -4x + 12$.
:::

The numbers outside the brackets can be decimals or fractions too.

:::example Decimal multipliers
Solve $0.5(4x + 6) = 1.5(2x - 2)$.
@step Expand: $2x + 3 = 3x - 3$
@step Subtract $2x$ from both sides: $3 = x - 3$
@step Add $3$ to both sides: $x = 6$
@step Check: left side $0.5(24 + 6) = 15$; right side $1.5(12 - 2) = 15$.
@answer $x = 6$
:::

## Equations with x divided by a number

In $\dfrac{x}{4} + 3 = 7$, the variable is divided by $4$. Undo the addition first, then undo the division by multiplying.

:::example Undo in reverse order
Solve $\dfrac{x}{4} + 3 = 7$.
@step Subtract $3$ from both sides: $\dfrac{x}{4} = 4$
@step Multiply both sides by $4$: $x = 16$
@step Check: $\dfrac{16}{4} + 3 = 4 + 3 = 7$
@answer $x = 16$
:::

:::example Fractions on both sides
Solve $\dfrac{x}{3} - \dfrac{1}{2} = \dfrac{5}{6}$.
@step Add $\dfrac{1}{2}$ to both sides: $\dfrac{x}{3} = \dfrac{5}{6} + \dfrac{3}{6} = \dfrac{8}{6} = \dfrac{4}{3}$
@step Multiply both sides by $3$: $x = 4$
@step Check: $\dfrac{4}{3} - \dfrac{1}{2} = \dfrac{8}{6} - \dfrac{3}{6} = \dfrac{5}{6}$
@answer $x = 4$
:::

## The variable in the denominator

In $\dfrac{24}{x} = 6$, the variable is in the denominator. Since you cannot divide by zero, $x \ne 0$. Multiply both sides by $x$ to bring it out of the denominator.

:::example A number divided by x
Solve $\dfrac{24}{x} = 6$.
@step Multiply both sides by $x$: $24 = 6x$
@step Divide both sides by $6$: $x = 4$
@step Check: $\dfrac{24}{4} = 6$
@answer $x = 4$
:::

:::example A negative answer
Solve $\dfrac{6}{x} = -4$.
@step Multiply both sides by $x$: $6 = -4x$
@step Divide both sides by $-4$: $x = \dfrac{6}{-4} = -\dfrac{3}{2}$, which is $-1.5$.
@step Check: $\dfrac{6}{-1.5} = -4$
@answer $x = -\dfrac{3}{2}$, or $-1.5$
:::

:::mistake Dividing the wrong way
From $6 = -4x$, the answer is $x = \dfrac{6}{-4}$, not $\dfrac{-4}{6}$. Divide both sides by the coefficient of $x$. A quick check catches this error: $\dfrac{6}{-\frac{2}{3}} = -9$, not $-4$.
:::

:::

:::summary
- With brackets, expand first using the distributive property, then collect terms and solve.
- For $\dfrac{x}{a} + b = c$, undo the $+b$ first, then multiply both sides by $a$.
- For $\dfrac{a}{x} = b$ (with $x \ne 0$), multiply both sides by $x$, then divide by $b$.
- Solutions can be integers, fractions or decimals. Check every solution in the original equation.
:::
