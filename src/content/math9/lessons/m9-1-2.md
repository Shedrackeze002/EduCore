Most numbers are not perfect squares. A square room with an area of $12.5\ \text{m}^2$ still has a side length, but it is not a tidy decimal. You can estimate it with benchmarks, then find it more closely with a calculator.

## Estimating with benchmarks

:::definition Non-perfect square
A **non-perfect square** is a number whose square root is not an exact fraction or decimal, such as $0.55$ or $\frac{2}{3}$. Its square root can only be estimated or rounded.
:::

:::definition Benchmark
A **benchmark** is a nearby perfect square that you know well. Benchmarks on each side of a number trap its square root between two values.
:::

:::example Estimating the square root of 0.55
Estimate $\sqrt{0.55}$ to two decimal places without a calculator.
@step Benchmarks: $0.7^2 = 0.49$ and $0.8^2 = 0.64$. Since $0.49 < 0.55 < 0.64$, the root is between $0.7$ and $0.8$.
@step $0.55$ is $0.06$ above $0.49$ and $0.09$ below $0.64$, so the root is closer to $0.7$.
@step Try $0.74$: $0.74^2 = 0.5476$, which is very close to $0.55$.
@answer $\sqrt{0.55} \approx 0.74$
:::

:::example A larger decimal
Between which two whole numbers is $\sqrt{52.4}$? Estimate it to one decimal place.
@step $7^2 = 49$ and $8^2 = 64$, so $7 < \sqrt{52.4} < 8$.
@step $52.4$ is much closer to $49$ than to $64$, so the root is a little more than $7$.
@answer $\sqrt{52.4}$ is between $7$ and $8$, about $7.2$ (check: $7.2^2 = 51.84$).
:::

:::mistake Halving is not square rooting
$\sqrt{0.5}$ is not $0.25$: $0.25^2 = 0.0625$. For a number between $0$ and $1$, the square root is **larger** than the number itself, because $0.7 \times 0.7 = 0.49$.
:::

## Using a calculator

A calculator gives a closer value. Round to the place the question asks for, then check by squaring.

:::example Rounding to the nearest hundredth
Find $\sqrt{2.7}$ and $\sqrt{\frac{3}{8}}$ to the nearest hundredth.
@step $\sqrt{2.7} \approx 1.6432$, so $\sqrt{2.7} \approx 1.64$. Check: $1.64^2 = 2.6896$, close to $2.7$.
@step For the fraction, divide first: $\frac{3}{8} = 0.375$.
@step $\sqrt{0.375} \approx 0.6124$
@answer $\sqrt{2.7} \approx 1.64$ and $\sqrt{\frac{3}{8}} \approx 0.61$.
:::

:::tip Estimate first
Estimate with benchmarks before you press any keys. If $\sqrt{2.7}$ came out as $5.2$ or $0.52$, the benchmarks $1^2 = 1$ and $2^2 = 4$ show that something went wrong.
:::

:::

## Working backwards

To find a number whose square root is between two values, **square** both values. Any number between the two squares works.

:::example A square root between 1.2 and 1.3
Find a number whose square root is between $1.2$ and $1.3$.
@step $1.2^2 = 1.44$ and $1.3^2 = 1.69$.
@step Choose any number between $1.44$ and $1.69$, such as $1.5$.
@answer $1.5$ works: $\sqrt{1.5} \approx 1.22$.
:::

:::mistake Choosing a number between the values
$1.25$ is between $1.2$ and $1.3$, but $\sqrt{1.25} \approx 1.12$. The number itself must be between the **squares**, $1.44$ and $1.69$.
:::

:::example A square patio
A square patio has an area of $12.5\ \text{m}^2$. How long is each side, to the nearest hundredth of a metre?
@step Estimate: $3^2 = 9$ and $4^2 = 16$, so the side is between $3\ \text{m}$ and $4\ \text{m}$.
@step $\sqrt{12.5} \approx 3.5355$
@answer Each side is about $3.54\ \text{m}$ long.
:::

:::

:::summary
- A non-perfect square has a square root that can only be estimated or rounded.
- Trap the square root between benchmarks: $0.49 < 0.55 < 0.64$, so $0.7 < \sqrt{0.55} < 0.8$.
- For numbers between $0$ and $1$, the square root is larger than the number.
- Use a calculator to round to the nearest hundredth, and check by squaring.
- A number whose square root is between $a$ and $b$ lies between $a^2$ and $b^2$.
:::
