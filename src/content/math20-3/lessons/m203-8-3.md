A number puzzle in the newspaper, a game of take-away on a lunch break and a riddle on a coffee cup all run on the same skill: reasoning with numbers. In this lesson you will look for patterns, solve magic squares and cage puzzles, and find strategies that win games.

## Number patterns

A pattern follows a rule. Some patterns **add** the same number each time, some **multiply** by the same number, and in some the **differences grow** by the same amount. Find the rule first, then use it.

:::example Toothpick squares
Figure $1$ uses $4$ toothpicks, figure $2$ uses $7$ and figure $3$ uses $10$. How many toothpicks does figure $20$ use?
@step Each new square shares a side with the one before it, so each figure adds $3$ toothpicks.
@step From figure $1$ to figure $20$ there are $19$ steps of $3$: $19 \times 3 = 57$.
@step $4 + 57 = 61$
@answer Figure $20$ uses $61$ toothpicks.
:::

:::mistake Counting shared sides twice
Twenty separate squares would use $20 \times 4 = 80$ toothpicks, but squares in a row share sides. Use the pattern of the figures, not the number of toothpicks in one square.
:::

You can also run the rule backward. Which figure uses $151$ toothpicks? Take away the first $4$, divide by $3$ to count the steps, then add $1$: $(151 - 4) \div 3 + 1 = 50$.

## Magic squares

:::definition Magic square
In a **magic square**, every row, every column and both diagonals add to the same number, called the **magic sum**.
:::

:::example Filling in a magic square
Find the missing numbers A, B, C and D in the magic square above.
@step The top row is complete: $18 + 16 + 11 = 45$, so the magic sum is $45$.
@step Left column: $18 + A + 19 = 45$, so $A = 45 - 37 = 8$.
@step Middle row: $8 + 15 + B = 45$, so $B = 45 - 23 = 22$.
@step Middle column: $16 + 15 + C = 45$, so $C = 45 - 31 = 14$.
@step Bottom row: $19 + 14 + D = 45$, so $D = 45 - 33 = 12$.
@answer $A = 8$, $B = 22$, $C = 14$ and $D = 12$. Check a diagonal: $18 + 15 + 12 = 45$.
:::

:::tip Look for a line with one gap
Each step uses a row, column or diagonal with only one missing number. In a $3$ by $3$ magic square, the centre number is always one-third of the magic sum: $15 = 45 \div 3$.
:::

## Cage puzzles and logic puzzles

In a **cage puzzle**, you fill a grid with the numbers $1$ to $3$ (or $1$ to $4$) so that each number appears once in every row and every column. Solid lines mark the **cages**, and the numbers in each cage add up to the small number in its corner.

:::

:::example Solving a cage puzzle
Solve the cage puzzle above.
@step The centre cell is a cage of one cell, so it is $1$.
@step The top-left cage needs two different numbers that add to $3$: $1$ and $2$. So the top-right cell is $3$.
@step The right cage adds to $5$ and starts with $3$, so the middle-right cell is $2$. The middle row is then $3,\ 1,\ 2$.
@step The left cage adds to $5$ and starts with $3$, so the bottom-left cell is $2$, and the top-left cell must be $1$. The top row is $1,\ 2,\ 3$.
@step The middle column has $2$ and $1$, so the bottom-middle cell is $3$, and the bottom-right is $1$. Check the cage: $3 + 1 = 4$.
@answer The rows are $1,\ 2,\ 3$; then $3,\ 1,\ 2$; then $2,\ 3,\ 1$. Only one grid fits every rule.
:::

A good logic puzzle has exactly one answer. Start with the clue that leaves the fewest possibilities, list them, and cross out any that break another clue.

:::example A mystery number
I am a two-digit number. My digits add up to $11$. I am a multiple of $4$. My tens digit is greater than my ones digit. What number am I?
@step Digits that add to $11$: $29,\ 38,\ 47,\ 56,\ 65,\ 74,\ 83,\ 92$.
@step Multiples of $4$ in that list: $56$ and $92$.
@step In $56$ the tens digit is smaller; in $92$ it is greater.
@answer The mystery number is $92$.
:::

## Winning strategies in games

:::definition Strategy
A **strategy** is a plan that tells you what to do on every turn, whatever the other player does.
:::

In a take-away game, two players take turns removing $1$, $2$ or $3$ counters from a pile, and the player who takes the **last** counter wins. To find a strategy, **work backward** from the end of the game.

:::example Twenty-one counters
There are $21$ counters and it is your turn. How many should you take?
@step If your opponent faces $4$ counters, whatever they take ($1$, $2$ or $3$), you take the rest and win.
@step So you want to leave your opponent $4$, $8$, $12$, $16$ or $20$: a multiple of $4$.
@step From $21$, taking $1$ leaves $20$.
@answer Take $1$ counter. Then, each round, take enough to make $4$ together with what your opponent took.
:::

:::mistake Grabbing as many as you can
Taking $3$ from $21$ leaves $18$, which is not a multiple of $4$. Your opponent can take $2$ to leave you $16$, and now they control the game.
:::

:::tip Change the rules, change the key numbers
If the player who takes the last counter **loses**, leave your opponent one more than a multiple of $4$: $1$, $5$, $9$, $13$, $17$ or $21$. If players may take $1$ to $4$, the key numbers go up by $5$ instead of $4$.
:::

:::check m203-number-puzzle 2
:::

:::summary
- Find the rule of a pattern first: add the same number, multiply by the same number, or differences that grow by the same amount.
- In a magic square, find the magic sum from a complete line, then fill a line with only one gap.
- In a cage puzzle, start with one-cell cages and cages with only one possible pair, and use the rule that each row and column has each number once.
- In a logic puzzle, start with the clue that leaves the fewest possibilities.
- In a take-away game, work backward to find the key numbers, and always leave your opponent on one.
:::
