“Is the capital of”, “is taller than”, “costs” — each of these phrases connects items from one set to items from another. Mathematics calls such a connection a **relation**, and there are several ways to show one.

## Sets and relations

:::definition Set and element
A **set** is a collection of distinct objects, written in braces, such as $\{2, 4, 6\}$. Each object is an **element** of the set.
:::

:::definition Relation
A **relation** associates elements of one set with elements of another set. It can be written as a set of **ordered pairs** (first element, second element).
:::

## Five ways to represent a relation

The relation “a number and its square” for $\{-2, -1, 0, 1, 2\}$ can be shown as:

**Words:** each number is paired with its square.

**Ordered pairs:** $\{(-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4)\}$

**Table:**

| $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ |
|---|---|---|---|---|---|
| $y$ | $4$ | $1$ | $0$ | $1$ | $4$ |

**Arrow diagram:**

:::figure

:::

**Graph:** plot each ordered pair as a point.

:::example Translating between forms
An arrow diagram has arrows $1 \to 5$, $2 \to 5$, $3 \to 7$. Write the relation as ordered pairs.
@answer $\{(1, 5), (2, 5), (3, 7)\}$
:::

## Independent and dependent variables

When one quantity depends on another:

- the **independent variable** is the input you choose or that changes on its own (it goes on the horizontal axis);
- the **dependent variable** is the output that depends on it (it goes on the vertical axis).

:::example Identifying variables
The cost of a taxi ride depends on the distance travelled.
@step The cost depends on the distance.
@answer Independent: distance. Dependent: cost.
:::

:::tip A quick test
Try saying “the ___ depends on the ___”. The first blank is the dependent variable.
:::

:::mistake Swapping the independent and dependent variables
The **independent** variable is the one you choose or control (time, number of tickets); the **dependent** variable is the one that results (distance, total cost). Ask "which one depends on the other?". The dependent variable goes on the vertical axis, and the order in each ordered pair is (independent, dependent).
:::

:::mistake Reversing the arrows in an arrow diagram
An arrow diagram for "is the capital of" points **from** each city **to** its province. Reading it backwards describes a different relation. Check one arrow out loud as a sentence before drawing the rest.
:::

:::summary
- A relation pairs elements of two sets; ordered pairs list (first, second).
- Relations can be shown in words, ordered pairs, tables, arrow diagrams and graphs.
- Independent variable: input (horizontal axis). Dependent variable: output (vertical axis).
:::
