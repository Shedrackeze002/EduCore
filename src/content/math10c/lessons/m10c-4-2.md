FOIL works for two binomials, but what about a binomial times a trinomial, or two trinomials? The distributive property handles them all.

## The general strategy

To multiply two polynomials, multiply **every term in the first** by **every term in the second**, then combine like terms. If the polynomials have $m$ and $n$ terms, there are $m \times n$ products before simplifying.

:::example Binomial × trinomial
Expand $(x + 3)(2x^2 - x + 4)$.
@step $x(2x^2 - x + 4) = 2x^3 - x^2 + 4x$
@step $3(2x^2 - x + 4) = 6x^2 - 3x + 12$
@step Add: $2x^3 - x^2 + 6x^2 + 4x - 3x + 12$
@answer $2x^3 + 5x^2 + x + 12$
:::

:::example Trinomial × trinomial
Expand $(x^2 + 2x - 1)(x^2 - 3x + 2)$.
@step $x^2(x^2 - 3x + 2) = x^4 - 3x^3 + 2x^2$
@step $2x(x^2 - 3x + 2) = 2x^3 - 6x^2 + 4x$
@step $-1(x^2 - 3x + 2) = -x^2 + 3x - 2$
@answer $x^4 - x^3 - 5x^2 + 7x - 2$
:::

:::tip Organize with a table
Write one polynomial across the top and the other down the side, fill in every cell, then add the diagonals of like terms. It is the area model again — and you will never miss a term.
:::

## Simplifying expressions with several products

Expand each product separately, then combine.

:::example A difference of products
Simplify $2(x + 1)(x - 4) - (x - 3)^2$.
@step $2(x + 1)(x - 4) = 2(x^2 - 3x - 4) = 2x^2 - 6x - 8$
@step $(x - 3)^2 = x^2 - 6x + 9$
@step Subtract the whole second product: $2x^2 - 6x - 8 - x^2 + 6x - 9$
@answer $x^2 - 17$
:::

:::mistake Subtracting a product
When you subtract a product, put it in brackets first. Every term changes sign: $-(x^2 - 6x + 9) = -x^2 + 6x - 9$.
:::

## Verifying by substitution

If two expressions are equal for every value of $x$, they must be equal for any value you choose. Substitute a simple number (avoid 0 and 1, which can hide errors) into both sides.

:::example Checking a product
Is $(x + 3)(2x - 1) = 2x^2 + 5x - 3$?
@step Let $x = 2$. Left: $(5)(3) = 15$. Right: $8 + 10 - 3 = 15$.
@answer The values match, so the product is very likely correct.
:::

If the two sides give different values, there is definitely an error.
