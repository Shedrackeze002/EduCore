Instead of writing $y = 3x - 2$, mathematicians often write $f(x) = 3x - 2$. This **function notation** names the function, shows the input, and makes it easy to talk about specific values.

## Reading function notation

:::definition Function notation
$f(x)$ is read “$f$ of $x$”. It means the output of the function $f$ when the input is $x$. It does **not** mean $f$ times $x$.
:::

- $y = 3x - 2$ becomes $f(x) = 3x - 2$.
- $f(4)$ means “the value of $f$ when $x = 4$”.
- $f(4) = 10$ means the point $(4, 10)$ is on the graph of $y = f(x)$.

Functions can have other names and variables: $g(t) = 7 + t$, $C(n) = 25 + 4n$.

## Finding an output: evaluate

Substitute the input for every $x$.

:::example Evaluating
For $f(x) = 3x - 2$, find $f(-1)$ and $f\left(\tfrac23\right)$.
@step $f(-1) = 3(-1) - 2 = -5$
@step $f\left(\tfrac23\right) = 3\left(\tfrac23\right) - 2 = 0$
:::

:::tip Use brackets
Write the substituted value in brackets, especially if it is negative: $3(-1)$, not $3 - 1$.
:::

## Finding an input: solve

If you know the output, set the expression equal to it and solve.

:::example Solving for the input
For $g(t) = 7 + t$, find $t$ so that $g(t) = 15$.
@step $7 + t = 15$
@answer $t = 8$
:::

:::example A fractional answer
For $h(x) = 4x - 5$, find $x$ when $h(x) = 1$.
@step $4x - 5 = 1$, so $4x = 6$
@answer $x = \tfrac32$
:::

## Using a graph

To find $f(a)$ from a graph, go to $x = a$ and read the height of the graph. To solve $f(x) = k$, go to $y = k$, move across to the graph, and read the $x$-value.

:::summary
- $f(x)$ means the output of $f$ for input $x$; $f(a) = b$ means $(a, b)$ is on the graph.
- Evaluate: substitute the input. Solve: set the function equal to the output and solve.
- On a graph: go across the $x$-axis to evaluate; go across from the $y$-axis to solve.
:::
