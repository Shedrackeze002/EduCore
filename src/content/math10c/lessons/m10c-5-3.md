A vending machine is a good picture of a **function**: press one button and you always get exactly one item. In this lesson you will learn what makes a relation a function and how to describe its **domain** and **range** precisely.

## Functions

:::definition Function
A **function** is a relation in which each element of the domain (each input $x$) is paired with **exactly one** element of the range (one output $y$).
:::

Every function is a relation, but not every relation is a function.

:::example Function or not?
(a) $\{(1, 3), (2, 5), (3, 3)\}$ (b) $\{(1, 3), (1, 5), (2, 7)\}$
@step (a) Each $x$ appears once. The repeated $y$-value 3 is fine. **Function.**
@step (b) $x = 1$ is paired with both 3 and 5. **Not a function.**
:::

:::mistake Repeated y-values are allowed
A function can send two inputs to the same output (two students can share a birthday). It cannot send one input to two outputs.
:::

## The vertical line test

On a graph, a repeated $x$-value means two points stacked vertically.

:::definition Vertical line test
A graph represents a function if **no vertical line** crosses the graph more than once.
:::

:::figure

:::

The dashed vertical line crosses this curve only once, and so would every other vertical line: it is a function. A circle or a sideways parabola fails the test.

## Domain and range

:::definition Domain and range
The **domain** is the set of all possible input values ($x$-values). The **range** is the set of all possible output values ($y$-values).
:::

For a **discrete** relation, list the values in a set:

:::example Discrete domain and range
For $\{(-1, 4), (0, 2), (2, 4), (5, -3)\}$:
@step Domain: $\{-1, 0, 2, 5\}$
@step Range: $\{-3, 2, 4\}$ (list each value once)
:::

For a **continuous** graph, describe an interval. There are several notations:

| Words | Set notation | Interval notation |
|---|---|---|
| $x$ is between $-2$ and $5$, inclusive | $\{x \mid -2 \le x \le 5,\ x \in \mathbb{R}\}$ | $[-2, 5]$ |
| $x$ is greater than $-2$, up to $5$ | $\{x \mid -2 < x \le 5,\ x \in \mathbb{R}\}$ | $(-2, 5]$ |
| $y$ is at least $1$ | $\{y \mid y \ge 1,\ y \in \mathbb{R}\}$ | $[1, \infty)$ |
| all real numbers | $\{x \mid x \in \mathbb{R}\}$ | $(-\infty, \infty)$ |

- A **closed dot** ● means the endpoint is included: $\le$ and a square bracket $[\ ]$.
- An **open dot** ○ means it is not included: $<$ and a round bracket $(\ )$.
- An **arrow** means the graph continues forever: $\infty$, always with a round bracket.

:::example A graph with endpoints
State the domain and range of the segment above (open dot at $(-3, -2)$, closed dot at $(4, 5)$).
@step Domain: $\{x \mid -3 < x \le 4,\ x \in \mathbb{R}\}$, or $(-3, 4]$
@step Range: $\{y \mid -2 < y \le 5,\ y \in \mathbb{R}\}$, or $(-2, 5]$

:::summary
- A function gives exactly one output for each input. Repeated $y$-values are fine; repeated $x$-values are not.
- Vertical line test: a graph is a function if no vertical line meets it more than once.
- Domain: all $x$-values. Range: all $y$-values.
- Closed dot → $\le$ and $[\ ]$; open dot → $<$ and $(\ )$; arrow → $\infty$.
:::
