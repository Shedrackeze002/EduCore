When no variable has a coefficient of 1, substitution creates fractions. **Elimination** avoids that by adding or subtracting the equations to make one variable disappear.

## Why elimination works

If $a = b$ and $c = d$, then $a + c = b + d$. Adding two true equations gives another true equation. If one variable has **opposite coefficients** in the two equations, adding eliminates it.

:::example Adding to eliminate
Solve $\begin{cases} 3x + 2y = 16 \\ 5x - 2y = 8 \end{cases}$
@step The $y$-coefficients are opposites. Add: $8x = 24$, so $x = 3$
@step Substitute: $3(3) + 2y = 16$, so $2y = 7$ and $y = \tfrac72$
@answer $\left(3, \tfrac72\right)$
:::

## Making coefficients opposites

Multiply one or both equations by a constant so a variable has opposite coefficients. Multiplying an equation by a non-zero constant gives an **equivalent equation** (the same line), so the solution does not change.

:::example Multiplying one equation
Solve $\begin{cases} 2x + 3y = 12 \\ x - y = 1 \end{cases}$
@step Multiply the second equation by 3: $3x - 3y = 3$
@step Add to the first: $5x = 15$, so $x = 3$
@step $3 - y = 1$, so $y = 2$
@answer $(3, 2)$
:::

:::example Multiplying both equations
Solve $\begin{cases} 4x + 3y = 5 \\ 3x - 2y = 8 \end{cases}$
@step To eliminate $y$, use the LCM of 3 and 2, which is 6. Multiply the first by 2 and the second by 3:
@step $8x + 6y = 10$ and $9x - 6y = 24$
@step Add: $17x = 34$, so $x = 2$
@step $4(2) + 3y = 5$, so $y = -1$
@answer $(2, -1)$
:::

:::mistake Subtracting carelessly
If you subtract one equation from another, subtract **every** term, including the constant. Many students prefer to multiply by a negative number and then add, which avoids this error.
:::

## Decimals and fractions

Clear them first by multiplying by 10, 100 or a common denominator.

:::example Decimal coefficients
Solve $\begin{cases} 0.2x + 0.5y = 1.6 \\ 0.3x - 0.1y = 0.7 \end{cases}$
@step Multiply both by 10: $2x + 5y = 16$ and $3x - y = 7$
@step Multiply the second by 5 and add: $2x + 5y + 15x - 5y = 16 + 35$, so $17x = 51$ and $x = 3$
@step $3(3) - y = 7$, so $y = 2$
@answer $(3, 2)$
:::

## Which method?

- A variable is already isolated, or has coefficient $\pm1$ → **substitution**.
- Coefficients are larger or matching → **elimination**.
- You want a picture or an estimate → **graphing**.

:::summary
- Add (or subtract) equations to eliminate a variable with opposite (or equal) coefficients.
- Multiply one or both equations first to create opposite coefficients.
- Clear decimals and fractions before eliminating.
- Choose the most efficient method for the system.
:::
