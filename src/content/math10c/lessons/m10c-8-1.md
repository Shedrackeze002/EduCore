A school sells 150 tickets to a play. Adult tickets cost \$12 and student tickets cost \$8, and the total is \$1480. How many of each were sold? One equation is not enough to answer — but **two** equations, solved together, are.

## Systems of linear equations

:::definition System of linear equations
Two or more linear equations that involve the same variables, considered together.
:::

:::definition Solution of a system
An ordered pair that makes **every** equation in the system true. Graphically, it is the **point of intersection** of the lines.
:::

## Modelling a situation

Define the variables, then write one equation for each piece of information.

:::example Writing a system
Write a system for the ticket problem above.
@step Let $a$ = number of adult tickets and $s$ = number of student tickets.
@step “150 tickets”: $a + s = 150$
@step “total \$1480”: $12a + 8s = 1480$
@answer $\begin{cases} a + s = 150 \\ 12a + 8s = 1480 \end{cases}$
:::

:::tip “How many” and “how much”
Many problems have one equation that counts things (how many) and one that adds their values (how much).
:::

## Verifying a solution

Substitute the ordered pair into **both** equations.

:::example Is it a solution?
Is $(70, 80)$ the solution of the ticket system?
@step $70 + 80 = 150$ ✓
@step $12(70) + 8(80) = 840 + 640 = 1480$ ✓
@answer Yes: 70 adult tickets and 80 student tickets.
:::

## Solving by graphing

1. Write each equation in a form that is easy to graph (slope-intercept or intercepts).
2. Graph both lines on the same grid.
3. Read the point of intersection.
4. Verify it in both equations.

:::example Solving graphically
Solve $y = x + 1$ and $y = -x + 5$ by graphing.
@step The lines intersect at $(2, 3)$.
@step Check: $3 = 2 + 1$ ✓ and $3 = -2 + 5$ ✓
@answer $(2, 3)$
:::

:::tip Limitations of graphing
Graphing works well when the solution has integer coordinates. When it does not, you can only estimate — algebraic methods (next lessons) give exact answers. Graphing technology can find intersections precisely.
:::

:::mistake Checking only one equation
A solution to a system must make **both** equations true. $(10, 140)$ might satisfy the ticket count but not the total cost. Always substitute into both equations.
:::

:::mistake Reading an approximate intersection as exact
On a hand-drawn graph, the intersection might look like $(3, 5)$ when it is really $(3.2, 4.9)$. Treat a graphical solution as an estimate and verify it algebraically.
:::

:::summary
- A system is two or more equations considered together; its solution satisfies all of them.
- Graphically, the solution is the point of intersection.
- To model, define variables and write one equation per fact.
- Always verify a solution in every equation.
:::
