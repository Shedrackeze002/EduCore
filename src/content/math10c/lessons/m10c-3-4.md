$\sqrt{72}$ and $6\sqrt{2}$ are the same number written two different ways. Being able to move between these forms lets you simplify answers and compare radicals without a calculator.

## The multiplication property of radicals

$$\sqrt[n]{ab} = \sqrt[n]{a} \times \sqrt[n]{b} \quad (\text{for } a, b \ge 0 \text{ when } n \text{ is even})$$

For example, $\sqrt{4 \times 9} = \sqrt{36} = 6$ and $\sqrt{4} \times \sqrt{9} = 2 \times 3 = 6$.

:::definition Entire and mixed radicals
An **entire radical** has nothing outside the radical sign, like $\sqrt{72}$. A **mixed radical** has a coefficient outside, like $6\sqrt{2}$.
:::

## Entire radical → mixed radical

1. Find the **largest perfect square** factor of the radicand (or perfect cube, for a cube root).
2. Split the radical and take the root of that factor.

:::example Simplifying a square root
Write $\sqrt{72}$ as a mixed radical in simplest form.
@step Perfect-square factors of 72: 4, 9, 36. The largest is 36.
@step $\sqrt{72} = \sqrt{36 \times 2} = \sqrt{36}\sqrt{2}$
@answer $\sqrt{72} = 6\sqrt{2}$
:::

:::example Using prime factors
Simplify $\sqrt{180}$.
@step $180 = 2^2 \times 3^2 \times 5$
@step Pairs come out: $\sqrt{2^2 \times 3^2 \times 5} = 2 \times 3 \sqrt{5}$
@answer $6\sqrt{5}$
:::

:::example A cube root
Simplify $\sqrt[3]{54}$.
@step Largest perfect-cube factor of 54 is 27: $54 = 27 \times 2$
@answer $\sqrt[3]{54} = 3\sqrt[3]{2}$
:::

:::definition Simplest form
A radical is in simplest form when the radicand has no perfect-square factor other than 1 (or no perfect-cube factor, for cube roots).
:::

:::mistake Not using the largest factor
$\sqrt{72} = \sqrt{4 \times 18} = 2\sqrt{18}$ is correct but **not simplified**, because 18 still contains the perfect square 9. Continue: $2\sqrt{9 \times 2} = 6\sqrt{2}$.
:::

## Mixed radical → entire radical

Write the coefficient as a radical with the same index, then multiply the radicands.

:::example Square root
Write $4\sqrt{3}$ as an entire radical.
@step $4 = \sqrt{16}$
@answer $4\sqrt{3} = \sqrt{16}\sqrt{3} = \sqrt{48}$
:::

:::example Cube root
Write $2\sqrt[3]{5}$ as an entire radical.
@step $2 = \sqrt[3]{8}$
@answer $2\sqrt[3]{5} = \sqrt[3]{40}$
:::

## Comparing radicals

Rewrite mixed radicals as entire radicals with the same index; the larger radicand is the larger number.

:::example Which is greater?
Compare $3\sqrt{5}$ and $2\sqrt{11}$.
@step $3\sqrt{5} = \sqrt{45}$ and $2\sqrt{11} = \sqrt{44}$
@answer $3\sqrt{5}$ is greater (just barely).
:::

:::summary
- $\sqrt[n]{ab} = \sqrt[n]{a}\sqrt[n]{b}$.
- To simplify, pull out the **largest** perfect square (or cube) factor.
- To make an entire radical, write the coefficient as a radical and multiply radicands.
- Compare radicals by writing them as entire radicals.
:::
