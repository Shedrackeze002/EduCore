Every non-vertical line can be described by two numbers: how steep it is and where it crosses the $y$-axis. **Slope-intercept form** puts both numbers right in the equation.

## Slope-intercept form

:::definition Slope-intercept form
$$y = mx + b$$
where $m$ is the **slope** and $b$ is the **y-intercept** (the line passes through $(0, b)$).
:::

Why does this work? At $x = 0$, $y = m(0) + b = b$, so $(0, b)$ is on the line. And each time $x$ increases by 1, $y$ increases by $m$ — a constant rate of change.

:::example Reading m and b
State the slope and $y$-intercept of (a) $y = -3x + 7$ (b) $y = \tfrac{x}{2} - 4$ (c) $y = 5$.
@step (a) $m = -3$, $b = 7$
@step (b) $\tfrac{x}{2} = \tfrac12 x$, so $m = \tfrac12$, $b = -4$
@step (c) $y = 0x + 5$: $m = 0$, $b = 5$ (horizontal line)
:::

:::example Rearranging first
Find the slope and $y$-intercept of $4x + 2y = 10$.
@step Isolate $y$: $2y = -4x + 10$
@step Divide by 2: $y = -2x + 5$
@answer $m = -2$, $b = 5$
:::

:::mistake Taking b without its sign
In $y = 3x - 8$, the $y$-intercept is $-8$, not $8$.
:::

## Graphing from y = mx + b

1. Plot the $y$-intercept $(0, b)$.
2. Use the slope as rise over run to plot a second point.
3. Draw the line through the points (a third point is a good check).

:::example Graphing
Graph $y = -\tfrac23 x + 4$.
@step Plot $(0, 4)$.
@step Slope $-\tfrac23$: right 3, down 2, giving $(3, 2)$.
@step Draw the line through $(0, 4)$ and $(3, 2)$.
:::

## Writing the equation from a graph

1. Read $b$ where the line crosses the $y$-axis.
2. Count rise over run between two grid points to find $m$.
3. Write $y = mx + b$.

:::example From a graph
A line crosses the $y$-axis at $-2$ and passes through $(4, 1)$.
@step $b = -2$
@step From $(0, -2)$ to $(4, 1)$: rise 3, run 4, so $m = \tfrac34$
@answer $y = \tfrac34 x - 2$
:::

:::tip Typing equations
Type fractions as `3/4x` or `(3/4)x`. For example: `y = 3/4x - 2`.
:::
