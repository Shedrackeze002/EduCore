Before you can find a mode, you need data. Good data starts with a good question. Then a table or a graph shows the frequencies so everyone can read them at a glance.

## Closed-list and open-ended questions

:::definition Closed-list and open-ended questions
A **closed-list question** gives a list of answers to choose from. An **open-ended question** lets people give any answer they like.
:::

| Open-ended | Closed-list |
|---|---|
| What sport do you like to play? | Which sport do you like to play best: hockey, soccer, basketball or volleyball? |
| What do you eat for breakfast? | What do you eat most often for breakfast: cereal, toast, eggs or other? |

Open-ended answers can be all different, so they are hard to count. You can still sort them into **categories**. For example, breakfast answers can be grouped into grains, fruit, dairy and other.

:::example Choosing a survey question
Your class wants to answer the statistical question "Which sport should our class play on fun day?" Write a good closed-list question.
@step The question must be about the same topic: sports for fun day.
@step Give a short list of choices that the class could really play.
@answer "Which sport would you like to play on fun day: soccer, basketball, kickball or relay races?" The mode of the answers answers the statistical question.
:::

## Frequency tables

:::definition Frequency table
A **frequency table** lists each category and its frequency.
:::

:::example Organizing answers
Students answered "Which season do you like best: winter, spring, summer or fall?" The answers were: Summer, Winter, Summer, Fall, Spring, Summer, Winter, Summer, Fall, Summer, Winter, Spring. Make a frequency table.
@step Tally each answer and cross it off: Winter `|||`, Spring `||`, Summer `|||||`, Fall `||`.
@step Write the counts: Winter $3$, Spring $2$, Summer $5$, Fall $2$.
@step Check: $3 + 2 + 5 + 2 = 12$ answers ✓
@answer Winter $3$, Spring $2$, Summer $5$, Fall $2$.
:::

## Bar graphs and dot plots

A **bar graph** shows each frequency as the height of a bar. Check the scale on the side before you read a bar.

:::definition Dot plot
A **dot plot** shows each data value as one dot above a number line. The dots stack up, so the height of each stack is the frequency.
:::

:::figure

:::

:::example Reading a dot plot
Each dot is one student. How many students have $2$ pets, and what is the mode?
@step Count the dots above $2$: there are $4$.
@step The tallest stack is above $1$. It has $5$ dots.
@answer $4$ students have $2$ pets. The mode is $1$ pet.
:::

:::mistake Counting the number instead of the dots
The number under a stack is the data value. The number of dots in the stack is its frequency.
:::

## Stem-and-leaf plots

:::definition Stem-and-leaf plot
A **stem-and-leaf plot** splits each number into a **stem** (the tens digit) and a **leaf** (the ones digit). Each leaf is one data value.
:::

Students counted how many times they could skip rope in one minute. In the plot, $3 \mid 4$ means $34$.

:::figure
{"type":"table","headers":["Stem","Leaf"],"rows":[["2","5 8"],["3","0 4 4 7 9"],["4","1 2 6"],["5","3"]]}
:::

:::example Reading a stem-and-leaf plot
How many students skipped from $30$ to $39$ times? How many skipped more than $40$ times?
@step The values from $30$ to $39$ are in the row with stem $3$: $30, 34, 34, 37, 39$. That is $5$ students.
@step More than $40$: the row with stem $4$ gives $41, 42, 46$, and the row with stem $5$ gives $53$.
@step $3 + 1 = 4$
@answer $5$ students skipped from $30$ to $39$ times, and $4$ students skipped more than $40$ times.
:::

:::tip Each row is a category
The rows of a stem-and-leaf plot work like categories: the twenties, the thirties, and so on. The number of leaves in a row is its frequency.
:::

:::summary
- A closed-list question gives choices. An open-ended question allows any answer. Open-ended answers can be sorted into categories.
- A frequency table lists each category and its frequency. The frequencies add up to the number of answers.
- A bar graph shows frequency as the height of a bar. A dot plot shows one dot for each value.
- In a stem-and-leaf plot, the stem is the tens digit and each leaf is one value.
:::
