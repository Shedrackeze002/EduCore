A school collected $45\,678$ cans in the fall and $23\,457$ cans in the spring. How many is that in all? With big numbers, it helps to have a set of steps that always works. That set of steps is called the standard algorithm.

## Adding with the standard algorithm

:::definition Standard algorithm
A **standard algorithm** is a set of steps that always works for a type of calculation. For adding and subtracting, you write the numbers in columns by place value and work from right to left.
:::

:::definition Regroup
To **regroup** is to trade $10$ of one place for $1$ of the next place to the left, or $1$ of a place for $10$ of the place to its right. For example, $13$ ones is $1$ ten and $3$ ones.
:::

To add:

1. Line up the digits by place value: ones under ones, tens under tens.
2. Add each column, starting on the **right**.
3. If a column adds to $10$ or more, write the ones digit and **carry** $1$ to the next column.

:::example Adding cans
Find $45\,678 + 23\,457$.
@step Ones: $8 + 7 = 15$. Write $5$ and carry $1$ to the tens.
@step Tens: $1 + 7 + 5 = 13$. Write $3$ and carry $1$. Hundreds: $1 + 6 + 4 = 11$. Write $1$ and carry $1$.
@step Thousands: $1 + 5 + 3 = 9$. Ten thousands: $4 + 2 = 6$.
@step $$\begin{array}{r}4\,\overset{1}{5}\,\overset{1}{6}\,\overset{1}{7}\,8 \\ +\ 2\,3\,4\,5\,7 \\ \hline 6\,9\,1\,3\,5\end{array}$$
@answer $45\,678 + 23\,457 = 69\,135$
:::

The small $1$s are the carries. They remind you to add $1$ more in that column.

:::

## Subtracting with the standard algorithm

To subtract, line up the places and start on the right. If the top digit is too small, **regroup** $1$ from the place to the left.

:::example Regrouping across zeros
Find $5003 - 1278$.
@step Ones: $3$ is less than $8$. The tens and hundreds are $0$, so go to the thousands.
@step Regroup $1$ thousand as $10$ hundreds. Then $1$ hundred as $10$ tens. Then $1$ ten as $10$ ones. Now the top digits are $4$, $9$, $9$ and $13$.
@step Ones: $13 - 8 = 5$. Tens: $9 - 7 = 2$. Hundreds: $9 - 2 = 7$. Thousands: $4 - 1 = 3$.
@step $$\begin{array}{r}\overset{4}{\cancel{5}}\,\overset{9}{\cancel{0}}\,\overset{9}{\cancel{0}}\,\overset{13}{\cancel{3}} \\ -\ 1\,2\,7\,8 \\ \hline 3\,7\,2\,5\end{array}$$
@answer $5003 - 1278 = 3725$
:::

:::mistake Taking the smaller digit from the bigger one
In the ones column, $3 - 8$ is **not** $8 - 3$. When the top digit is smaller, regroup first. Always subtract the bottom digit from the top digit.
:::

:::tip Check with addition
Add your answer to the number you subtracted. You should get the top number: $3725 + 1278 = 5003$.
:::

## Adding and subtracting decimals

With decimals, **line up the decimal points**. Then every digit is under a digit with the same place value. Add zeros at the right end so the numbers have the same number of decimal places. These zeros do not change the values.

:::example Adding decimals
Find $12.5 + 3.875$.
@step Line up the decimal points. Write $12.5$ as $12.500$.
@step Thousandths: $0 + 5 = 5$. Hundredths: $0 + 7 = 7$. Tenths: $5 + 8 = 13$. Write $3$ and carry $1$.
@step Ones: $1 + 2 + 3 = 6$. Tens: bring down the $1$.
@step $$\begin{array}{r}1\,\overset{1}{2}.\,5\,0\,0 \\ +\ \phantom{0}\,3.\,8\,7\,5 \\ \hline 1\,6.\,3\,7\,5\end{array}$$
@answer $12.5 + 3.875 = 16.375$
:::

:::example Subtracting from a whole number
Find $8 - 3.465$.
@step A whole number has its decimal point after the ones digit. Write $8$ as $8.000$.
@step Regroup $1$ one as $10$ tenths, $1$ tenth as $10$ hundredths, and $1$ hundredth as $10$ thousandths.
@step $$\begin{array}{r}\overset{7}{\cancel{8}}.\,\overset{9}{\cancel{0}}\,\overset{9}{\cancel{0}}\,\overset{10}{\cancel{0}} \\ -\ 3.\,4\,6\,5 \\ \hline 4.\,5\,3\,5\end{array}$$
@answer $8 - 3.465 = 4.535$
:::

:::mistake Lining up the last digits
If you line up the last digits of $12.5 + 3.875$, the $5$ tenths sits over the $5$ thousandths. The sum would come out less than $12.5$, which cannot be right. Line up the **decimal points**, not the right ends.
:::

:::

## Finding a missing number

Addition and subtraction undo each other. You can use one to find a missing number in the other.

:::example What goes in the box?
$\square + 3.85 = 10.2$
@step Adding $3.85$ gave $10.2$. To undo it, subtract: $10.2 - 3.85$.
@step Write $10.2$ as $10.20$. Then $10.20 - 3.85 = 6.35$.
@step Check: $6.35 + 3.85 = 10.2$.
@answer The missing number is $6.35$.
:::

:::check m5-add-subtract 3
:::

:::summary
- Line up the places, then add or subtract each column from right to left.
- Carry when a column adds to $10$ or more. Regroup when a top digit is too small.
- For decimals, line up the decimal points and add zeros at the right end.
- Check a subtraction by adding, and find a missing number with the opposite operation.
:::
