Maps, game boards and computer screens use grids to tell exactly where things are. On a coordinate grid, two numbers are all you need to find a spot.

## The coordinate grid

:::definition Coordinate grid
A **coordinate grid** has a **horizontal axis** (going across) and a **vertical axis** (going up). The axes meet at the point $(0,\ 0)$. Points sit where a vertical grid line and a horizontal grid line meet.
:::

:::definition Coordinates
The **coordinates** of a point are an **ordered pair** of numbers, like $(4,\ 6)$. The first number is the distance from the vertical axis: how far **across**. The second number is the distance from the horizontal axis: how far **up**.
:::

:::figure

:::

:::example Reading a point
What are the coordinates of point $P$?
@step Start at $(0,\ 0)$. Count across the horizontal axis to the line below $P$: $4$.
@step Count up from the horizontal axis to $P$: $6$.
@answer $P$ is at $(4,\ 6)$.
:::

:::mistake Across first, then up
The order matters. $(2,\ 5)$ and $(5,\ 2)$ are different points. Always write the across number first and the up number second.
:::

## Locating a point

To find the point for a pair of coordinates, start at $(0,\ 0)$. Move across by the first number. Then move up by the second number.

:::example Plotting a point
Plot the point $(6,\ 2)$.
@step Start at $(0,\ 0)$.
@step Move $6$ across, along the horizontal axis.
@step Move $2$ up. Mark the point where the grid lines meet.
@answer The point is $6$ across and $2$ up.
:::

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":10,"yMin":0,"yMax":10,"step":1},"segments":[{"from":[0,0],"to":[6,0],"color":"accent","dashed":true,"arrowEnd":true},{"from":[6,0],"to":[6,2],"color":"accent","dashed":true,"arrowEnd":true}],"points":[{"x":6,"y":2,"label":"(6, 2)","color":"brand"}],"caption":"The point (6, 2): 6 across, then 2 up"}
:::

:::tip Points on the axes
A point with first number $0$, like $(0,\ 4)$, is on the vertical axis. A point with second number $0$, like $(5,\ 0)$, is on the horizontal axis.
:::

## Describing one point from another

We can also describe where a point is compared to another point. Use the words **left**, **right**, **up** and **down**.

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":10,"yMin":0,"yMax":10,"step":1},"segments":[{"from":[2,3],"to":[7,3],"color":"accent","dashed":true,"arrowEnd":true},{"from":[7,3],"to":[7,5],"color":"accent","dashed":true,"arrowEnd":true}],"points":[{"x":2,"y":3,"label":"A","color":"brand"},{"x":7,"y":5,"label":"B","color":"brand"}],"caption":"From A(2, 3) to B(7, 5): 5 right, then 2 up"}
:::

:::example From A to B
$A$ is at $(2,\ 3)$ and $B$ is at $(7,\ 5)$. Describe how to move from $A$ to $B$.
@step Across: from $2$ to $7$ is $7 - 2 = 5$. The first number gets bigger, so move right.
@step Up or down: from $3$ to $5$ is $5 - 3 = 2$. The second number gets bigger, so move up.
@answer Move $5$ units right and $2$ units up.
:::

:::tip Which number changes?
Moving right or left changes the **first** number: right adds, left subtracts. Moving up or down changes the **second** number: up adds, down subtracts.
:::

:::mistake Going the other way
From $B$ back to $A$ is **not** the same move. It is $5$ units left and $2$ units down.
:::

:::check m5-grid-points 2
:::

## Planning a path

Some problems have more than one move. Do one move at a time and write the new point after each move.

:::example A campground map
On a map, the tent is at $(1,\ 2)$. Kiona walks $6$ units right to the washroom, then $4$ units up to the dock. Where is the dock?
@step Start at $(1,\ 2)$. Moving $6$ right: $1 + 6 = 7$. The washroom is at $(7,\ 2)$.
@step Moving $4$ up from $(7,\ 2)$: $2 + 4 = 6$.
@answer The dock is at $(7,\ 6)$.
:::

:::check m5-grid-points 3
:::

:::summary
- A coordinate grid has a horizontal axis and a vertical axis that meet at $(0,\ 0)$.
- Coordinates are an ordered pair: (how far across, how far up).
- The order matters: $(2,\ 5)$ and $(5,\ 2)$ are different points.
- Right and left change the first number. Up and down change the second number.
:::
