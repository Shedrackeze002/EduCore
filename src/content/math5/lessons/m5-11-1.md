Maya stacks cups in towers: $3$ cups, then $5$, then $7$, then $9$. Each tower has $2$ more cups than the one before. Patterns like this are everywhere, and today you will show them in tables and on grids.

## Positions and terms

:::definition Sequence, term and position
A **sequence** is a list of numbers in order. Each number in the list is a **term**. The **position** tells where a term is in the list: first, second, third, and so on. Positions are the natural numbers $1, 2, 3, \ldots$
:::

:::definition Arithmetic sequence
In an **arithmetic sequence**, you add the same number each time to get the next term.
:::

The sequence $3, 5, 7, 9, \ldots$ is arithmetic. You add $2$ each time. The term $3$ is at position $1$. The term $9$ is at position $4$.

:::example Finding a term by its position
What is the term at position $3$ in the sequence $4, 10, 16, 22, \ldots$?
@step Count along the list: position $1$ is $4$, position $2$ is $10$, position $3$ is $16$.
@answer The term at position $3$ is $16$.
:::

:::mistake Starting at zero
The first term is at position $1$, not position $0$. Always start counting positions at $1$.
:::

## Tables of values

:::definition Table of values
A **table of values** for a sequence lists the positions in the first row (or column) and the terms in the second row (or column). Each position matches exactly one term.
:::

@step Position $4$: $13 + 4 = 17$
@step Check with position $5$: $17 + 4 = 21$ ✓
@answer The missing term is $17$.

## Points on a grid

Each position and its term make an ordered pair: **(position, term)**. The position comes first. The term comes second. You can plot each pair as a point on a grid.

:::example Writing points
Write the first four terms of $2, 4, 6, 8, \ldots$ as points.
@step Position $1$, term $2$: the point is $(1, 2)$.
@step Position $2$, term $4$: the point is $(2, 4)$.
@step Then $(3, 6)$ and $(4, 8)$.
@answer The points are $(1, 2)$, $(2, 4)$, $(3, 6)$ and $(4, 8)$.
:::

The point for position $3$ and term $6$ is $(3, 6)$, not $(6, 3)$. Position first, term second.

## The graph is a straight line

Look at the graph above. Each point is $1$ step to the right and $2$ steps up from the one before. The steps are always the same, so the points lie on a **straight line**.

This is true for every arithmetic sequence. Because you add the same number each time, every point goes up by the same amount.

:::tip Use the line to check your work
If one point is not on the same straight line as the others, a term is wrong.
:::

:::example Going past the graph
A graph shows the points $(1, 5)$, $(2, 8)$, $(3, 11)$ and $(4, 14)$. If the pattern continues, what is the term at position $6$?
@step The terms go up by $3$ each time: $8 - 5 = 3$.
@step Position $5$: $14 + 3 = 17$
@step Position $6$: $17 + 3 = 20$
@answer The term at position $6$ is $20$. Its point is $(6, 20)$, on the same straight line.
:::

:::check m5-sequence-table 3
:::

:::summary
- A sequence is a list of terms. The position tells where a term is, starting at $1$.
- In an arithmetic sequence, you add the same number each time.
- A table of values lists positions in one row and terms in the other.
- Each position and term make a point (position, term).
- The points of an arithmetic sequence lie on a straight line.
:::
