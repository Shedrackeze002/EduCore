Your class is choosing a snack for the fun fair. Everyone votes. How do you find the winner fairly? You count the votes for each snack, and that count has a name: **frequency**.

## Categories and frequency

:::definition Category and frequency
A **category** is a group that answers fit into, such as "apple" or "banana". The **frequency** of a category is how many times it appears in the data.
:::

Students named their favourite fruit:

Apple, Banana, Apple, Grapes, Banana, Apple, Orange, Apple, Grapes, Banana

:::example Counting a frequency
What is the frequency of Apple? Make a tally chart to organize all the answers.
@step Go through the list one answer at a time. Make a tally mark for each one and cross it off.
@step Apple: `||||` → $4$. Banana: `|||` → $3$. Grapes: `||` → $2$. Orange: `|` → $1$.
@step Check: $4 + 3 + 2 + 1 = 10$ answers, the same as the list ✓
@answer The frequency of Apple is $4$.
:::

:::

In a tally chart, each group `|||||` stands for $5$. Count by fives, then count the extra marks.

## The mode

:::definition Mode
The **mode** is the category with the greatest frequency. It is the most common answer.
:::

:::figure
{"type":"barChart","categories":["Popcorn","Cheese","Crackers","Yogurt"],"values":[6,4,9,3],"valueLabel":"Number of students","categoryLabel":"Snack","max":10,"step":1}
:::

:::example Reading the mode from a bar graph
The bar graph shows the snack votes. What is the mode?
@step Find the tallest bar: Crackers, with a frequency of $9$.
@step No other bar is that tall.
@answer The mode is Crackers.
:::

:::mistake The mode is not a number of votes
The mode is a **category**. In the graph, the mode is Crackers, not $9$. The $9$ is the frequency of the mode.
:::

## No mode, or more than one mode

Data does not always have exactly one mode.

| Frequencies | Mode |
|---|---|
| Hockey $7$, Soccer $5$, Swimming $3$ | One mode: Hockey |
| Hockey $6$, Soccer $6$, Swimming $3$ | Two modes: Hockey and Soccer |
| Hockey $4$, Soccer $4$, Swimming $4$ | No mode |

:::example Two modes
A class voted for a season: Winter $5$, Spring $8$, Summer $8$, Fall $4$. What is the mode?
@step The greatest frequency is $8$.
@step Two categories have $8$: Spring and Summer.
@answer There are two modes: Spring and Summer.
:::

If every category has the same frequency, no answer is more common than the others, so there is **no mode**.

## Using the mode to answer a question

A **statistical question** is a question you answer by collecting data, such as "Which snack should our class sell?" The mode is often the best answer, because more people chose it than any other answer.

:::example Numbers as categories
Students said how many pets they have: $0, 2, 1, 1, 3, 1, 0, 2, 1, 4, 1, 2$. What is the mode, and what is its frequency?
@step Count each value: $0$ appears $2$ times, $1$ appears $5$ times, $2$ appears $3$ times, $3$ appears $1$ time, $4$ appears $1$ time.
@step The value that appears most often is $1$.
@answer The mode is $1$ pet. Its frequency is $5$: five students have $1$ pet.
:::

:::tip Data value or frequency?
Here the categories are numbers, so be careful. The data value ($1$ pet) is the category. The frequency ($5$ students) is how many times it appears.
:::

:::check m5-frequency-mode 3
:::

:::summary
- The frequency of a category is how many times it appears. It is a count, not the data value itself.
- A tally chart helps you count. Each `|||||` is $5$.
- The mode is the category with the greatest frequency.
- Data can have one mode, more than one mode, or no mode.
- Use the mode to answer a statistical question: it is the most common answer.
:::
