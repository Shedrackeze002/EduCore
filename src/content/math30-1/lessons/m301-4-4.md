The equation $\sin\theta = \frac{1}{2}$ has two solutions in one turn of the unit circle, and infinitely many if the angle can keep turning. Solving a trigonometric equation means finding all of the solutions in the domain you are given.

## Solving over one rotation

A **first-degree trigonometric equation** contains one trigonometric ratio, raised to the first power. Solve it in four steps:

1. Isolate the ratio, as you would isolate $x$.
2. Find the reference angle from the **positive** value of the ratio.
3. Use the CAST rule (or the signs of $x$ and $y$ on the unit circle) to find the quadrants where the ratio has the given sign.
4. Place the reference angle in each of those quadrants, within the domain.

:::example In degrees
Solve $2\cos\theta + 1 = 0$ for $0^\circ \le \theta < 360^\circ$.
@step $2\cos\theta = -1$, so $\cos\theta = -\dfrac{1}{2}$.
@step $\cos\theta_R = \dfrac{1}{2}$ gives $\theta_R = 60^\circ$.
@step Cosine is negative in quadrants II and III: $\theta = 180^\circ - 60^\circ$ or $\theta = 180^\circ + 60^\circ$.
@answer $\theta = 120^\circ$ or $\theta = 240^\circ$
:::

:::example In radians
Solve $\sqrt{2}\sin\theta + 1 = 0$ for $0 \le \theta < 2\pi$.
@step $\sin\theta = -\dfrac{1}{\sqrt{2}} = -\dfrac{\sqrt{2}}{2}$, so $\theta_R = \dfrac{\pi}{4}$.
@step Sine is negative in quadrants III and IV: $\theta = \pi + \dfrac{\pi}{4}$ or $\theta = 2\pi - \dfrac{\pi}{4}$.
@answer $\theta = \dfrac{5\pi}{4}$ or $\theta = \dfrac{7\pi}{4}$
:::

The graph shows the same solutions: $y = \sin\theta$ meets the line $y = -\frac{\sqrt{2}}{2}$ at $\theta = \frac{5\pi}{4}$ and $\theta = \frac{7\pi}{4}$.

## When the value is not special

If the value is not one of the special values, find the reference angle with an inverse key, always using the positive value.

:::example With a calculator
Solve $5\sin\theta + 2 = 0$ for $0 \le \theta < 2\pi$, to the nearest hundredth.
@step $\sin\theta = -\dfrac{2}{5} = -0.4$
@step Radian mode: $\theta_R = \sin^{-1}(0.4) \approx 0.4115$
@step Quadrants III and IV: $\theta = \pi + 0.4115 \approx 3.5531$ or $\theta = 2\pi - 0.4115 \approx 5.8717$
@answer $\theta \approx 3.55$ or $\theta \approx 5.87$
:::

Some equations have only one solution per rotation, and some have none:

- $\sin\theta = -1$ only at $\theta = \dfrac{3\pi}{2}$, where the terminal arm points straight down.
- $3\cos\theta - 4 = 0$ gives $\cos\theta = \dfrac{4}{3}$. Since $-1 \le \cos\theta \le 1$, there is **no solution**.

:::mistake Using a negative calculator angle
$\sin^{-1}(-0.4) \approx -0.41$ is not in $0 \le \theta < 2\pi$. Use the positive value to get the reference angle, then place it in the correct quadrants.
:::

:::tip Check your mode
If your answers look like $23.6$ instead of $0.41$, the calculator is in degree mode. Radian answers between $0$ and $2\pi$ are always less than about $6.28$.
:::

## Larger domains and the general solution

Once you have the solutions for one rotation, add or subtract $2\pi$ (or $360^\circ$) to reach the rest of the domain.

:::example Two rotations
Solve $2\sin\theta - 1 = 0$ for $-2\pi \le \theta \le 2\pi$.
@step $\sin\theta = \dfrac{1}{2}$: in one rotation, $\theta = \dfrac{\pi}{6}$ or $\theta = \dfrac{5\pi}{6}$.
@step Subtract $2\pi$: $\dfrac{\pi}{6} - 2\pi = -\dfrac{11\pi}{6}$ and $\dfrac{5\pi}{6} - 2\pi = -\dfrac{7\pi}{6}$. Adding $2\pi$ leaves the domain.
@answer $\theta = -\dfrac{11\pi}{6}, -\dfrac{7\pi}{6}, \dfrac{\pi}{6}, \dfrac{5\pi}{6}$
:::

:::definition General solution
The **general solution** lists every solution, using $n \in \mathbb{I}$ to count full turns. For $2\sin\theta - 1 = 0$:
$$\theta = \frac{\pi}{6} + 2\pi n \quad \text{or} \quad \theta = \frac{5\pi}{6} + 2\pi n, \qquad n \in \mathbb{I}$$
:::

:::example Solutions half a turn apart
Write the general solution of $\tan\theta = 1$.
@step In one rotation, $\theta = \dfrac{\pi}{4}$ or $\theta = \dfrac{5\pi}{4}$.
@step These are exactly $\pi$ apart, so one family covers both.
@answer $\theta = \dfrac{\pi}{4} + \pi n$, $n \in \mathbb{I}$
:::

:::check m301-trig-equation-basic 3
:::

:::summary
- Isolate the ratio, find the reference angle from the positive value, choose the quadrants by sign, then place the angle.
- Expect two solutions per rotation, one when the ratio is $\pm 1$ (for sine and cosine), and none when $\sin\theta$ or $\cos\theta$ would be outside $[-1, 1]$.
- Add or subtract $2\pi$ (or $360^\circ$) to find solutions in a larger domain.
- The general solution adds $2\pi n$ to each solution, or $\pi n$ when two solutions are half a turn apart.
:::
