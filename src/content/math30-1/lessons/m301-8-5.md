Converting $50$°F to kelvins takes two steps: Fahrenheit to Celsius, then Celsius to kelvins. Doing one function and then feeding its output into another is called **composition**, and it builds new functions out of old ones.

## What is a composite function?

:::definition Composite function
The composite function $f(g(x))$, also written $(f \circ g)(x)$, applies $g$ first and then applies $f$ to the result. The output of the inner function $g$ becomes the input of the outer function $f$.
:::

With $C(F) = \dfrac{5}{9}(F - 32)$ and $K(C) = C + 273.15$: $C(50) = 10$, then $K(10) = 283.15$, so $K(C(50)) = 283.15$ K.

:::example Order matters
For $f(x) = 3x + 1$ and $g(x) = x^2 - 2$, evaluate $f(g(2))$ and $g(f(2))$.
@step $f(g(2))$: inside first, $g(2) = 4 - 2 = 2$, then $f(2) = 3(2) + 1 = 7$.
@step $g(f(2))$: inside first, $f(2) = 7$, then $g(7) = 49 - 2 = 47$.
@answer $f(g(2)) = 7$ and $g(f(2)) = 47$
:::

In general $f(g(x)) \ne g(f(x))$: the order of composition matters.

## Writing composite functions

To write $f(g(x))$, replace every $x$ in $f(x)$ with the whole expression for $g(x)$, in brackets.

:::example Two composites
For $f(x) = x^2 + 3x$ and $g(x) = 2x - 1$, write $f(g(x))$ and $g(f(x))$.
@step $f(g(x)) = (2x - 1)^2 + 3(2x - 1) = 4x^2 - 4x + 1 + 6x - 3 = 4x^2 + 2x - 2$
@step $g(f(x)) = 2(x^2 + 3x) - 1 = 2x^2 + 6x - 1$
@answer $f(g(x)) = 4x^2 + 2x - 2$ and $g(f(x)) = 2x^2 + 6x - 1$
:::

:::mistake Composition is not multiplication
$f(g(x))$ means "$f$ of $g(x)$", not $f(x) \cdot g(x)$. Here $(fg)(x) = (x^2 + 3x)(2x - 1)$, a different function.
:::

:::check m301-composition 2
:::

## The domain of a composite function

$x$ is in the domain of $f(g(x))$ when $x$ is in the domain of $g$ **and** $g(x)$ is in the domain of $f$. Find the domain before you simplify.

:::example Square roots
Let $f(x) = \sqrt{x}$ and $g(x) = x - 3$. Write $f(g(x))$ and $g(f(x))$ and state their domains.
@step $f(g(x)) = \sqrt{x - 3}$. The input of $f$ must be non-negative: $x - 3 \ge 0$, so $x \ge 3$.
@step $g(f(x)) = \sqrt{x} - 3$. Here $f$ is applied first and needs $x \ge 0$; $g$ accepts any input.
@answer $\sqrt{x - 3}$ with $\{x \mid x \ge 3,\ x \in \mathbb{R}\}$; $\sqrt{x} - 3$ with $\{x \mid x \ge 0,\ x \in \mathbb{R}\}$
:::

:::tip A simplified form can hide a restriction
For $f(x) = x^2$ and $g(x) = \sqrt{x + 2}$, $f(g(x)) = (\sqrt{x + 2})^2 = x + 2$. It looks like a line, but $g$ only accepts $x \ge -2$, so the domain is $\{x \mid x \ge -2,\ x \in \mathbb{R}\}$.
:::

:::

## Decomposing a function

Many functions can be written as a composition. Ask: what is done to $x$ first (the inner function $g$), and what is done to that result (the outer function $f$)?

:::example Finding f and g
Write $h(x) = (3x + 2)^2 - 5$ as $f(g(x))$.
@step First $3x + 2$ is calculated: $g(x) = 3x + 2$.
@step Then the result is squared and $5$ is subtracted: $f(x) = x^2 - 5$.
@step Check: $f(g(x)) = (3x + 2)^2 - 5$. ✓
@answer $f(x) = x^2 - 5$ and $g(x) = 3x + 2$
:::

Decompositions are not unique; $f(x) = (x + 2)^2 - 5$ with $g(x) = 3x$ also works. Choose the split that makes the structure clear.

:::check m301-composition 2
:::

:::summary
- $f(g(x))$ applies $g$ first, then $f$; work from the inside out.
- The order matters: usually $f(g(x)) \ne g(f(x))$.
- To write $f(g(x))$, substitute the whole expression for $g(x)$ into $f$, then simplify.
- The domain of $f(g(x))$ needs $x$ in the domain of $g$ and $g(x)$ in the domain of $f$; find it before simplifying.
- To decompose $h(x)$, the inner function is what is done to $x$ first.
:::
