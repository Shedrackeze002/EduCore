Engineers who model sound waves and alternating current rewrite trigonometric expressions all the time, because a simpler form is easier to graph, to calculate with, and later to differentiate in calculus. The tools for this are **identities**: equations that are true for every value of the variable where both sides are defined.

## Identities and non-permissible values

The equation $\dfrac{\sin x}{\tan x} = \cos x$ is true at $x = 30^\circ$, at $x = 2$, and at every other angle you try, as long as both sides are defined. That makes it an identity.

:::definition Trigonometric identity
An equation involving trigonometric functions that is true for **every** permissible value of the variable.
:::

:::definition Non-permissible value
A value of the variable that makes an expression undefined: a denominator is 0, or a function such as $\tan x$ or $\sec x$ does not exist there.
:::

Because $\tan x = \dfrac{\sin x}{\cos x}$, the left side above is undefined when $\cos x = 0$, and also when $\tan x = 0$ (that is, when $\sin x = 0$). Its graph is the cosine curve with holes at $0^\circ$, $90^\circ$, $180^\circ$, $270^\circ$ and $360^\circ$.

:::example Finding non-permissible values
Determine the non-permissible values of $\dfrac{\cos x}{\sin x\tan x}$ for $0 \le x < 2\pi$.
@step The factor $\sin x$ in the denominator cannot be 0: $\sin x = 0$ when $x = 0,\ \pi$.
@step $\tan x$ is undefined when $\cos x = 0$: $x = \frac{\pi}{2},\ \frac{3\pi}{2}$.
@step $\tan x$ in the denominator cannot be 0 either, but $\tan x = 0$ only where $\sin x = 0$, which is already listed.
@answer $x \ne 0,\ \frac{\pi}{2},\ \pi,\ \frac{3\pi}{2}$. For all real numbers: $x \ne \frac{\pi}{2}n,\ n \in \mathrm{I}$.
:::

:::tip Hidden denominators
$\tan x$ and $\sec x$ have $\cos x$ in a denominator; $\cot x$ and $\csc x$ have $\sin x$. Check them as well as any fraction you can see.

## Reciprocal and quotient identities

These come straight from the definitions of the ratios on the unit circle, where $x = \cos\theta$, $y = \sin\theta$ and $r = 1$.

:::definition Reciprocal and quotient identities
$$\csc x = \frac{1}{\sin x} \qquad \sec x = \frac{1}{\cos x} \qquad \cot x = \frac{1}{\tan x}$$
$$\tan x = \frac{\sin x}{\cos x} \qquad \cot x = \frac{\cos x}{\sin x}$$
:::

A reliable first move is to write every function in terms of $\sin x$ and $\cos x$, then divide out common factors.

:::example One step at a time
Simplify $\tan x\cos x\csc x$.
@step Quotient and reciprocal identities: $\dfrac{\sin x}{\cos x}\cdot\cos x\cdot\dfrac{1}{\sin x}$
@step Divide out $\cos x$ and $\sin x$.
@answer $\tan x\cos x\csc x = 1$, for $x \ne \frac{\pi}{2}n,\ n \in \mathrm{I}$
:::

:::check m301-identity-simplify 1
:::

By the Pythagorean theorem, $\cos^2\theta + \sin^2\theta = 1$. Dividing every term by $\cos^2\theta$ gives $1 + \tan^2\theta = \sec^2\theta$, and dividing by $\sin^2\theta$ gives $\cot^2\theta + 1 = \csc^2\theta$.

:::definition Pythagorean identities
$$\sin^2 x + \cos^2 x = 1 \qquad 1 + \tan^2 x = \sec^2 x \qquad 1 + \cot^2 x = \csc^2 x$$
Each can be rearranged, for example $1 - \sin^2 x = \cos^2 x$ and $\sec^2 x - 1 = \tan^2 x$.
:::

:::example Using a Pythagorean identity
Simplify $\dfrac{\sec^2 x - 1}{\sec^2 x}$.
@step Pythagorean identity: $\dfrac{\tan^2 x}{\sec^2 x}$
@step Quotient and reciprocal identities: $\dfrac{\sin^2 x}{\cos^2 x}\cdot\cos^2 x$
@step Check at $x = 30^\circ$: $\dfrac{\frac{4}{3} - 1}{\frac{4}{3}} = \dfrac{1}{4}$ and $\sin^2 30^\circ = \dfrac{1}{4}$.
@answer $\dfrac{\sec^2 x - 1}{\sec^2 x} = \sin^2 x$
:::

:::mistake What the square applies to
$\sin^2 x$ means $(\sin x)^2$, not $\sin(x^2)$. And $1 - \sin^2 x$ is $\cos^2 x$, not $\cos x$ and not $-\cos^2 x$. Most wrong simplifications come from a dropped square or sign.
:::

## A strategy for harder expressions

1. Write everything in terms of $\sin x$ and $\cos x$.
2. Combine fractions over a common denominator.
3. Look for $\sin^2 x + \cos^2 x$ (or a rearrangement) and replace it.
4. Factor, then divide out common factors.

:::example Combining fractions
Simplify $\dfrac{\cos x}{1 - \sin x} - \tan x$, and state the non-permissible values.
@step $\dfrac{\cos x}{1 - \sin x} - \dfrac{\sin x}{\cos x} = \dfrac{\cos^2 x - \sin x(1 - \sin x)}{\cos x(1 - \sin x)}$
@step Expand: $\dfrac{\cos^2 x - \sin x + \sin^2 x}{\cos x(1 - \sin x)} = \dfrac{1 - \sin x}{\cos x(1 - \sin x)}$
@step Divide out $1 - \sin x$: $\dfrac{1}{\cos x} = \sec x$
@step Restrictions: $\cos x \ne 0$ and $\sin x \ne 1$. Together they exclude $x = \frac{\pi}{2} + \pi n$.
@answer $\sec x$, for $x \ne \frac{\pi}{2} + \pi n,\ n \in \mathrm{I}$
:::

:::

:::summary
- An identity is true for every permissible value; non-permissible values make a denominator 0 or a function undefined.
- Reciprocal: $\csc x = \frac{1}{\sin x}$, $\sec x = \frac{1}{\cos x}$, $\cot x = \frac{1}{\tan x}$. Quotient: $\tan x = \frac{\sin x}{\cos x}$, $\cot x = \frac{\cos x}{\sin x}$.
- Pythagorean: $\sin^2 x + \cos^2 x = 1$, $1 + \tan^2 x = \sec^2 x$, $1 + \cot^2 x = \csc^2 x$.
- To simplify: rewrite in sine and cosine, use common denominators, replace Pythagorean patterns, then factor and divide out.
- State the non-permissible values in the domain, or for all real numbers with $n \in \mathrm{I}$.
:::
