Your calculator says $\sin 75^\circ \approx 0.9659$, but where does that number come from? Since $75^\circ = 45^\circ + 30^\circ$, an identity for the sine of a sum gives the exact value from two special triangles. The same identities let physicists combine two waves into one and let you rewrite $\sin 2x$ in terms of $\sin x$ and $\cos x$.

## The sum and difference identities

:::definition Sum and difference identities
$$\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$$
$$\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$$
$$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$$
In the cosine and tangent identities the signs are opposite: $\cos(A + B)$ has a minus sign in its expansion.
:::

**Where they come from.** Put $A$ and $B$ in standard position on the unit circle, at the points $(\cos A, \sin A)$ and $(\cos B, \sin B)$. The chord joining them subtends the angle $A - B$, so its length is the same as the chord from $(1, 0)$ to $(\cos(A - B), \sin(A - B))$. Setting the two squared distances equal and using $\sin^2 + \cos^2 = 1$ gives $\cos(A - B) = \cos A\cos B + \sin A\sin B$. The others follow: replace $B$ with $-B$ for $\cos(A + B)$, use $\sin\theta = \cos(90^\circ - \theta)$ for sine, and divide sine by cosine for tangent.

:::mistake Functions do not distribute
$\sin(A + B)$ is **not** $\sin A + \sin B$. For example, $\sin(30^\circ + 60^\circ) = \sin 90^\circ = 1$, but $\sin 30^\circ + \sin 60^\circ \approx 1.366$.
:::

## Writing an expression as one function

Read an identity from right to left to collapse an expansion into a single function.

:::example Recognizing an expansion
Determine the exact value of $\cos 50^\circ\cos 20^\circ + \sin 50^\circ\sin 20^\circ$.
@step This matches $\cos A\cos B + \sin A\sin B = \cos(A - B)$ with $A = 50^\circ$ and $B = 20^\circ$.
@step $\cos(50^\circ - 20^\circ) = \cos 30^\circ$
@answer $\dfrac{\sqrt{3}}{2}$
:::

The same works with variables: $\sin 3x\cos x - \cos 3x\sin x = \sin(3x - x) = \sin 2x$.

:::example The sine of 75°
Determine the exact value of $\sin 75^\circ$.
@step $\sin 75^\circ = \sin(45^\circ + 30^\circ) = \sin 45^\circ\cos 30^\circ + \cos 45^\circ\sin 30^\circ$
@step $= \left(\dfrac{\sqrt{2}}{2}\right)\left(\dfrac{\sqrt{3}}{2}\right) + \left(\dfrac{\sqrt{2}}{2}\right)\left(\dfrac{1}{2}\right) = \dfrac{\sqrt{6}}{4} + \dfrac{\sqrt{2}}{4}$
@answer $\sin 75^\circ = \dfrac{\sqrt{6} + \sqrt{2}}{4} \approx 0.9659$
:::

:::example A tangent in radians
Determine the exact value of $\tan\dfrac{\pi}{12}$.
@step $\dfrac{\pi}{12} = \dfrac{\pi}{3} - \dfrac{\pi}{4}$, so $\tan\dfrac{\pi}{12} = \dfrac{\tan\frac{\pi}{3} - \tan\frac{\pi}{4}}{1 + \tan\frac{\pi}{3}\tan\frac{\pi}{4}} = \dfrac{\sqrt{3} - 1}{1 + \sqrt{3}}$
@step Multiply by the conjugate: $\dfrac{(\sqrt{3} - 1)(\sqrt{3} - 1)}{(\sqrt{3} + 1)(\sqrt{3} - 1)} = \dfrac{4 - 2\sqrt{3}}{2}$
@answer $\tan\dfrac{\pi}{12} = 2 - \sqrt{3} \approx 0.2679$
:::

## Double-angle identities

Put $B = A$ in the sum identities. For example, $\sin(A + A) = \sin A\cos A + \cos A\sin A = 2\sin A\cos A$. Then use $\sin^2 A + \cos^2 A = 1$ to get two more forms of $\cos 2A$.

:::definition Double-angle identities
$$\sin 2A = 2\sin A\cos A \qquad \tan 2A = \frac{2\tan A}{1 - \tan^2 A}$$
$$\cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$$
:::

They work in both directions: $2\sin 15^\circ\cos 15^\circ = \sin 30^\circ = \dfrac{1}{2}$, and $1 - 2\sin^2 4x = \cos 8x$.

:::check m301-double-angle 1
:::

:::example From one ratio and a quadrant
Given $\sin\theta = \dfrac{3}{5}$ with $\dfrac{\pi}{2} < \theta < \pi$, determine $\sin 2\theta$ and $\cos 2\theta$.
@step In quadrant II, $x < 0$: with $y = 3$ and $r = 5$, $x = -\sqrt{5^2 - 3^2} = -4$, so $\cos\theta = -\dfrac{4}{5}$.
@step $\sin 2\theta = 2\sin\theta\cos\theta = 2\left(\dfrac{3}{5}\right)\left(-\dfrac{4}{5}\right) = -\dfrac{24}{25}$
@step $\cos 2\theta = \cos^2\theta - \sin^2\theta = \dfrac{16}{25} - \dfrac{9}{25} = \dfrac{7}{25}$
@answer $\sin 2\theta = -\dfrac{24}{25}$ and $\cos 2\theta = \dfrac{7}{25}$
:::

:::mistake Doubling the ratio
$\sin 2\theta$ is not $2\sin\theta$. In the example, $2\sin\theta = \dfrac{6}{5}$, which is not even a possible value of sine.
:::

## Two angles from given ratios

When $A$ and $B$ are not special angles, find all four ratios from the given information first.

:::example The cosine of a difference
Given $\sin A = \dfrac{4}{5}$ with $A$ in quadrant II, and $\cos B = \dfrac{5}{13}$ with $B$ in quadrant IV, determine $\cos(A - B)$.
@step Quadrant II: $\cos A = -\dfrac{3}{5}$. Quadrant IV: $\sin B = -\dfrac{12}{13}$.
@step $\cos(A - B) = \cos A\cos B + \sin A\sin B = \left(-\dfrac{3}{5}\right)\left(\dfrac{5}{13}\right) + \left(\dfrac{4}{5}\right)\left(-\dfrac{12}{13}\right)$
@step $= -\dfrac{15}{65} - \dfrac{48}{65}$
@answer $\cos(A - B) = -\dfrac{63}{65}$
:::

:::summary
- $\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$; $\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$; $\tan(A \pm B) = \dfrac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$.
- Use them to find exact values (write the angle as a sum or difference of special angles) and to collapse an expansion into one function.
- $\sin 2A = 2\sin A\cos A$; $\cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$; $\tan 2A = \dfrac{2\tan A}{1 - \tan^2 A}$.
- From one ratio and a quadrant, find the other ratios (with the correct signs) before using an identity.
:::
