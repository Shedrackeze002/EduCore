Sine, cosine and tangent each have a reciprocal partner. With the unit circle, all six ratios of any angle, in degrees or radians, come from the two coordinates of one point.

## The six trigonometric ratios

Let $P(\theta) = (x, y)$ be the point where the terminal arm of $\theta$ meets the unit circle.

:::definition The six trigonometric ratios
$$\sin\theta = y \qquad \cos\theta = x \qquad \tan\theta = \frac{y}{x}$$
$$\csc\theta = \frac{1}{\sin\theta} = \frac{1}{y} \qquad \sec\theta = \frac{1}{\cos\theta} = \frac{1}{x} \qquad \cot\theta = \frac{1}{\tan\theta} = \frac{x}{y}$$
**Cosecant**, **secant** and **cotangent** are the **reciprocal ratios**. A ratio is undefined when its denominator is $0$.
:::

If the point $(x, y)$ is on the terminal arm at a distance $r = \sqrt{x^2 + y^2}$ from the origin instead, divide by $r$: $\sin\theta = \dfrac{y}{r}$, $\cos\theta = \dfrac{x}{r}$, $\csc\theta = \dfrac{r}{y}$, $\sec\theta = \dfrac{r}{x}$, while $\tan\theta = \dfrac{y}{x}$ and $\cot\theta = \dfrac{x}{y}$ are unchanged.

:::example All six from a point
$P(\theta) = \left(-\dfrac{3}{5}, -\dfrac{4}{5}\right)$. Determine the six trigonometric ratios of $\theta$.
@step $\sin\theta = -\dfrac{4}{5}$, $\cos\theta = -\dfrac{3}{5}$, $\tan\theta = \dfrac{-4/5}{-3/5} = \dfrac{4}{3}$
@step Take reciprocals: $\csc\theta = -\dfrac{5}{4}$, $\sec\theta = -\dfrac{5}{3}$, $\cot\theta = \dfrac{3}{4}$
@answer $\sin\theta = -\frac{4}{5}$, $\cos\theta = -\frac{3}{5}$, $\tan\theta = \frac{4}{3}$, $\csc\theta = -\frac{5}{4}$, $\sec\theta = -\frac{5}{3}$, $\cot\theta = \frac{3}{4}$
:::

:::mistake Pairing the wrong reciprocals
**Co**secant goes with sine, not cosine: $\csc\theta = \dfrac{1}{\sin\theta}$ and $\sec\theta = \dfrac{1}{\cos\theta}$. Each pair has exactly one "co".
:::

:::example A reciprocal ratio
Determine the exact value of $\sec\dfrac{5\pi}{4}$.
@step $P\left(\dfrac{5\pi}{4}\right) = \left(-\dfrac{\sqrt{2}}{2}, -\dfrac{\sqrt{2}}{2}\right)$ (reference angle $\frac{\pi}{4}$, quadrant III)
@step $\sec\dfrac{5\pi}{4} = \dfrac{1}{x} = -\dfrac{2}{\sqrt{2}} = -\dfrac{2\sqrt{2}}{2}$
@answer $\sec\dfrac{5\pi}{4} = -\sqrt{2}$
:::

:::example A negative angle
Determine the exact value of $\cot\left(-\dfrac{\pi}{6}\right)$.
@step $P\left(-\dfrac{\pi}{6}\right) = \left(\dfrac{\sqrt{3}}{2}, -\dfrac{1}{2}\right)$ (reflect $P\left(\frac{\pi}{6}\right)$ in the $x$-axis)
@step $\cot\left(-\dfrac{\pi}{6}\right) = \dfrac{x}{y} = \dfrac{\sqrt{3}/2}{-1/2}$
@answer $\cot\left(-\dfrac{\pi}{6}\right) = -\sqrt{3}$
:::

:::example A quadrantal angle
Determine $\csc\dfrac{3\pi}{2}$ and $\sec\dfrac{3\pi}{2}$.
@step $P\left(\dfrac{3\pi}{2}\right) = (0, -1)$
@step $\csc\dfrac{3\pi}{2} = \dfrac{1}{y} = \dfrac{1}{-1} = -1$, but $\sec\dfrac{3\pi}{2} = \dfrac{1}{x} = \dfrac{1}{0}$.
@answer $\csc\dfrac{3\pi}{2} = -1$, and $\sec\dfrac{3\pi}{2}$ is undefined.
:::

:::example Combining values
Determine the exact value of $2\sin\dfrac{\pi}{6} - \sec^2\dfrac{\pi}{4}$.
@step $\sin\dfrac{\pi}{6} = \dfrac{1}{2}$ and $\sec\dfrac{\pi}{4} = \dfrac{2}{\sqrt{2}} = \sqrt{2}$
@step $2\left(\dfrac{1}{2}\right) - \left(\sqrt{2}\right)^2 = 1 - 2$
@answer $-1$
:::

## From one ratio to the others

When you know one ratio and the quadrant, sketch a point on the terminal arm, read two of $x$, $y$ and $r$ with the correct signs, and find the third with $x^2 + y^2 = r^2$.

:::example Given cosecant
$\csc\theta = -\dfrac{17}{8}$ and $\theta$ terminates in quadrant IV. Determine the exact values of $\cos\theta$ and $\cot\theta$.
@step $\csc\theta = \dfrac{r}{y}$, so take $r = 17$ and $y = -8$ ($r$ is always positive).
@step $x^2 = 17^2 - (-8)^2 = 225$, and $x > 0$ in quadrant IV, so $x = 15$.
@answer $\cos\theta = \dfrac{x}{r} = \dfrac{15}{17}$ and $\cot\theta = \dfrac{x}{y} = -\dfrac{15}{8}$
:::

## Approximate values and angles

Calculators have no reciprocal keys: evaluate $\csc$, $\sec$ and $\cot$ as $\dfrac{1}{\sin}$, $\dfrac{1}{\cos}$ and $\dfrac{1}{\tan}$. Set radian mode for angles without a degree sign.

:::example Evaluating a reciprocal ratio
Determine $\csc 2.1$ to the nearest thousandth.
@step Radian mode: $\sin 2.1 \approx 0.86321$
@step $\csc 2.1 = \dfrac{1}{\sin 2.1} \approx 1.15847$
@answer $\csc 2.1 \approx 1.158$
:::

:::example Finding an angle
$\sec\theta = -2.5$ and $\pi < \theta < \dfrac{3\pi}{2}$. Determine $\theta$ to the nearest hundredth of a radian.
@step $\cos\theta = \dfrac{1}{-2.5} = -0.4$
@step Reference angle: $\theta_R = \cos^{-1}(0.4) \approx 1.1593$
@step In quadrant III: $\theta = \pi + 1.1593 \approx 4.3009$
@answer $\theta \approx 4.30$
:::

:::mistake sec⁻¹ is not 1/cos⁻¹
To undo $\sec\theta = -2.5$, first write $\cos\theta = \dfrac{1}{-2.5}$, then use $\cos^{-1}$. Computing $\dfrac{1}{\cos^{-1}(-2.5)}$ gives an error, because $\cos^{-1}$ only accepts values from $-1$ to $1$.
:::

:::summary
- On the unit circle, $\sin\theta = y$, $\cos\theta = x$ and $\tan\theta = \dfrac{y}{x}$.
- $\csc\theta = \dfrac{1}{\sin\theta}$, $\sec\theta = \dfrac{1}{\cos\theta}$, $\cot\theta = \dfrac{1}{\tan\theta}$; a ratio with a zero denominator is undefined.
- Given one ratio and the quadrant, find $x$, $y$ and $r$ with $x^2 + y^2 = r^2$, keeping the signs.
- On a calculator, use $\frac{1}{\sin}$, $\frac{1}{\cos}$, $\frac{1}{\tan}$ in the correct mode, and find angles from the reference angle and the quadrant.
:::
