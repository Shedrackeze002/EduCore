A projectile launched at speed $v$ and angle $\theta$ lands a horizontal distance $R = \dfrac{v^2\sin 2\theta}{g}$ away. Finding the launch angles that hit a target means solving a trigonometric equation, and many such equations only become solvable after an identity rewrites them in terms of a single function.

## Quadratic equations in one function

An equation such as $2\sin^2 x - \sin x - 1 = 0$ is a quadratic in $\sin x$. If it helps, let $u = \sin x$: $2u^2 - u - 1 = 0$ factors as $(2u + 1)(u - 1) = 0$.

:::example Factoring
Solve $2\sin^2 x - \sin x - 1 = 0$ for $0 \le x < 2\pi$.
@step Factor: $(2\sin x + 1)(\sin x - 1) = 0$
@step $\sin x = -\dfrac{1}{2}$: the reference angle is $\dfrac{\pi}{6}$, and sine is negative in quadrants III and IV, so $x = \dfrac{7\pi}{6},\ \dfrac{11\pi}{6}$.
@step $\sin x = 1$: $x = \dfrac{\pi}{2}$.
@answer $x = \dfrac{\pi}{2},\ \dfrac{7\pi}{6},\ \dfrac{11\pi}{6}$
:::

:::mistake Dividing by a trigonometric function
To solve $\sin^2 x = \sin x$, do not divide both sides by $\sin x$: that throws away the solutions of $\sin x = 0$. Move everything to one side and factor: $\sin x(\sin x - 1) = 0$, so $x = 0,\ \dfrac{\pi}{2},\ \pi$ for $0 \le x < 2\pi$.
:::

## Square roots, impossible values and calculator values

- For $a\sin^2 x = b$, take square roots and keep **both** signs: $4\cos^2 x - 3 = 0$ gives $\cos x = \pm\dfrac{\sqrt{3}}{2}$, so $x = 30^\circ,\ 150^\circ,\ 210^\circ,\ 330^\circ$.
- A factor such as $\sin x - 2 = 0$ gives no solutions, because $-1 \le \sin x \le 1$ (and $-1 \le \cos x \le 1$).
- A value that is not special needs the inverse function for the reference angle.

:::example A value that is not special
Solve $3\sin^2 x + 5\sin x - 2 = 0$ for $0^\circ \le x < 360^\circ$, to the nearest tenth of a degree.
@step Factor: $(3\sin x - 1)(\sin x + 2) = 0$
@step $\sin x = -2$ has no solution.
@step $\sin x = \dfrac{1}{3}$: reference angle $\sin^{-1}\left(\dfrac{1}{3}\right) \approx 19.47^\circ$; sine is positive in quadrants I and II.
@answer $x \approx 19.5^\circ$ or $x \approx 180^\circ - 19.47^\circ \approx 160.5^\circ$
:::

:::example Two launch angles
A ball leaves a launcher at $20$ m/s and must land $20$ m away on level ground. Using $R = \dfrac{v^2\sin 2\theta}{g}$ with $g = 9.8$ m/s², determine the launch angles between $0^\circ$ and $90^\circ$, to the nearest tenth of a degree.
@step $\sin 2\theta = \dfrac{Rg}{v^2} = \dfrac{20(9.8)}{20^2} = 0.49$
@step Since $0^\circ < \theta < 90^\circ$, the angle $2\theta$ is between $0^\circ$ and $180^\circ$: $2\theta \approx 29.34^\circ$ or $2\theta \approx 180^\circ - 29.34^\circ = 150.66^\circ$.
@step Divide by 2 only after finding every value of $2\theta$.
@answer $\theta \approx 14.7^\circ$ or $\theta \approx 75.3^\circ$
:::

## Using an identity first

When an equation mixes functions or angles, choose an identity that leaves **one** function of **one** angle.

| The equation contains | Substitute |
| --- | --- |
| $\cos 2x$ and $\sin x$ | $\cos 2x = 1 - 2\sin^2 x$ |
| $\cos 2x$ and $\cos x$ | $\cos 2x = 2\cos^2 x - 1$ |
| $\sin 2x$ | $\sin 2x = 2\sin x\cos x$, then factor |
| $\sin^2 x$ and $\cos x$ | $\sin^2 x = 1 - \cos^2 x$ |
| $\sec^2 x$ and $\tan x$ | $\sec^2 x = 1 + \tan^2 x$ |

:::example A double angle with sine
Solve $\cos 2x = \sin x$ for $0^\circ \le x < 360^\circ$.
@step Substitute $\cos 2x = 1 - 2\sin^2 x$: $1 - 2\sin^2 x = \sin x$
@step Rearrange: $2\sin^2 x + \sin x - 1 = 0$, which factors as $(2\sin x - 1)(\sin x + 1) = 0$
@step $\sin x = \dfrac{1}{2}$: $x = 30^\circ,\ 150^\circ$. $\sin x = -1$: $x = 270^\circ$.
@answer $x = 30^\circ,\ 150^\circ,\ 270^\circ$
:::

:::example A Pythagorean substitution
Solve $2\sin^2 x + 3\cos x = 0$ for $0^\circ \le x < 360^\circ$.
@step Substitute $\sin^2 x = 1 - \cos^2 x$: $2 - 2\cos^2 x + 3\cos x = 0$
@step Multiply by $-1$ and factor: $2\cos^2 x - 3\cos x - 2 = 0$, so $(2\cos x + 1)(\cos x - 2) = 0$
@step $\cos x = 2$ has no solution. $\cos x = -\dfrac{1}{2}$: quadrants II and III.
@answer $x = 120^\circ,\ 240^\circ$
:::

:::tip Factor out the common factor
For $\sin 2x = \cos x$, write $2\sin x\cos x - \cos x = 0$ and factor: $\cos x(2\sin x - 1) = 0$. This gives $x = 90^\circ,\ 270^\circ$ from $\cos x = 0$ and $x = 30^\circ,\ 150^\circ$ from $\sin x = \dfrac{1}{2}$.
:::

## General solutions

Sine and cosine repeat every $2\pi$ ($360^\circ$) and tangent every $\pi$ ($180^\circ$), so every solution in one revolution produces infinitely many. Add a multiple of the period, with $n \in \mathrm{I}$.

:::example Writing the general solution
Write the general solution of $2\sin^2 x - \sin x - 1 = 0$ in radians.
@step From the first example, the solutions in one revolution are $\dfrac{\pi}{2}$, $\dfrac{7\pi}{6}$ and $\dfrac{11\pi}{6}$.
@step Sine repeats every $2\pi$, and no two of these solutions are $\pi$ apart, so each needs its own expression.
@answer $x = \dfrac{\pi}{2} + 2\pi n,\ \dfrac{7\pi}{6} + 2\pi n,\ \dfrac{11\pi}{6} + 2\pi n,\ n \in \mathrm{I}$
:::

When solutions are evenly spaced, combine them. For $\tan^2 x = 1$ the solutions $\dfrac{\pi}{4}$, $\dfrac{3\pi}{4}$, $\dfrac{5\pi}{4}$ and $\dfrac{7\pi}{4}$ are a quarter-turn apart, so $x = \dfrac{\pi}{4} + \dfrac{\pi}{2}n,\ n \in \mathrm{I}$.

:::check m301-trig-equation-identity 3
:::

:::summary
- Treat an equation such as $2\sin^2 x - \sin x - 1 = 0$ as a quadratic in $\sin x$: factor, then solve each factor over the domain.
- Never divide by a trigonometric function; move everything to one side and factor instead.
- $\sin x$ and $\cos x$ must lie between $-1$ and $1$, so a factor like $\cos x = 2$ has no solution.
- Use an identity to get one function of one angle: $\cos 2x = 1 - 2\sin^2 x = 2\cos^2 x - 1$, $\sin 2x = 2\sin x\cos x$, $\sin^2 x = 1 - \cos^2 x$, $\sec^2 x = 1 + \tan^2 x$.
- General solution: add $2\pi n$ ($360^\circ n$) to each solution, or combine solutions that are evenly spaced (for example $\pi n$ for pairs a half-turn apart), with $n \in \mathrm{I}$.
:::
