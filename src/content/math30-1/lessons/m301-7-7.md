How long does it take an investment to double at 5% per year, compounded annually? You need to solve $(1.05)^{n} = 2$, and $1.05$ and $2$ have no common base. Logarithms solve it: $n = \dfrac{\log 2}{\log 1.05} \approx 14.2$ years. This lesson puts all of the unit's tools to work.

## Solving logarithmic equations

1. Use the laws of logarithms to write the equation as a single logarithm equal to a number (or two single logarithms with the same base).
2. Convert to exponential form (or set the arguments equal).
3. Solve the resulting equation.
4. Check every answer in the **original** equation: each argument must be positive.

:::definition Extraneous root
A value found while solving that does not satisfy the original equation. In logarithmic equations, it is usually a value that makes an argument zero or negative.
:::

:::example A root to reject
Solve $\log_{2} x + \log_{2}(x - 2) = 3$.
@step Product law: $\log_{2}\left[x(x - 2)\right] = 3$.
@step Exponential form: $x(x - 2) = 2^{3} = 8$, so $x^{2} - 2x - 8 = 0$.
@step $(x - 4)(x + 2) = 0$, so $x = 4$ or $x = -2$.
@step Check $x = -2$: $\log_{2}(-2)$ is undefined, so $x = -2$ is extraneous. Check $x = 4$: $\log_{2} 4 + \log_{2} 2 = 2 + 1 = 3$ ✓
@answer $x = 4$
:::

The graph of $y = \log_{2} x + \log_{2}(x - 2)$ starts at its asymptote $x = 2$ and meets the line $y = 3$ only once, at $x = 4$.

:::example A quotient
Solve $\log_{3}(x + 6) - \log_{3}(x - 2) = 2$.
@step Quotient law: $\log_{3} \dfrac{x + 6}{x - 2} = 2$, so $\dfrac{x + 6}{x - 2} = 3^{2} = 9$.
@step $x + 6 = 9x - 18$, so $8x = 24$ and $x = 3$.
@step Check: the arguments are $3 + 6 = 9$ and $3 - 2 = 1$, both positive ✓
@answer $x = 3$
:::

:::mistake Check the original equation
$\log_{2}(x^{2} - 2x) = 3$ leads to the same quadratic, but here **both** $x = 4$ and $x = -2$ are solutions, because $x^{2} - 2x = 8 > 0$ for each. Whether a root is extraneous depends on the original arguments, so always check in the original equation, never in a combined one.
:::

## Exponential equations with logarithms

When the two sides cannot be written with a common base, take the logarithm of both sides and use the power law to bring the exponent down.

:::example One power
Solve $3^{x} = 20$. Round to the nearest hundredth.
@step $\log 3^{x} = \log 20$, so $x\log 3 = \log 20$.
@step $x = \dfrac{\log 20}{\log 3} \approx \dfrac{1.3010}{0.4771}$
@answer $x \approx 2.73$
:::

The solution is the $x$-coordinate where $y = 3^{x}$ meets $y = 20$:

:::example Different bases
Solve $2^{x + 1} = 5^{x}$. Round to the nearest hundredth.
@step $(x + 1)\log 2 = x\log 5$
@step $x\log 2 + \log 2 = x\log 5$, so $\log 2 = x(\log 5 - \log 2)$.
@step $x = \dfrac{\log 2}{\log 5 - \log 2} \approx \dfrac{0.3010}{0.3979}$
@answer $x \approx 0.76$
:::

:::example Quadratic form
Solve $4^{x} - 6(2^{x}) + 8 = 0$.
@step $4^{x} = \left(2^{x}\right)^{2}$. Let $A = 2^{x}$: $A^{2} - 6A + 8 = 0$, so $(A - 2)(A - 4) = 0$.
@step $2^{x} = 2$ gives $x = 1$; $2^{x} = 4$ gives $x = 2$.
@answer $x = 1$ or $x = 2$
:::

:::mistake Bring down the whole exponent
$\log 2^{x + 1} = (x + 1)\log 2$. Without brackets, $x + 1\log 2$ means something different. Isolate the power first, too: in $5(2)^{x} = 35$, divide by $5$ before taking logarithms.
:::

## Applications

In each application, write the formula, substitute what you know, isolate the power, and take logarithms to find an unknown exponent.

:::example Doubling time
\$1000 is invested at 5% per year, compounded annually, so $A = 1000(1.05)^{n}$ after $n$ years. How long until it is worth \$2000?
@step $2000 = 1000(1.05)^{n}$, so $1.05^{n} = 2$.
@step $n = \dfrac{\log 2}{\log 1.05} \approx 14.2$
@answer About 14.2 years
:::

:::example Half-life
A 100 mg sample of a radioactive isotope has a half-life of 8 days, so $A = 100\left(\frac{1}{2}\right)^{\frac{t}{8}}$. How long until 20 mg remain?
@step $20 = 100(0.5)^{\frac{t}{8}}$, so $0.5^{\frac{t}{8}} = 0.2$.
@step $\dfrac{t}{8}\log 0.5 = \log 0.2$, so $t = \dfrac{8\log 0.2}{\log 0.5} \approx 18.6$.
@answer About 18.6 days
:::

**Logarithmic scales** describe quantities that vary over huge ranges. Three common ones:

- pH: $\text{pH} = -\log\left[\text{H}^{+}\right]$. A drop of $1$ in pH means $10$ times the hydrogen ion concentration.
- Sound level: $\beta = 10\log \dfrac{I}{I_0}$ decibels. An increase of $10$ dB means $10$ times the intensity.
- Earthquake magnitude: $M = \log \dfrac{A}{A_0}$. An increase of $1$ in magnitude means $10$ times the amplitude.

:::example Comparing earthquakes
Using $M = \log \dfrac{A}{A_0}$, how many times as great is the amplitude of a magnitude 6.3 earthquake as that of a magnitude 4.8 earthquake?
@step Subtracting the two equations gives $M_1 - M_2 = \log \dfrac{A_1}{A_2}$, so $\dfrac{A_1}{A_2} = 10^{6.3 - 4.8} = 10^{1.5}$.
@answer About $31.6$ times as great
:::

:::tip Read the formula in the question
Rates, half-lives and scale formulas are always given in the question. Identify what each letter means before substituting.
:::

:::summary
- Logarithmic equations: combine with the laws, convert to exponential form, solve, and reject any root that makes an argument of the original equation zero or negative.
- Exponential equations with no common base: isolate the power, take the logarithm of both sides, and use the power law.
- An equation such as $4^{x} - 6(2^{x}) + 8 = 0$ is quadratic in $2^{x}$; a power is never negative.
- Growth, decay, interest and logarithmic scales all lead to equations with an unknown exponent.
:::
