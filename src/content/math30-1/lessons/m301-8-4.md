A ball's height above the ground and a drone's height above the ground are two functions of time. The height of the ball *above the drone* is their difference, a new function built from the two. Functions can be added, subtracted, multiplied and divided just like numbers.

## Combining functions

:::definition Sum, difference, product and quotient of functions
For functions $f$ and $g$:
- $(f + g)(x) = f(x) + g(x)$
- $(f - g)(x) = f(x) - g(x)$
- $(fg)(x) = f(x) \cdot g(x)$
- $\left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)}$, where $g(x) \ne 0$
:::

:::example Writing combined functions
For $f(x) = 2x - 3$ and $g(x) = x^2 + x - 4$, write $(f + g)(x)$, $(f - g)(x)$ and $(fg)(x)$.
@step $(f + g)(x) = (2x - 3) + (x^2 + x - 4) = x^2 + 3x - 7$
@step $(f - g)(x) = (2x - 3) - (x^2 + x - 4) = 2x - 3 - x^2 - x + 4 = -x^2 + x + 1$
@step $(fg)(x) = (2x - 3)(x^2 + x - 4) = 2x^3 + 2x^2 - 8x - 3x^2 - 3x + 12 = 2x^3 - x^2 - 11x + 12$
@answer $x^2 + 3x - 7$; $-x^2 + x + 1$; $2x^3 - x^2 - 11x + 12$
:::

:::mistake Subtract every term
$(f - g)(x)$ subtracts **all** of $g(x)$. Put $g(x)$ in brackets first: $-(x^2 + x - 4) = -x^2 - x + 4$, not $-x^2 + x - 4$.
:::

## Evaluating from equations, tables and graphs

To evaluate a combined function at one value, you do not need its equation: find each function's value and combine them. For example, with the functions above, $(f - g)(2) = f(2) - g(2) = 1 - 2 = -1$.

:::example From a table
Use the table to find $(f - g)(0)$, $(fg)(3)$ and $\left(\dfrac{f}{g}\right)(2)$. Is $\left(\dfrac{g}{f}\right)(2)$ defined?
@step $(f - g)(0) = f(0) - g(0) = 1 - (-3) = 4$
@step $(fg)(3) = f(3) \cdot g(3) = 5 \times (-1) = -5$
@step $\left(\dfrac{f}{g}\right)(2) = \dfrac{f(2)}{g(2)} = \dfrac{0}{4} = 0$
@step $\left(\dfrac{g}{f}\right)(2) = \dfrac{4}{0}$ is undefined, because $f(2) = 0$.
@answer $4$; $-5$; $0$; no
:::

## The domain of a combined function

A combined function is defined only where **both** $f$ and $g$ are defined. A quotient also needs a denominator that is not $0$.

- Domain of $f + g$, $f - g$ and $fg$: the $x$-values in the domain of $f$ and in the domain of $g$.
- Domain of $\dfrac{f}{g}$: the same, but also excluding every $x$ with $g(x) = 0$.

:::example Square roots and denominators
Let $f(x) = \sqrt{x - 1}$ and $g(x) = x - 4$. State the domains of $f + g$, $\dfrac{f}{g}$ and $\dfrac{g}{f}$.
@step $f$ needs $x - 1 \ge 0$, so $x \ge 1$. $g$ is defined for every real number.
@step $f + g$: $\{x \mid x \ge 1,\ x \in \mathbb{R}\}$.
@step $\dfrac{f}{g}$: also $g(x) \ne 0$, so $\{x \mid x \ge 1,\ x \ne 4,\ x \in \mathbb{R}\}$.
@step $\dfrac{g}{f}$: $f(1) = 0$, so $x = 1$ is excluded too: $\{x \mid x > 1,\ x \in \mathbb{R}\}$.
@answer $x \ge 1$; $x \ge 1,\ x \ne 4$; $x > 1$
:::

:::mistake Simplifying hides restrictions
For $f(x) = x^2 - 9$ and $g(x) = x + 3$, $\left(\dfrac{f}{g}\right)(x) = \dfrac{(x - 3)(x + 3)}{x + 3} = x - 3$. The simplified form looks defined everywhere, but $g(-3) = 0$, so the domain is $\{x \mid x \ne -3,\ x \in \mathbb{R}\}$. Find the domain **before** you simplify.
:::

:::summary
- $(f \pm g)(x) = f(x) \pm g(x)$, $(fg)(x) = f(x)g(x)$ and $\left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)}$.
- To evaluate at one value, find $f$ and $g$ there (from equations, a table or graphs) and combine.
- Subtract every term of $g(x)$ when writing $(f - g)(x)$.
- The domain is where both functions are defined; a quotient also excludes the zeros of its denominator, even after simplifying.
:::
