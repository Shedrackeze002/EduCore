To undo squaring, you take a square root. To undo "raise 2 to a power", you need a new operation. The question "2 to what exponent gives 32?" has the answer 5, and we write that as $\log_{2} 32 = 5$. A logarithm *is* an exponent.

## Logarithms are exponents

:::definition Logarithm
For $c > 0$, $c \ne 1$ and $x > 0$, $\log_{c} x = y$ means $c^{y} = x$. The logarithm of $x$ to base $c$ is the exponent that $c$ must be raised to in order to give $x$.
:::

:::definition Common logarithm
A logarithm with base $10$. It is written without a base: $\log x$ means $\log_{10} x$. It is the LOG key on a calculator.
:::

Every exponential statement has a logarithmic form, and every logarithmic statement has an exponential form:
$$c^{y} = x \quad \Longleftrightarrow \quad \log_{c} x = y$$

The base stays the base, and the exponent becomes the value of the logarithm.

:::example Convert between forms
Write $3^{4} = 81$ and $8^{\frac{2}{3}} = 4$ in logarithmic form, and $\log 0.01 = -2$ in exponential form.
@step $3^{4} = 81$: base $3$, exponent $4$, so $\log_{3} 81 = 4$.
@step $8^{\frac{2}{3}} = 4$: base $8$, exponent $\frac{2}{3}$, so $\log_{8} 4 = \frac{2}{3}$.
@step $\log 0.01 = -2$ has base $10$, so $10^{-2} = 0.01$.
@answer $\log_{3} 81 = 4$, $\log_{8} 4 = \frac{2}{3}$ and $10^{-2} = 0.01$
:::

## Evaluating logarithms

To evaluate $\log_{c} x$, write $x$ as a power of $c$. If that is not obvious, write both $c$ and $x$ as powers of a smaller number.

Four facts follow straight from the definition (for $c > 0$, $c \ne 1$):

- $\log_{c} 1 = 0$, because $c^{0} = 1$.
- $\log_{c} c = 1$, because $c^{1} = c$.
- $\log_{c} c^{n} = n$ and $c^{\log_{c} x} = x$: a power and a logarithm with the same base undo each other.

:::example Whole-number, negative and fractional values
Evaluate $\log_{2} 32$, $\log_{3} \frac{1}{9}$, $\log 0.001$ and $\log_{8} 4$.
@step $2^{5} = 32$, so $\log_{2} 32 = 5$.
@step $\frac{1}{9} = 3^{-2}$, so $\log_{3} \frac{1}{9} = -2$.
@step $0.001 = 10^{-3}$, so $\log 0.001 = -3$.
@step $8 = 2^{3}$ and $4 = 2^{2}$. If $8^{y} = 4$, then $2^{3y} = 2^{2}$, so $3y = 2$ and $y = \frac{2}{3}$.
@answer $5$, $-2$, $-3$ and $\frac{2}{3}$
:::

:::mistake Arguments must be positive
$\log_{2} 0$ and $\log_{2}(-8)$ are undefined: no power of $2$ is $0$ or negative. A logarithm itself can be negative (as $\log_{3} \frac{1}{9} = -2$ shows), but its argument cannot.
:::

## Estimating logarithms

When the argument is not an exact power, find the two powers it lies between. For $\log_{2} 50$: $2^{5} = 32$ and $2^{6} = 64$, and $32 < 50 < 64$.

:::

So $5 < \log_{2} 50 < 6$, and since $50$ is a bit closer to $64$ than to $32$, a reasonable estimate is about $5.6$. (In Lesson 7.6 you will find $\log_{2} 50 \approx 5.64$ exactly with a calculator.)

:::tip Common logarithms on a calculator
The LOG key gives common logarithms directly: $\log 50 \approx 1.699$, which makes sense because $10^{1} < 50 < 10^{2}$.
:::

## Solving equations by converting

Rewriting a logarithmic equation in exponential form often solves it at once.

:::example Unknown argument
Solve $\log_{5} x = -2$ and $\log_{4} x = \frac{3}{2}$.
@step $x = 5^{-2} = \frac{1}{25}$.
@step $x = 4^{\frac{3}{2}} = \left(\sqrt{4}\right)^{3} = 2^{3} = 8$.
@answer $x = \frac{1}{25}$ and $x = 8$
:::

:::example Unknown base
Solve $\log_{x} 81 = 4$.
@step Exponential form: $x^{4} = 81$, so $x = \pm 3$.
@step The base of a logarithm must be positive, so reject $x = -3$.
@answer $x = 3$
:::

:::example A logarithm inside a logarithm
Solve $\log_{2}\left(\log_{3} x\right) = 2$.
@step Work from the outside in: $\log_{3} x = 2^{2} = 4$.
@step Then $x = 3^{4} = 81$.
@answer $x = 81$
:::

:::summary
- $\log_{c} x = y$ means $c^{y} = x$ (with $c > 0$, $c \ne 1$, $x > 0$): a logarithm is an exponent.
- $\log x$ is the common logarithm, base $10$.
- $\log_{c} 1 = 0$, $\log_{c} c = 1$, $\log_{c} c^{n} = n$ and $c^{\log_{c} x} = x$.
- To evaluate, write the argument as a power of the base; to estimate, find the powers it lies between.
- To solve, convert to exponential form, and remember that a base must be positive.
:::
