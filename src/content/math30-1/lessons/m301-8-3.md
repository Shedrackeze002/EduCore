Two resistors in parallel, two workers sharing a job, a boat fighting a river current: each of these leads to an equation with the variable in a denominator. You can solve such a **rational equation** with algebra, or read its solutions from a graph, and the two methods check each other.

## Solving rational equations algebraically

1. Factor every denominator and state the **non-permissible values**.
2. Multiply every term by the lowest common denominator (LCD) to clear the fractions.
3. Solve the resulting polynomial equation.
4. Reject any root that is non-permissible, and check the others.

:::example One solution
Solve $\dfrac{x + 5}{x - 1} = 3$.
@step Non-permissible value: $x = 1$.
@step Multiply both sides by $x - 1$: $x + 5 = 3(x - 1) = 3x - 3$.
@step $8 = 2x$, so $x = 4$.
@step Check: $\dfrac{4 + 5}{4 - 1} = \dfrac{9}{3} = 3$. ✓
@answer $x = 4$
:::

:::example A quadratic
Solve $x + \dfrac{6}{x} = 5$.
@step Non-permissible value: $x = 0$.
@step Multiply every term by $x$: $x^2 + 6 = 5x$, so $x^2 - 5x + 6 = 0$.
@step $(x - 2)(x - 3) = 0$: $x = 2$ or $x = 3$. Both are permissible.
@answer $x = 2$ or $x = 3$
:::

## Extraneous roots

Multiplying by an expression that can be $0$ may create a root that does not satisfy the original equation.

:::definition Extraneous root
A root of the simplified (polynomial) equation that is not a solution of the original equation, usually because it is a non-permissible value.
:::

:::example Rejecting a root
Solve $\dfrac{2}{x - 3} + \dfrac{x}{x + 1} = \dfrac{8}{x^2 - 2x - 3}$.
@step Factor: $x^2 - 2x - 3 = (x - 3)(x + 1)$, so $x \ne 3$ and $x \ne -1$.
@step Multiply every term by $(x - 3)(x + 1)$: $2(x + 1) + x(x - 3) = 8$.
@step Expand: $x^2 - x + 2 = 8$, so $x^2 - x - 6 = 0$ and $(x - 3)(x + 2) = 0$.
@step $x = 3$ is non-permissible: it is extraneous. Check $x = -2$: $\dfrac{2}{-5} + \dfrac{-2}{-1} = 1.6$ and $\dfrac{8}{4 + 4 - 3} = 1.6$. ✓
@answer $x = -2$
:::

:::mistake Skipping the check
The quadratic $x^2 - x - 6 = 0$ has two roots, but the equation has only one solution. Always compare your roots with the non-permissible values. If every root is rejected, the equation has **no solution**.
:::

:::check m301-rational-equation-graph 2
:::

## Solving graphically

Rearrange the equation so one side is $0$. The other side defines the **related function**, and its $x$-intercepts are the solutions.

For $\dfrac{x + 5}{x - 1} = 3$, the related function is $y = \dfrac{x + 5}{x - 1} - 3 = \dfrac{-2(x - 4)}{x - 1}$. Its graph crosses the $x$-axis only at $x = 4$, the same solution as before.

## Applications

:::example Sharing a job
Working alone, Jonah takes $3$ h longer than Rhea to flood the outdoor rink. Together they take $2$ h. How long does Rhea take alone?
@step Let $t$ be Rhea's time. Each hour Rhea does $\dfrac{1}{t}$ of the job and Jonah does $\dfrac{1}{t + 3}$, so $\dfrac{1}{t} + \dfrac{1}{t + 3} = \dfrac{1}{2}$.
@step Multiply by $2t(t + 3)$: $2(t + 3) + 2t = t(t + 3)$, so $t^2 - t - 6 = 0$.
@step $(t - 3)(t + 2) = 0$: $t = 3$ or $t = -2$. A time cannot be negative.
@step Check: $\dfrac{1}{3} + \dfrac{1}{6} = \dfrac{1}{2}$. ✓
@answer Rhea takes $3$ h (and Jonah $6$ h).
:::

:::tip Rejecting roots in context
Besides non-permissible values, reject roots that make no sense in the situation: negative times, speeds below the speed of the current, negative resistances.
:::

:::check m301-rational-equation-graph 3
:::

:::summary
- State the non-permissible values, multiply by the LCD, solve, and check.
- A root that makes a denominator $0$ is extraneous; if every root is rejected, there is no solution.
- Graphically, the solutions are the $x$-intercepts of the related function $y = (\text{left side}) - (\text{right side})$; holes show extraneous roots.
- In applications, also reject roots that do not fit the context.
:::
