A culture of 200 bacteria doubles every 3 hours, so after $t$ hours it holds $N = 200(2)^{\frac{t}{3}}$ bacteria. When will it reach 6400? Dividing by 200 gives $2^{\frac{t}{3}} = 32$, and since $32 = 2^{5}$, the exponents must match: $\frac{t}{3} = 5$, so $t = 15$ hours. This lesson is about that idea.

## Equal powers, equal exponents

:::definition Exponential equation
An equation with the variable in an exponent, such as $3^{x - 1} = 81$ or $2^{x + 1} = 8^{x - 2}$.
:::

The graph of $y = c^{x}$ (with $c > 0$, $c \ne 1$) is always increasing or always decreasing, so it passes the horizontal line test: each $y$-value comes from exactly one exponent. Below, the line $y = 8$ meets $y = 2^{x}$ only at $x = 3$.

**Property.** If $c^{m} = c^{n}$, where $c > 0$ and $c \ne 1$, then $m = n$.

:::example Write one side as a power
Solve $3^{x - 1} = 81$.
@step $81 = 3^{4}$, so $3^{x - 1} = 3^{4}$.
@step The bases are equal, so the exponents are equal: $x - 1 = 4$.
@answer $x = 5$
:::

:::example A reciprocal
Solve $5^{2x} = \dfrac{1}{125}$.
@step $\dfrac{1}{125} = \dfrac{1}{5^{3}} = 5^{-3}$, so $5^{2x} = 5^{-3}$.
@step $2x = -3$
@answer $x = -\frac{3}{2}$
:::

:::

## Rewriting both sides with a common base

When the bases differ but are powers of the same number (such as $4$, $8$ and $16$, or $9$ and $27$):

1. Write each base as a power of the common base.
2. Use the power of a power law, $\left(c^{m}\right)^{n} = c^{mn}$.
3. Set the exponents equal and solve.
4. Check by substituting.

:::example Two different bases
Solve $2^{x + 1} = 8^{x - 2}$.
@step $8 = 2^{3}$, so $2^{x + 1} = \left(2^{3}\right)^{x - 2} = 2^{3x - 6}$.
@step $x + 1 = 3x - 6$, so $-2x = -7$ and $x = \frac{7}{2}$.
@step Check: $2^{\frac{9}{2}}$ on the left and $8^{\frac{3}{2}} = \left(2^{3}\right)^{\frac{3}{2}} = 2^{\frac{9}{2}}$ on the right ✓
@answer $x = \frac{7}{2}$
:::

:::example A fractional base
Solve $\left(\frac{1}{9}\right)^{x} = 27^{x + 2}$.
@step $\frac{1}{9} = 3^{-2}$ and $27 = 3^{3}$, so $3^{-2x} = 3^{3x + 6}$.
@step $-2x = 3x + 6$, so $-5x = 6$.
@answer $x = -\frac{6}{5}$
:::

:::mistake Multiply the whole exponent
$\left(2^{3}\right)^{x - 2} = 2^{3(x - 2)} = 2^{3x - 6}$, not $2^{3x - 2}$. Keep brackets around the exponent until you have multiplied every term.
:::

## Products, quotients and radicals

Use the exponent laws to collect each side into a single power: add exponents to multiply, subtract to divide, and write roots as rational exponents ($\sqrt{c} = c^{\frac{1}{2}}$).

:::example A quotient
Solve $9^{x} = \dfrac{27^{x - 1}}{3}$.
@step $3^{2x} = \dfrac{3^{3x - 3}}{3^{1}} = 3^{3x - 4}$
@step $2x = 3x - 4$, so $x = 4$.
@step Check: $9^{4} = 6561$ and $\dfrac{27^{3}}{3} = \dfrac{19\,683}{3} = 6561$ ✓
@answer $x = 4$
:::

:::example A radical
Solve $4^{x} = 8\sqrt{2}$.
@step $8\sqrt{2} = 2^{3} \cdot 2^{\frac{1}{2}} = 2^{\frac{7}{2}}$, and $4^{x} = 2^{2x}$.
@step $2x = \frac{7}{2}$
@answer $x = \frac{7}{4}$
:::

:::example A quadratic exponent
Solve $2^{x^{2} - 3x} = 16$.
@step $16 = 2^{4}$, so $x^{2} - 3x = 4$.
@step $x^{2} - 3x - 4 = 0$, so $(x - 4)(x + 1) = 0$.
@answer $x = -1$ or $x = 4$ (both check: $2^{4} = 16$)
:::

:::

## Applications

Doubling and half-life models often lead to equations with a common base.

:::example Half-life
A medical isotope has a half-life of 6 hours, so the mass remaining from an 80 mg dose is $A = 80\left(\frac{1}{2}\right)^{\frac{t}{6}}$. When will 5 mg remain?
@step $5 = 80\left(\frac{1}{2}\right)^{\frac{t}{6}}$, so $\left(\frac{1}{2}\right)^{\frac{t}{6}} = \frac{5}{80} = \frac{1}{16} = \left(\frac{1}{2}\right)^{4}$.
@step $\dfrac{t}{6} = 4$
@answer $t = 24$ hours
:::

:::tip When there is no common base
An equation such as $3^{x} = 20$ cannot be written with a common base. You will solve equations like that with logarithms in Lesson 7.7.
:::

:::summary
- If $c^{m} = c^{n}$ (with $c > 0$, $c \ne 1$), then $m = n$.
- Rewrite each side as a single power of a common base: power of a power multiplies exponents; products add them; quotients subtract them; $\sqrt[n]{c} = c^{\frac{1}{n}}$.
- Set the exponents equal, solve, and check by substituting.
- A quadratic exponent can give two solutions.
:::
