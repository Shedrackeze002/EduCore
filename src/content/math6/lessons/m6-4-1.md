Three pizzas. Four hungry friends. How much pizza does each friend get? When you share things equally, the answer is a fraction. In this lesson, you will see that every fraction is also a division.

## Sharing makes a fraction

When you share things so that everyone gets the same amount, each share is a fraction.

:::definition Equal sharing
**Equal sharing** means splitting an amount so that every share is the same size.
:::

:::definition Quotient
A **quotient** is the answer to a division. In $12 \div 3 = 4$, the quotient is $4$.
:::

Here is one way to share $3$ pizzas among $4$ friends. Cut each pizza into $4$ equal pieces. Each friend takes one piece from each pizza.

:::example Three pizzas, four friends
$3$ pizzas are shared equally by $4$ friends. How much pizza does each friend get?
@step Cut each pizza into $4$ equal pieces. Each piece is $\dfrac{1}{4}$ of a pizza.
@step Each friend gets one piece from each pizza. That is $3$ pieces.
@step $3$ pieces of $\dfrac{1}{4}$ make $\dfrac{3}{4}$.
@answer Each friend gets $\dfrac{3}{4}$ of a pizza. This is the quotient $3 \div 4$.
:::

In an equal-sharing fraction, the **numerator** (top) is the amount shared. The **denominator** (bottom) is the number of shares.

:::mistake Flipping the fraction
$3$ pizzas shared by $4$ friends is $\dfrac{3}{4}$, not $\dfrac{4}{3}$. Put the amount being shared on top.
:::

## More than one way to share

You can model the same sharing in different ways. The answer is always the same.

- **Way 1:** Cut all $3$ pizzas into quarters. Each friend gets $3$ quarters, or $\dfrac{3}{4}$.
- **Way 2:** Cut $2$ pizzas in half. That makes $4$ halves, so each friend gets $\dfrac{1}{2}$. Cut the last pizza into quarters, so each friend also gets $\dfrac{1}{4}$. Each friend gets $\dfrac{1}{2} + \dfrac{1}{4} = \dfrac{2}{4} + \dfrac{1}{4} = \dfrac{3}{4}$.

:::example More than one whole each
$5$ sandwiches are shared equally by $2$ campers. How much does each camper get?
@step Each camper gets $5 \div 2 = \dfrac{5}{2}$ sandwiches.
@step $5 \div 2 = 2$ R $1$. Each camper gets $2$ whole sandwiches, and $1$ sandwich is left.
@step Cut the last sandwich in half. Each camper gets $\dfrac{1}{2}$ more.
@answer Each camper gets $\dfrac{5}{2} = 2\dfrac{1}{2}$ sandwiches.
:::

:::tip Equivalent fractions, same share
$6$ pizzas shared by $8$ friends is $\dfrac{6}{8}$ each. Divide the top and bottom by $2$: $\dfrac{6}{8} = \dfrac{3}{4}$. That is the same share as $3$ pizzas for $4$ friends. All equivalent fractions show the same quotient.
:::

## A fraction is a division

The fraction bar means "divided by". So you can write any fraction as a division statement, and any division as a fraction.

$$\dfrac{5}{8} = 5 \div 8 \qquad\qquad 6 \div 11 = \dfrac{6}{11}$$

:::example Both directions
Write $\dfrac{7}{9}$ as a division statement. Then write $2 \div 3$ as a fraction.
@step The numerator is divided by the denominator: $\dfrac{7}{9} = 7 \div 9$.
@step The number being divided goes on top: $2 \div 3 = \dfrac{2}{3}$.
@answer $\dfrac{7}{9} = 7 \div 9$ and $2 \div 3 = \dfrac{2}{3}$.
:::

## From a fraction to a decimal

To write a fraction as a decimal, divide the numerator by the denominator. Use the standard algorithm. When there is a remainder, write a zero after it and keep dividing.

:::example Three quarters as a decimal
Write $\dfrac{3}{4}$ as a decimal.
@step $\dfrac{3}{4} = 3 \div 4$. $4$ does not go into $3$, so write $0$ and a decimal point.
@step $30 \div 4 = 7$ R $2$. Write $7$ after the decimal point.
@step $20 \div 4 = 5$, with no remainder. Write $5$.
@answer $\dfrac{3}{4} = 0.75$
:::

:::example Juice in jugs
$7$ L of juice is poured equally into $4$ jugs. How many litres are in each jug? Write the answer as a decimal.
@step Each jug gets $7 \div 4 = \dfrac{7}{4}$ L.
@step $7 \div 4 = 1$ R $3$. Write $1$ and a decimal point.
@step $30 \div 4 = 7$ R $2$, then $20 \div 4 = 5$.
@answer Each jug has $1.75$ L of juice.
:::

:::mistake Writing the digits
$\dfrac{3}{8}$ is **not** $3.8$ or $0.38$. You must divide: $30 \div 8 = 3$ R $6$, $60 \div 8 = 7$ R $4$, $40 \div 8 = 5$. So $\dfrac{3}{8} = 0.375$.
:::

Decimals make shares easy to compare. At one table, $3$ pizzas are shared by $4$ students: $3 \div 4 = 0.75$. At another table, $5$ pizzas are shared by $8$ students: $5 \div 8 = 0.625$. Since $0.75 > 0.625$, each student gets more at the first table.

:::summary
- Equal sharing: the amount shared ÷ the number of shares. $3$ pizzas for $4$ friends is $\dfrac{3}{4}$ each.
- A fraction is a division: $\dfrac{a}{b} = a \div b$.
- Equivalent fractions show the same share.
- To change a fraction to a decimal, divide the numerator by the denominator.
:::
