Imagine a bin with $3$ bags of marbles and $5$ loose marbles. Every bag holds the same number. If you do not know that number, call it $x$. Then the bin holds $3x + 5$ marbles. In this lesson, you will learn to tidy up expressions like this one.

## Terms and like terms

:::definition Term
A **term** is a number, a variable, or a number times a variable. The expression $3x + 5$ has two terms: $3x$ and $5$. A term with no variable, like $5$, is a **constant term**.
:::

:::definition Like terms
**Like terms** have exactly the same variable. $3x$ and $7x$ are like terms. Constant terms, such as $5$ and $9$, are like terms too.
:::

Some terms are **not** like terms:
- $3x$ and $3y$ have different variables.
- $3x$ and $3$: one has a variable and one does not.
- $3x$ and $3x^{2}$: the variables are not exactly the same.

You can model an expression with **algebra tiles**. A long tile stands for $x$. A small square stands for $1$.

:::example Modelling like terms
The model shows $2x + 3$ and $x + 2$. Write a simplified expression for all the tiles.
@step Count the long tiles: $2x + x = 3x$. (The lone $x$ means $1x$.)
@step Count the small squares: $3 + 2 = 5$.
@answer All the tiles show $3x + 5$.

## Combining like terms

To **simplify** an expression, combine the like terms. Add or subtract the numbers in front of the same variable. Add or subtract the constants.

:::example Four terms
Simplify $4n + 3 + 2n + 5$.
@step The $n$-terms: $4n + 2n = 6n$.
@step The constants: $3 + 5 = 8$.
@answer $4n + 3 + 2n + 5 = 6n + 8$
:::

:::example With subtraction
Simplify $7y + 6 - 3y - 2$.
@step Each term keeps the sign in front of it. The $y$-terms: $7y - 3y = 4y$.
@step The constants: $6 - 2 = 4$.
@answer $7y + 6 - 3y - 2 = 4y + 4$
:::

:::mistake Combining terms that are not alike
$6n + 8$ is **not** $14n$. $6n$ and $8$ are not like terms, so they stay apart. Think of $6$ bags and $8$ loose marbles: you cannot add them into one number of bags.
:::

## Algebraic properties

The terms of an expression can be moved around without changing its value. These rules are called **properties**.

:::definition Commutative property
You can change the **order** when you add or multiply: $a + b = b + a$ and $a \times b = b \times a$.
:::

:::definition Associative property
You can change the **grouping** when you add or multiply: $(a + b) + c = a + (b + c)$ and $(a \times b) \times c = a \times (b \times c)$.
:::

:::definition Distributive property
A number times a sum multiplies **each** term in the sum: $a(b + c) = ab + ac$. For example, $3(x + 4) = 3x + 12$.
:::

:::example Using the properties
Simplify $3 + 2x + 5$.
@step Commutative property: change the order to $2x + 3 + 5$.
@step Associative property: group the constants, $2x + (3 + 5)$.
@answer $3 + 2x + 5 = 2x + 8$
:::

:::

## Expressions for perimeter

The perimeter of a shape is the sum of its sides. When the sides are expressions, add them and combine like terms.

:::example Perimeter of a triangle
A triangle has sides of $2n$, $n + 4$ and $3n + 1$ centimetres. Write a simplified expression for its perimeter.
@step Add the sides: $2n + n + 4 + 3n + 1$.
@step The $n$-terms: $2n + n + 3n = 6n$.
@step The constants: $4 + 1 = 5$.
@answer The perimeter is $6n + 5$ cm.
:::

:::check m6-like-terms 3
:::

:::summary
- Like terms have exactly the same variable. Constants are like terms too.
- Simplify by combining like terms: $4n + 3 + 2n + 5 = 6n + 8$.
- Commutative property: change the order. Associative property: change the grouping.
- Distributive property: $a(b + c) = ab + ac$.
:::
