A fraction such as $\tfrac{3}{4}$ is a quotient of integers. A **rational expression** is the same idea one level up: a quotient of polynomials, such as the average cost $\dfrac{500 + 12n}{n}$ of making $n$ snowboards. Everything you know about fractions carries over, with one new rule: you can never divide by zero.

## What is a rational expression?

:::definition Rational expression
A quotient $\dfrac{P}{Q}$ of two polynomials $P$ and $Q$, where $Q \ne 0$. Examples: $\dfrac{5}{x}$, $\dfrac{x + 4}{x^2 - 7x + 10}$, $\dfrac{3a^2}{2b}$. (An expression such as $\dfrac{1}{\sqrt{x}}$ is not rational, because $\sqrt{x}$ is not a polynomial.)
:::

A rational expression is undefined whenever its denominator equals zero, so those values of the variable must be excluded.

:::definition Non-permissible value
A value of the variable that makes a denominator equal to zero. We state these as restrictions, for example $x \ne 2,\ 5$.
:::

:::example Reading the restrictions
Find the non-permissible values of $\dfrac{x + 4}{x^2 - 7x + 10}$.
@step Set the denominator equal to zero: $x^2 - 7x + 10 = 0$.
@step Factor: $(x - 2)(x - 5) = 0$, so $x = 2$ or $x = 5$.
@answer $x \ne 2,\ 5$
:::

:::mistake Looking at the numerator
The numerator can be zero — that just makes the expression equal $0$. In $\dfrac{x + 4}{x^2 - 7x + 10}$, $x = -4$ is perfectly allowed. Only denominators create restrictions.
:::

## Factor first, then find the restrictions

When the denominator is a trinomial with a leading coefficient other than $1$, factor carefully. A factor such as $2x - 3$ gives a fractional restriction.

:::example A non-monic denominator
Find the non-permissible values of $\dfrac{3x}{2x^2 + x - 6}$.
@step Factor: $2x^2 + x - 6 = (2x - 3)(x + 2)$. Check by expanding: $2x^2 + 4x - 3x - 6$ ✓
@step $2x - 3 = 0$ gives $x = \tfrac{3}{2}$; $x + 2 = 0$ gives $x = -2$.
@answer $x \ne -2,\ \tfrac{3}{2}$
:::

Some denominators are never zero. For $\dfrac{5}{x^2 + 4}$, the square $x^2$ is at least $0$, so $x^2 + 4 \ge 4$. There are **no** non-permissible values. For a trinomial that will not factor, check the discriminant $b^2 - 4ac$: if it is negative, the denominator is never zero.

:::

## Equivalent rational expressions

For any non-zero $k$, $\dfrac{k}{k} = 1$. That is why $\dfrac{6}{8} = \dfrac{2 \cdot 3}{2 \cdot 4} = \dfrac{3}{4}$, and it works the same way with polynomial factors:

$$\frac{(x + 2)(x - 1)}{(x - 1)(x + 5)} = \frac{x + 2}{x + 5} \cdot \frac{x - 1}{x - 1} = \frac{x + 2}{x + 5}, \quad x \ne 1,\ -5$$

The two expressions agree for every permissible $x$. At $x = 3$, both equal $\tfrac{5}{8}$. But at $x = 1$ the original is $\tfrac{0}{0}$ (undefined) while $\dfrac{x + 2}{x + 5}$ equals $\tfrac{1}{2}$. They are equivalent **only** with the restriction $x \ne 1$, so the restrictions of the original expression always travel with the simplified one.

:::tip Why cancelling is legal
Dividing a common factor out of the numerator and denominator is the same as multiplying by $\dfrac{x - 1}{x - 1} = 1$ in reverse. It is allowed only when that factor is not zero — exactly what the restriction promises.
:::

## Simplifying by factoring

1. Factor the numerator and the denominator completely.
2. State the non-permissible values from the **original** denominator.
3. Divide out common factors.

:::example A monomial quotient
Simplify $\dfrac{12x^3}{18x^5}$.
@step Restriction: $x \ne 0$.
@step Divide the coefficients by their GCF, $6$: $\dfrac{12}{18} = \dfrac{2}{3}$. Subtract exponents: $\dfrac{x^3}{x^5} = \dfrac{1}{x^2}$.
@answer $\dfrac{2}{3x^2}$, $x \ne 0$
:::

:::example Trinomial over a difference of squares
Simplify $\dfrac{x^2 - 4x - 12}{x^2 - 36}$.
@step Factor: $\dfrac{(x - 6)(x + 2)}{(x - 6)(x + 6)}$. Restrictions: $x \ne 6,\ -6$.
@step Divide out $(x - 6)$.
@answer $\dfrac{x + 2}{x + 6}$, $x \ne \pm 6$
:::

:::example Opposite factors
Simplify $\dfrac{10 - 2x}{x^2 - 25}$.
@step Factor $-2$ from the numerator so it matches: $10 - 2x = -2(x - 5)$. The denominator is $(x - 5)(x + 5)$, so $x \ne \pm 5$.
@step $\dfrac{-2(x - 5)}{(x - 5)(x + 5)}$: divide out $(x - 5)$.
@answer $-\dfrac{2}{x + 5}$, $x \ne \pm 5$
:::

:::mistake Cancelling terms instead of factors
$\dfrac{x^2 + 5}{x^2 + 3}$ is **not** $\dfrac{5}{3}$. Test $x = 1$: $\dfrac{6}{4} = 1.5$, but $\tfrac{5}{3} \approx 1.67$. You may only divide out something that **multiplies** the whole numerator and the whole denominator.
:::

:::summary
- A rational expression is a quotient of polynomials; it is undefined where a denominator is $0$.
- Find non-permissible values by factoring each denominator and setting each factor equal to $0$.
- Simplify by factoring completely and dividing out common factors — never single terms.
- Opposite factors such as $5 - x$ and $x - 5$ simplify to $-1$.
- State restrictions from the original expression, including factors you cancelled.
:::
