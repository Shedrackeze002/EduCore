The period of a pendulum, the speed of a car from its skid marks and the time for an object to fall are all modelled with square roots. To work backwards — from a period to a length, say — you solve a **radical equation**. Squaring both sides is the key move, but it can sneak in answers that do not work, so checking becomes part of the method.

## Restrictions on the variable

A square root is a real number only when its radicand is non-negative. Before solving, decide which values of the variable are allowed.

:::definition Restriction
A **restriction** is a condition on the variable that keeps every radicand non-negative (and every denominator non-zero). Values outside the restriction cannot be solutions.
:::

:::example Finding restrictions
State the restrictions on $x$ in (a) $\sqrt{3x - 12}$ (b) $\sqrt{6 - 2x}$ (c) $\dfrac{5}{\sqrt{x + 4}}$.
@step (a) $3x - 12 \ge 0$, so $3x \ge 12$ and $x \ge 4$.
@step (b) $6 - 2x \ge 0$, so $-2x \ge -6$. Dividing by $-2$ reverses the inequality: $x \le 3$.
@step (c) The radicand must be non-negative **and** the denominator cannot be $0$, so $x + 4 > 0$ and $x > -4$.
@answer (a) $x \ge 4$ (b) $x \le 3$ (c) $x > -4$
:::

When there are two radicals, both conditions must hold. For $\sqrt{x - 2} + \sqrt{8 - x}$ you need $x \ge 2$ and $x \le 8$, so $2 \le x \le 8$.

:::mistake Forgetting to reverse the inequality
From $-2x \ge -6$, dividing by a negative number reverses the sign: $x \le 3$, not $x \ge 3$. Test a value to be sure: $x = 0$ gives $\sqrt{6}$, which is real, so $0$ must be allowed.
:::

## Solving by squaring

1. **Isolate** the radical on one side.
2. **Square** both sides to remove it.
3. **Solve** the resulting equation.
4. **Check** every answer in the original equation.

:::example A one-radical equation
Solve $\sqrt{2x + 3} + 4 = 9$.
@step Isolate: $\sqrt{2x + 3} = 5$
@step Square: $2x + 3 = 25$, so $2x = 22$ and $x = 11$.
@step Check: $\sqrt{2(11) + 3} + 4 = \sqrt{25} + 4 = 9$ ✓
@answer $x = 11$
:::

## Extraneous roots

If $a = b$, then $a^2 = b^2$. The reverse is not true: $a^2 = b^2$ only tells you $a = \pm b$. So squaring can introduce answers that solve the squared equation but not the original one.

:::definition Extraneous root
An **extraneous root** is a value produced while solving that does not satisfy the original equation.
:::

:::example A quadratic after squaring
Solve $\sqrt{x + 3} = x - 3$.
@step Restriction: $x \ge -3$. Square both sides: $x + 3 = x^2 - 6x + 9$.
@step Collect terms: $x^2 - 7x + 6 = 0$, so $(x - 1)(x - 6) = 0$ and $x = 1$ or $x = 6$.
@step Check $x = 1$: left side $\sqrt{4} = 2$, right side $1 - 3 = -2$. ✗ Extraneous.
@step Check $x = 6$: left side $\sqrt{9} = 3$, right side $6 - 3 = 3$. ✓
@answer $x = 6$
:::

The graph shows why. The solution is where $y = \sqrt{x + 3}$ meets $y = x - 3$. The extraneous root $x = 1$ is where the line meets $y = -\sqrt{x + 3}$ (grey), the curve that squaring brings in.

If the isolated radical equals a negative number, there is **no solution**: $\sqrt{x - 2} + 7 = 3$ gives $\sqrt{x - 2} = -4$, and a principal square root is never negative.

:::mistake Squaring term by term
$(x - 3)^2$ is $x^2 - 6x + 9$, not $x^2 - 9$. Square the **whole side**, not each term separately.
:::

## Two radicals

When an equation has two radicals, isolate one, square, then isolate the radical that is left and square again.

:::example Squaring twice
Solve $\sqrt{x + 7} = \sqrt{x} + 1$.
@step Square both sides: $x + 7 = x + 2\sqrt{x} + 1$
@step Simplify: $6 = 2\sqrt{x}$, so $\sqrt{x} = 3$ and $x = 9$.
@step Check: $\sqrt{16} = 4$ and $\sqrt{9} + 1 = 4$ ✓
@answer $x = 9$
:::

## Radical equations in context

:::example The length of a pendulum
The period of a pendulum is modelled by $T = 2\pi\sqrt{\dfrac{L}{9.8}}$, where $T$ is in seconds and $L$ in metres. A clock pendulum has a period of $2.0$ s. How long is it, to the nearest hundredth of a metre?
@step Isolate the radical: $\sqrt{\dfrac{L}{9.8}} = \dfrac{2.0}{2\pi}$
@step Square: $\dfrac{L}{9.8} = \left(\dfrac{2.0}{2\pi}\right)^2$, so $L = 9.8\left(\dfrac{2.0}{2\pi}\right)^2 \approx 0.993$
@answer The pendulum is about $0.99$ m long.
:::

:::tip Does the answer make sense?
A longer pendulum swings more slowly. Check that a larger $T$ gives a larger $L$ in your work — it is a quick way to catch an algebra slip.
:::

:::check m201-radical-equation 3
:::

:::summary
- Restrictions: every radicand $\ge 0$ (and $> 0$ in a denominator). Reverse the inequality when dividing by a negative.
- To solve: isolate the radical, square both sides, solve, then **check every answer**.
- Squaring can create **extraneous roots**; reject any value that fails the original equation.
- If an isolated square root equals a negative number, there is no solution.
- With two radicals, isolate and square twice.
:::
