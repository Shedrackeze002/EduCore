The height of a model rocket might be given as $h = -5t^2 + 30t + 2$. This is **standard form**: easy to evaluate, but the vertex is hidden. Two tools reveal it: the formula $x = -\dfrac{b}{2a}$ and completing the square.

## Standard form

:::definition Standard form
A quadratic function in **standard form** is $y = ax^2 + bx + c$, where $a \ne 0$.
:::

Some features can be read straight away:

- $a > 0$: the parabola opens up; $a < 0$: it opens down.
- Substituting $x = 0$ gives $y = c$, so $c$ is the $y$-intercept.

## The axis of symmetry

**Why $x = -\dfrac{b}{2a}$?** Find the points where $y = c$:
$$ax^2 + bx + c = c \;\Rightarrow\; ax^2 + bx = 0 \;\Rightarrow\; x(ax + b) = 0,$$
so $x = 0$ or $x = -\dfrac{b}{a}$. These two points are at the same height, so the axis of symmetry is halfway between them:
$$x = \frac{0 + \left(-\frac{b}{a}\right)}{2} = -\frac{b}{2a}$$

For $y = x^2 - 6x + 5$, the points $(0, 5)$ and $(6, 5)$ are at the same height, so the axis is $x = 3$. Then $y = 3^2 - 6(3) + 5 = -4$, and the vertex is $(3, -4)$.

:::example Vertex from standard form
Find the vertex, the range and the $y$-intercept of $y = 2x^2 - 12x + 7$.
@step $x = -\dfrac{b}{2a} = -\dfrac{-12}{2(2)} = 3$.
@step $y = 2(3)^2 - 12(3) + 7 = 18 - 36 + 7 = -11$, so the vertex is $(3, -11)$.
@step $a = 2 > 0$, so the parabola opens up and $-11$ is the minimum value.
@answer Vertex $(3, -11)$; range $\{y \mid y \ge -11,\ y \in \mathbb{R}\}$; $y$-intercept $7$.
:::

## Completing the square when a = 1

Since $(x + k)^2 = x^2 + 2kx + k^2$, the expression $x^2 + bx$ becomes a perfect square when you add $\left(\dfrac{b}{2}\right)^2$. To keep the function unchanged, add **and** subtract that number.

:::definition Completing the square
Rewriting $ax^2 + bx + c$ in the form $a(x - p)^2 + q$ by creating a perfect-square trinomial.
:::

:::example Completing the square
Write $y = x^2 + 8x + 3$ in vertex form.
@step Half of $8$ is $4$, and $4^2 = 16$.
@step Add and subtract $16$: $y = (x^2 + 8x + 16) - 16 + 3$.
@step Factor the perfect square: $y = (x + 4)^2 - 13$.
@answer $y = (x + 4)^2 - 13$, with vertex $(-4, -13)$.
:::

:::

## Completing the square when a ≠ 1

1. Factor $a$ out of the $x^2$ and $x$ terms.
2. Inside the brackets, add and subtract the square of half the coefficient of $x$.
3. Move the subtracted term out of the brackets by multiplying it by $a$.
4. Factor the perfect square and combine the constants.

:::example Factoring out a first
Write $y = -2x^2 + 12x - 5$ in vertex form.
@step $y = -2(x^2 - 6x) - 5$
@step Half of $-6$ is $-3$, and $(-3)^2 = 9$: $y = -2(x^2 - 6x + 9 - 9) - 5$.
@step $y = -2(x^2 - 6x + 9) + 18 - 5$, because $-2 \times (-9) = 18$.
@answer $y = -2(x - 3)^2 + 13$. Check: $x = -\dfrac{12}{2(-2)} = 3$ and $-2(3)^2 + 12(3) - 5 = 13$ ✓
:::

:::mistake Forgetting to multiply by a
The $-9$ inside $-2(\ \ldots - 9)$ is worth $-2 \times (-9) = +18$ outside the brackets. Writing $-2(x - 3)^2 - 9 - 5$ gives the wrong vertex.
:::

## Analyzing a function in standard form

Find the vertex first; the other features follow from it.

:::example Fractions in the vertex
Analyze $y = 2x^2 + 6x - 1$.
@step $x = -\dfrac{6}{2(2)} = -\dfrac{3}{2}$, and $y = 2\left(-\dfrac{3}{2}\right)^2 + 6\left(-\dfrac{3}{2}\right) - 1 = \dfrac{9}{2} - 9 - 1 = -\dfrac{11}{2}$.
@step Vertex $\left(-\frac{3}{2}, -\frac{11}{2}\right)$; $a > 0$, so it opens up with minimum value $-\frac{11}{2}$.
@step The vertex is below the $x$-axis and the parabola opens up, so there are two $x$-intercepts.
@answer Domain $\{x \mid x \in \mathbb{R}\}$; range $\{y \mid y \ge -\frac{11}{2},\ y \in \mathbb{R}\}$; two $x$-intercepts; $y$-intercept $-1$.
:::

:::check m201-standard-features 3
:::

:::summary
- In $y = ax^2 + bx + c$, the sign of $a$ gives the direction of opening and $c$ is the $y$-intercept.
- The axis of symmetry is $x = -\dfrac{b}{2a}$; substitute it to find the $y$-coordinate of the vertex.
- Complete the square to rewrite standard form as vertex form: factor out $a$, add and subtract $\left(\dfrac{b}{2a}\right)^2$ inside, and multiply the subtracted term by $a$ as it leaves the brackets.
:::
