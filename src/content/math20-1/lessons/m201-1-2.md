A well-known story says that a young Carl Friedrich Gauss was told to add the whole numbers from 1 to 100 and finished in moments. His trick — pair the first number with the last — works for every arithmetic series, and it turns a long addition into one short calculation.

## Series and partial sums

:::definition Series
The sum of the terms of a sequence. If the terms form an arithmetic sequence, the sum is an **arithmetic series**.
:::

:::definition Partial sum
$S_n$ is the sum of the first $n$ terms: $S_n = t_1 + t_2 + \cdots + t_n$.
:::

:::example Partial sums by hand
Find $S_1$ to $S_5$ for $3 + 7 + 11 + 15 + 19 + \cdots$
@step $S_1 = 3$, $S_2 = 3 + 7 = 10$, $S_3 = 10 + 11 = 21$
@step $S_4 = 21 + 15 = 36$, $S_5 = 36 + 19 = 55$
@answer $S_5 = 55$
:::

Adding term by term is fine for five terms, but not for fifty. We need a formula.

## Reverse and add

Write the sum of $1 + 2 + \cdots + 100$ forwards and backwards, then add the two lines column by column.

:::figure
{"type":"table","headers":["","1st","2nd","3rd","⋯","100th"],"rows":[["S","1","2","3","⋯","100"],["S","100","99","98","⋯","1"],["2S","101","101","101","⋯","101"]]}
:::

Every column adds to $101$, and there are 100 columns, so $2S = 100(101)$ and $S = 5050$.

The same argument works for any arithmetic series. Forwards, each term goes up by $d$; backwards, each term goes down by $d$. So every column adds to $t_1 + t_n$:

$$\begin{aligned} S_n &= t_1 + (t_1 + d) + \cdots + t_n \\ S_n &= t_n + (t_n - d) + \cdots + t_1 \\ 2S_n &= n(t_1 + t_n) \end{aligned}$$

Substituting $t_n = t_1 + (n - 1)d$ gives a second version.

:::definition Sum of an arithmetic series
$$S_n = \frac{n(t_1 + t_n)}{2} \qquad\text{or}\qquad S_n = \frac{n}{2}\left[2t_1 + (n - 1)d\right]$$
:::

:::tip Which formula?
Use $\dfrac{n(t_1 + t_n)}{2}$ when you know the last term. Use $\dfrac{n}{2}\left[2t_1 + (n - 1)d\right]$ when you know the common difference but not the last term.
:::

## Using the formulas

:::example Sum of the first n terms
Find the sum of the first 20 terms of $3 + 7 + 11 + \cdots$
@step $t_1 = 3$, $d = 4$, $n = 20$
@step $S_{20} = \dfrac{20}{2}\left[2(3) + (20 - 1)(4)\right] = 10(6 + 76)$
@answer $S_{20} = 820$
:::

:::example When the last term is given
Find the sum of $5 + 8 + 11 + \cdots + 101$.
@step Find $n$ first: $101 = 5 + 3(n - 1)$, so $96 = 3(n - 1)$ and $n = 33$.
@step $S_{33} = \dfrac{33(5 + 101)}{2} = \dfrac{33(106)}{2}$
@answer The sum is $1749$.
:::

:::mistake Using the last term as n
In $5 + 8 + \cdots + 101$, the number $101$ is $t_n$, not $n$. Always find how many terms there are before you use a sum formula.
:::

## Problems with arithmetic series

:::example A pile of logs
A pile of logs has 24 logs in the bottom row and 6 in the top row. Each row has 2 fewer logs than the row below. How many logs are there?
@step $t_1 = 24$, $t_n = 6$, $d = -2$: $6 = 24 - 2(n - 1)$, so $n - 1 = 9$ and $n = 10$ rows.
@step $S_{10} = \dfrac{10(24 + 6)}{2}$
@answer There are $150$ logs.
:::

Sometimes the total is known and the number of terms is not. Substituting into the sum formula then gives a **quadratic equation** in $n$.

:::example How many rows?
A theatre's first row has 12 seats, and each row has 2 more seats than the row in front of it. The theatre has 390 seats. How many rows does it have?
@step $390 = \dfrac{n}{2}\left[2(12) + (n - 1)(2)\right] = \dfrac{n}{2}(2n + 22) = n(n + 11)$
@step $n^2 + 11n - 390 = 0$
@step $(n - 15)(n + 26) = 0$, so $n = 15$ or $n = -26$
@answer The number of rows cannot be negative, so the theatre has 15 rows.
:::

:::mistake Keeping the negative root
A quadratic gives two solutions, but $n$ counts terms, so it must be a natural number. Reject the negative root (and any root that is not a whole number).
:::

:::summary
- A series is the sum of a sequence's terms; $S_n$ is the sum of the first $n$ terms.
- Reverse and add: every pair sums to $t_1 + t_n$, so $S_n = \dfrac{n(t_1 + t_n)}{2} = \dfrac{n}{2}\left[2t_1 + (n - 1)d\right]$.
- When the last term is given, find $n$ first with $t_n = t_1 + (n - 1)d$.
- Finding $n$ from $S_n$ gives a quadratic: solve it and keep the positive whole-number root.
:::
