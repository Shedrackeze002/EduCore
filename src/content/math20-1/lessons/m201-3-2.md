An engineer designing an arch knows how high it must be and how wide it is at the base. That is enough to write its equation, because a parabola is fixed by its vertex and one other point.

## From the vertex and one point

To write $y = a(x - p)^2 + q$:

1. Substitute the vertex for $p$ and $q$.
2. Substitute the coordinates of another point for $x$ and $y$.
3. Solve for $a$.

:::example Vertex and a point
A parabola has vertex $(2, -3)$ and passes through $(4, 5)$. Write its equation in vertex form.
@step Substitute the vertex: $y = a(x - 2)^2 - 3$.
@step Substitute $(4, 5)$: $5 = a(4 - 2)^2 - 3$, so $5 = 4a - 3$.
@step $4a = 8$, so $a = 2$.
@answer $y = 2(x - 2)^2 - 3$
:::

:::

:::example Equation from a graph
Write the equation of the parabola shown.
@step The vertex is $(-1, 4)$, so $y = a(x + 1)^2 + 4$.
@step The parabola passes through $(1, 2)$: $2 = a(1 + 1)^2 + 4$, so $2 = 4a + 4$.
@step $4a = -2$, so $a = -\frac{1}{2}$.
@answer $y = -\frac{1}{2}(x + 1)^2 + 4$
:::

:::tip Use the step pattern to check
From the vertex of $y = x^2$, moving $1$ right goes up $1$, and moving $2$ right goes up $4$. For $y = a(x - p)^2 + q$ those rises are multiplied by $a$. Above, moving $2$ right goes **down** $2$, so $4a = -2$ and $a = -\frac{1}{2}$.
:::

- **A**: vertex above the $x$-axis, opens up (away from the axis): no $x$-intercepts.
- **B**: vertex on the $x$-axis ($q = 0$): one $x$-intercept.
- **C**: vertex below the $x$-axis, opens up (toward the axis): two $x$-intercepts.

In general, if $a$ and $q$ have the **same sign**, there are no $x$-intercepts; if $q = 0$ there is one; if they have **opposite signs** there are two.

:::example Counting x-intercepts
How many $x$-intercepts does $y = -3(x - 1)^2 - 2$ have?
@step The vertex $(1, -2)$ is below the $x$-axis.
@step $a = -3 < 0$, so the parabola opens down, away from the axis.
@answer None.
:::

## Finding the intercepts

- **$y$-intercept**: substitute $x = 0$.
- **$x$-intercepts**: substitute $y = 0$, isolate the squared bracket, and take the square root of both sides.

:::example Intercepts
Find the intercepts of $y = 2(x - 3)^2 - 8$.
@step $x$-intercepts: $0 = 2(x - 3)^2 - 8$, so $(x - 3)^2 = 4$.
@step $x - 3 = \pm 2$, so $x = 1$ or $x = 5$.
@step $y$-intercept: $y = 2(0 - 3)^2 - 8 = 18 - 8 = 10$.
@answer $x$-intercepts $1$ and $5$; $y$-intercept $10$.
:::

:::example Irrational intercepts
Find the $x$-intercepts of $y = -(x + 1)^2 + 7$, exactly and to the nearest hundredth.
@step $0 = -(x + 1)^2 + 7$, so $(x + 1)^2 = 7$.
@step $x + 1 = \pm\sqrt{7}$, so $x = -1 \pm \sqrt{7}$.
@answer $x = -1 + \sqrt{7} \approx 1.65$ and $x = -1 - \sqrt{7} \approx -3.65$.
:::

:::mistake Forgetting the negative root
$(x - 3)^2 = 4$ has two solutions, because $2^2 = 4$ and $(-2)^2 = 4$. Taking only $x - 3 = 2$ loses the intercept $x = 1$. Notice the two intercepts are symmetric about the axis $x = 3$.
:::

:::

## Modelling with vertex form

Choose a coordinate system that makes the vertex easy to find, then use one more known point.

:::example A parabolic arch
An arch is $40$ m wide at ground level and $10$ m high at its centre. Write its equation with the origin at the left end of the arch.
@step The top of the arch is halfway across: the vertex is $(20, 10)$, so $y = a(x - 20)^2 + 10$.
@step The left end is $(0, 0)$: $0 = a(0 - 20)^2 + 10$, so $400a = -10$.
@step $a = -\frac{10}{400} = -\frac{1}{40}$.
@answer $y = -\frac{1}{40}(x - 20)^2 + 10$. (Check the right end: $-\frac{1}{40}(20)^2 + 10 = 0$ ✓)
:::

:::check m201-vertex-equation 3
:::

:::summary
- To write $y = a(x - p)^2 + q$, substitute the vertex, then another point, and solve for $a$.
- Number of $x$-intercepts: $a$ and $q$ with the same sign give none, $q = 0$ gives one, opposite signs give two.
- For $x$-intercepts set $y = 0$ and use $\pm$ square roots; for the $y$-intercept set $x = 0$.
- The $x$-intercepts are symmetric about the axis of symmetry.
:::
