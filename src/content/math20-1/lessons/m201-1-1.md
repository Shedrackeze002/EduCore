Rows of seats in a theatre, a savings account that grows by the same deposit every week, the distance a falling stone drops in each second — each one changes by the **same amount** at every step. These patterns are called arithmetic sequences, and one formula lets you jump straight to the 100th term without listing the first 99.

## Sequences and common differences

:::definition Sequence
An ordered list of numbers. Each number is a **term**. We write $t_1$ for the first term, $t_2$ for the second, and $t_n$ for the term in position $n$.
:::

:::definition Arithmetic sequence
A sequence in which each term after the first is found by adding the same number, the **common difference** $d$:
$$d = t_n - t_{n-1}$$
:::

| Sequence | Common difference |
|---|---|
| $5,\ 9,\ 13,\ 17,\ \ldots$ | $d = 9 - 5 = 4$ |
| $20,\ 14,\ 8,\ 2,\ \ldots$ | $d = 14 - 20 = -6$ |
| $\frac{1}{2},\ \frac{5}{4},\ 2,\ \frac{11}{4},\ \ldots$ | $d = \frac{5}{4} - \frac{1}{2} = \frac{3}{4}$ |

A sequence is a function whose domain is the natural numbers $\{1, 2, 3, \ldots\}$. If you plot each term $t_n$ against its position $n$, the points of an arithmetic sequence lie on a straight line whose slope is $d$.

## The general term

Start at $t_1$ and keep adding $d$:

$$t_1,\quad t_2 = t_1 + d,\quad t_3 = t_1 + 2d,\quad t_4 = t_1 + 3d,\quad \ldots$$

To reach term $n$ you add $d$ exactly $n - 1$ times.

:::definition General term of an arithmetic sequence
$$t_n = t_1 + (n - 1)d$$
:::

:::example Finding a far-off term
Find $t_{40}$ for $5,\ 9,\ 13,\ \ldots$
@step $t_1 = 5$ and $d = 4$
@step $t_{40} = 5 + (40 - 1)(4) = 5 + 156$
@answer $t_{40} = 161$
:::

:::example Writing the general term
Write the general term of $20,\ 14,\ 8,\ 2,\ \ldots$ in simplified form.
@step $t_1 = 20$ and $d = -6$
@step $t_n = 20 + (n - 1)(-6) = 20 - 6n + 6$
@step Check: $t_2 = -6(2) + 26 = 14$ ✓
@answer $t_n = -6n + 26$
:::

:::mistake Multiplying d by n instead of n − 1
$t_{40} = 5 + 40(4) = 165$ is wrong: it adds $d$ one time too many. The first term already counts as one step, so there are $n - 1$ jumps.
:::

:::tip A linear function in disguise
Expanding always gives $t_n = dn + (t_1 - d)$: a linear function of $n$ whose slope is the common difference. That is why the points lie on a line.
:::

## Two terms that are not next to each other

If you know two terms, count the steps between them.

:::example From two terms
In an arithmetic sequence, $t_4 = 17$ and $t_{11} = 52$. Find $t_{20}$.
@step From $t_4$ to $t_{11}$ is $11 - 4 = 7$ steps, so $t_{11} = t_4 + 7d$.
@step $52 = 17 + 7d$, so $7d = 35$ and $d = 5$.
@step Work back: $t_1 = t_4 - 3d = 17 - 15 = 2$
@step $t_{20} = 2 + (20 - 1)(5) = 2 + 95$
@answer $t_{20} = 97$
:::

You could also write the system $t_1 + 3d = 17$ and $t_1 + 10d = 52$ and subtract the equations. It is the same calculation.

:::check m201-arith-term 3
:::

## Finding n, t₁ or d

The general term links four quantities: $t_n$, $t_1$, $n$ and $d$. Know any three and you can solve for the fourth.

:::example Which term is it?
Which term of $5,\ 9,\ 13,\ \ldots$ is $97$?
@step $97 = 5 + (n - 1)(4)$
@step $92 = 4(n - 1)$, so $n - 1 = 23$
@answer $n = 24$, so $97$ is $t_{24}$.
:::

:::example Counting the terms
How many terms are in $7,\ 12,\ 17,\ \ldots,\ 152$?
@step The last term is $t_n = 152$, with $t_1 = 7$ and $d = 5$.
@step $152 = 7 + 5(n - 1)$, so $145 = 5(n - 1)$ and $n - 1 = 29$.
@answer There are $30$ terms.
:::

:::mistake Accepting a fraction for n
The position $n$ must be a natural number. For $5,\ 9,\ 13,\ \ldots$, solving $100 = 5 + 4(n - 1)$ gives $n - 1 = 23.75$. That means $100$ is **not** a term of the sequence.
:::

## Arithmetic sequences in context

Decide what the first term is and what changes by the same amount each step.

:::example Theatre seats
The first row of a theatre has 18 seats, and each row has 2 more seats than the row in front of it. Write the general term, find the seats in row 25, and find which row has 60 seats.
@step $t_1 = 18$, $d = 2$: $t_n = 18 + 2(n - 1) = 2n + 16$
@step Row 25: $t_{25} = 2(25) + 16 = 66$ seats
@step $60 = 2n + 16$, so $2n = 44$
@answer $t_n = 2n + 16$; row 25 has 66 seats; row 22 has 60 seats.
:::

:::example A falling stone
Ignoring air resistance, a dropped stone falls $4.9$ m in the first second and $9.8$ m more in each second than in the second before. Write the general term for the distance fallen in second $n$.
@step $t_1 = 4.9$ and $d = 9.8$
@step $t_n = 4.9 + 9.8(n - 1) = 9.8n - 4.9$
@answer $t_n = 9.8n - 4.9$; for example, it falls $t_5 = 44.1$ m during the fifth second.
:::

:::summary
- An arithmetic sequence adds the same common difference $d = t_n - t_{n-1}$ at every step.
- General term: $t_n = t_1 + (n - 1)d$, which simplifies to a linear function of $n$ with slope $d$.
- From two terms: the gap between them is (difference in positions) $\times\, d$.
- Solve $t_n = t_1 + (n - 1)d$ for whichever quantity is missing; $n$ must be a natural number.
:::
