You cannot add $\tfrac{1}{4} + \tfrac{1}{6}$ until both fractions have the same denominator: $\tfrac{3}{12} + \tfrac{2}{12} = \tfrac{5}{12}$. Rational expressions work the same way, and the **lowest** common denominator keeps the algebra as short as possible.

## Monomial denominators

:::definition Lowest common denominator (LCD)
The simplest expression that every denominator divides into. Build it from the least common multiple of the coefficients and each variable factor to its **highest** power.
:::

To add or subtract, rewrite each fraction over the LCD by multiplying its numerator and denominator by whatever its denominator is missing. Then combine the numerators.

:::example Different powers of x
Simplify $\dfrac{3}{4x} + \dfrac{5}{6x^2}$.
@step LCD: the least common multiple of $4$ and $6$ is $12$, and the highest power of $x$ is $x^2$, so the LCD is $12x^2$.
@step $\dfrac{3}{4x} \cdot \dfrac{3x}{3x} + \dfrac{5}{6x^2} \cdot \dfrac{2}{2} = \dfrac{9x}{12x^2} + \dfrac{10}{12x^2}$
@answer $\dfrac{9x + 10}{12x^2}$, $x \ne 0$
:::

:::example Numerators with two terms
Simplify $\dfrac{x + 1}{4} - \dfrac{x - 3}{6}$.
@step LCD $= 12$: $\dfrac{3(x + 1) - 2(x - 3)}{12}$.
@step Expand carefully: $3x + 3 - 2x + 6 = x + 9$.
@answer $\dfrac{x + 9}{12}$
:::

## Binomial denominators

When the denominators are different binomials with no common factor, the LCD is their product.

:::example Two binomials
Simplify $\dfrac{2}{x + 3} - \dfrac{1}{x - 2}$.
@step LCD: $(x + 3)(x - 2)$, so $x \ne -3,\ 2$.
@step $\dfrac{2(x - 2)}{(x + 3)(x - 2)} - \dfrac{1(x + 3)}{(x + 3)(x - 2)} = \dfrac{2(x - 2) - (x + 3)}{(x + 3)(x - 2)}$
@step Numerator: $2x - 4 - x - 3 = x - 7$.
@answer $\dfrac{x - 7}{(x + 3)(x - 2)}$, $x \ne -3,\ 2$
:::

:::mistake Subtracting only the first term
$2(x - 2) - (x + 3)$ is $2x - 4 - x - 3$, not $2x - 4 - x + 3$. Put the numerator you subtract in brackets so the minus sign reaches **every** term.
:::

:::

## Factor the denominators first

When a denominator is a trinomial or a difference of squares, factor it. Then the LCD uses each different factor the greatest number of times it appears in any one denominator.

:::example A shared factor
Simplify $\dfrac{x}{x^2 - 9} + \dfrac{2}{x + 3}$.
@step Factor: $x^2 - 9 = (x - 3)(x + 3)$. The LCD is $(x - 3)(x + 3)$, so $x \ne \pm 3$.
@step The second fraction is missing $(x - 3)$: $\dfrac{x + 2(x - 3)}{(x - 3)(x + 3)}$.
@step Numerator: $x + 2x - 6 = 3x - 6 = 3(x - 2)$.
@answer $\dfrac{3(x - 2)}{(x - 3)(x + 3)}$, $x \ne \pm 3$
:::

:::tip Opposite denominators
$x - 4$ and $4 - x$ are opposites, so $\dfrac{3}{4 - x} = -\dfrac{3}{x - 4}$. That gives $\dfrac{5}{x - 4} + \dfrac{3}{4 - x} = \dfrac{5}{x - 4} - \dfrac{3}{x - 4} = \dfrac{2}{x - 4}$, with $x \ne 4$.
:::

## Simplify at the end

After combining, factor the numerator. If it shares a factor with the denominator, divide it out — but keep the original restrictions.

:::example A result that simplifies
Simplify $\dfrac{1}{x - 1} - \dfrac{2}{x^2 - 1}$.
@step LCD: $(x - 1)(x + 1)$, so $x \ne \pm 1$.
@step $\dfrac{(x + 1) - 2}{(x - 1)(x + 1)} = \dfrac{x - 1}{(x - 1)(x + 1)}$
@step Divide out $(x - 1)$.
@answer $\dfrac{1}{x + 1}$, $x \ne \pm 1$
:::

:::

:::summary
- Find the LCD: factor every denominator, then take each different factor to its highest power.
- Multiply each numerator by the factors its denominator is missing.
- Put brackets around any numerator you subtract.
- Simplify the numerator, check for a common factor, and state the restrictions.
:::
