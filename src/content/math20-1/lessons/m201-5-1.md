A square courtyard with an area of $200\ \text{m}^2$ has sides $\sqrt{200}$ m long. An engineer would write that as $10\sqrt{2}$ m: it is exact, it is easy to estimate (about $14.1$ m), and it can be added to other lengths such as $3\sqrt{2}$ m. In calculus you will keep answers exact like this all the time, so this lesson makes working with radicals routine.

## Radicals and simplest form

:::definition Radical
A **radical** $\sqrt[n]{a}$ has an **index** $n$ and a **radicand** $a$. For a square root the index $2$ is not written. When $n$ is even, $\sqrt[n]{a}$ means the **principal** (non-negative) root, and the radicand must be non-negative.
:::

Everything in this unit rests on one property.

$$\sqrt{ab} = \sqrt{a}\,\sqrt{b} \qquad \text{for } a \ge 0,\ b \ge 0$$

**Why it is true.** Both $\sqrt{a}$ and $\sqrt{b}$ are non-negative, so $\sqrt{a}\,\sqrt{b} \ge 0$. Also $\left(\sqrt{a}\,\sqrt{b}\right)^2 = \left(\sqrt{a}\right)^2\left(\sqrt{b}\right)^2 = ab$. So $\sqrt{a}\,\sqrt{b}$ is the non-negative number whose square is $ab$ — which is exactly the definition of $\sqrt{ab}$. The same argument works for cube roots, with no sign restriction.

:::definition Mixed and entire radicals
An **entire radical** has nothing outside the radical sign, such as $\sqrt{300}$. A **mixed radical** has a coefficient outside, such as $10\sqrt{3}$. A radical is in **simplest form** when the radicand has no perfect-square factor other than $1$ (no perfect-cube factor for a cube root).
:::

:::example Entire to mixed
Write (a) $\sqrt{300}$ and (b) $\sqrt[3]{-54}$ in simplest form.
@step (a) The largest perfect square dividing $300$ is $100$: $\sqrt{300} = \sqrt{100}\,\sqrt{3} = 10\sqrt{3}$.
@step (b) The largest perfect cube dividing $-54$ is $-27 = (-3)^3$: $\sqrt[3]{-54} = \sqrt[3]{-27}\,\sqrt[3]{2} = -3\sqrt[3]{2}$.
@answer $\sqrt{300} = 10\sqrt{3}$ and $\sqrt[3]{-54} = -3\sqrt[3]{2}$
:::

:::mistake Stopping too early
$\sqrt{300} = \sqrt{4 \times 75} = 2\sqrt{75}$ is true but **not** simplest form, because $75 = 25 \times 3$ still contains a perfect square. Use the largest perfect-square factor, or keep going until none is left.
:::

## Variable radicands

A power with an even exponent is a perfect square: $x^6 = \left(x^3\right)^2$, so $\sqrt{x^6} = x^3$. Taking a square root halves an even exponent.

Careful: $\sqrt{x^2} = |x|$, not $x$. For example, $\sqrt{(-3)^2} = \sqrt{9} = 3$. In this unit we **state that the variables are non-negative**, so $\sqrt{x^2} = x$ and no absolute value signs are needed.

:::example A variable radicand
Assume $x \ge 0$ and $y \ge 0$. Write $\sqrt{72x^5y^2}$ in simplest form.
@step Split off the largest perfect square: $72x^5y^2 = 36x^4y^2 \cdot 2x$.
@step $\sqrt{36x^4y^2} = 6x^2y$, because $\left(6x^2y\right)^2 = 36x^4y^2$.
@answer $\sqrt{72x^5y^2} = 6x^2y\sqrt{2x}$
:::

:::example Mixed to entire
Assume $a \ge 0$. Write $3a^2\sqrt{2a}$ as an entire radical.
@step Write the outside factor as a square root: $3a^2 = \sqrt{9a^4}$.
@step Multiply the radicands: $\sqrt{9a^4}\,\sqrt{2a} = \sqrt{18a^5}$.
@answer $3a^2\sqrt{2a} = \sqrt{18a^5}$
:::

:::mistake Taking the root of the exponent
$\sqrt{x^{6}}$ is $x^{3}$, not $x^{4}$ or $x^{\sqrt6}$. Halve the exponent: $\left(x^3\right)^2 = x^6$.
:::

## Comparing and ordering radicals

To compare radicals without a calculator, write each one as an **entire radical**. For non-negative numbers, the larger radicand gives the larger square root.

:::example Ordering
Order $3\sqrt{5}$, $2\sqrt{11}$, $4\sqrt{3}$ and $7$ from least to greatest.
@step $3\sqrt{5} = \sqrt{45}$, $2\sqrt{11} = \sqrt{44}$, $4\sqrt{3} = \sqrt{48}$ and $7 = \sqrt{49}$.
@step Compare the radicands: $44 < 45 < 48 < 49$.
@answer $2\sqrt{11} < 3\sqrt{5} < 4\sqrt{3} < 7$
:::

The four numbers are very close together, which is why converting is more reliable than estimating:

For negative radicals the order flips. Since $-3\sqrt{2} = -\sqrt{18}$ and $-2\sqrt{5} = -\sqrt{20}$, and $\sqrt{20}$ is farther from zero, $-2\sqrt{5} < -3\sqrt{2}$.

:::tip Variables under the radical
If $x > 0$, then $2\sqrt{3x} = \sqrt{12x}$ and $3\sqrt{x} = \sqrt{9x}$, so $3\sqrt{x} < 2\sqrt{3x}$. Compare the coefficients of $x$ under the radical signs.

## Adding and subtracting radicals

:::definition Like radicals
**Like radicals** have the same index and the same radicand, such as $5\sqrt{2}$ and $-3\sqrt{2}$. Like radicals combine the way like terms do: $5\sqrt{2} - 3\sqrt{2} = 2\sqrt{2}$, just as $5x - 3x = 2x$.
:::

Radicals that do not look alike may become like radicals once they are simplified.

:::example Simplify, then combine
Simplify $\sqrt{50} + \sqrt{18} - \sqrt{8}$.
@step $\sqrt{50} = 5\sqrt{2}$, $\sqrt{18} = 3\sqrt{2}$ and $\sqrt{8} = 2\sqrt{2}$.
@step $5\sqrt{2} + 3\sqrt{2} - 2\sqrt{2} = (5 + 3 - 2)\sqrt{2}$
@answer $6\sqrt{2}$
:::

:::example Two kinds of radicals
Simplify $\sqrt{12} + \sqrt{50} - \sqrt{27} + \sqrt{8}$.
@step $2\sqrt{3} + 5\sqrt{2} - 3\sqrt{3} + 2\sqrt{2}$
@step Group like radicals: $(5 + 2)\sqrt{2} + (2 - 3)\sqrt{3}$
@answer $7\sqrt{2} - \sqrt{3}$
:::

:::example Variable radicands
Assume $x \ge 0$. Simplify $x\sqrt{12x} + 3\sqrt{27x^3} - 2x\sqrt{3x}$.
@step $x\sqrt{12x} = x \cdot 2\sqrt{3x} = 2x\sqrt{3x}$
@step $3\sqrt{27x^3} = 3 \cdot 3x\sqrt{3x} = 9x\sqrt{3x}$
@step All three terms are multiples of $x\sqrt{3x}$: $(2 + 9 - 2)x\sqrt{3x}$
@answer $9x\sqrt{3x}$
:::

:::mistake Adding radicands
$\sqrt{2} + \sqrt{3} \ne \sqrt{5}$. Check with a calculator: $1.414 + 1.732 = 3.146$, but $\sqrt{5} \approx 2.236$. Only the **coefficients** of like radicals are added; the radicand never changes.
:::

:::summary
- $\sqrt{ab} = \sqrt{a}\,\sqrt{b}$ for $a, b \ge 0$; use it to move between entire and mixed radicals.
- Simplest form: take out the **largest** perfect square (or cube). Even exponents are perfect squares.
- With variable radicands, state that the variables are non-negative, since $\sqrt{x^2} = |x|$.
- Compare radicals by writing them as entire radicals; for negatives the order flips.
- Add or subtract only **like radicals** — simplify first, then combine the coefficients.
:::
