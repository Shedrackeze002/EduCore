Which numbers are exactly 5 units from 3 on a number line? There are two: $8$ and $-2$. That is the equation $|x - 3| = 5$, and it shows why absolute value equations usually have two solutions.

## Two cases

:::figure
{"type":"numberLine","min":-3,"max":9,"step":1,"points":[{"value":-2,"label":"−2"},{"value":3,"label":"3"},{"value":8,"label":"8"}]}
:::

If $|A| = b$ and $b \ge 0$, then $A = b$ or $A = -b$. Solve both cases.

:::example A linear expression
Solve $|2x - 3| = 7$.
@step Case 1: $2x - 3 = 7$, so $2x = 10$ and $x = 5$.
@step Case 2: $2x - 3 = -7$, so $2x = -4$ and $x = -2$.
@step Check: $|2(5) - 3| = 7$ ✓ and $|2(-2) - 3| = |{-}7| = 7$ ✓
@answer $x = -2$ or $x = 5$
:::

:::example Isolate the absolute value first
Solve $3|x - 1| + 4 = 10$.
@step Subtract 4 and divide by 3: $|x - 1| = 2$.
@step $x - 1 = 2$ gives $x = 3$; $x - 1 = -2$ gives $x = -1$.
@answer $x = -1$ or $x = 3$
:::

:::mistake A negative right side
$|x + 4| = -2$ has **no solution**: an absolute value is never negative. Do not solve the two cases — they would give answers that do not check.
:::

:::check m201-abs-equation 1
:::

## Extraneous solutions

When the right side contains the variable, it might be negative for some of the answers you find. Those answers are extraneous.

:::definition Extraneous solution
A value found while solving that does not satisfy the original equation. With absolute value equations, it usually makes the right side negative.
:::

:::example A variable on the right
Solve $|x - 3| = 2x + 1$.
@step Case 1: $x - 3 = 2x + 1$, so $x = -4$.
@step Case 2: $x - 3 = -(2x + 1)$, so $3x = 2$ and $x = \tfrac{2}{3}$.
@step Check $x = -4$: left $|{-}7| = 7$, right $2(-4) + 1 = -7$ ✗ — extraneous.
@step Check $x = \tfrac{2}{3}$: left $\left|{-}\tfrac{7}{3}\right| = \tfrac{7}{3}$, right $\tfrac{4}{3} + 1 = \tfrac{7}{3}$ ✓
@answer $x = \tfrac{2}{3}$
:::

## Quadratic expressions

The two cases now give two quadratic equations. Each might have two, one or no real roots.

:::example Up to four solutions
Solve $|x^2 - 5| = 4$.
@step Case 1: $x^2 - 5 = 4$, so $x^2 = 9$ and $x = \pm 3$.
@step Case 2: $x^2 - 5 = -4$, so $x^2 = 1$ and $x = \pm 1$.
@answer $x = -3,\ -1,\ 1,\ 3$
:::

:::example A case with no real roots
Solve $|x^2 - 2x - 3| = 5$.
@step Case 1: $x^2 - 2x - 8 = 0$, so $(x - 4)(x + 2) = 0$: $x = 4$ or $x = -2$.
@step Case 2: $x^2 - 2x + 2 = 0$. The discriminant is $4 - 8 = -4 < 0$, so there are no real roots.
@answer $x = -2$ or $x = 4$
:::

:::example Rejecting roots
Solve $|x^2 - 4| = 3x$.
@step Case 1: $x^2 - 3x - 4 = 0$, so $(x - 4)(x + 1) = 0$: $x = 4$ or $x = -1$.
@step Case 2: $x^2 - 4 = -3x$, so $x^2 + 3x - 4 = 0$ and $(x + 4)(x - 1) = 0$: $x = -4$ or $x = 1$.
@step The right side $3x$ must not be negative, so reject $x = -1$ and $x = -4$. Check $x = 4$: $|12| = 12$ ✓; $x = 1$: $|{-}3| = 3$ ✓
@answer $x = 1$ or $x = 4$
:::

:::check m201-abs-equation 3
:::

:::summary
- $|A| = b$ with $b \ge 0$ means $A = b$ or $A = -b$; with $b < 0$ there is no solution.
- Isolate the absolute value before splitting into cases.
- If the right side contains the variable, check every answer: reject any that make it negative.
- Quadratic cases can give up to four solutions; use the discriminant when a case will not factor.
:::
